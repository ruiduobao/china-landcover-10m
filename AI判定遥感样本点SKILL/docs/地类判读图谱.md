# 参考：地类判读图谱（判据写在"影像上看到什么"）

> 适用：0.3–0.6 m 高分底图（Esri/Google，判结构）+ 10 m 哨兵时序（判物候）+ 辅助指标（冠层高度/树覆盖/淹水）。
> 用法：先按下表判断"大类"，再对耕地走第 2 节的**作物决策树**；单期分不开的一律靠物候。
> 铁律：**没有日期就没有作物**。高分底图是多年拼接，必须问"这张影像是什么季节/哪一年"。

---

## 1. 大类速判（高分图上）

| 大类 | 影像特征（0.5 m） | 排除项 |
|---|---|---|
| 耕地 | 规整田块、田埂/垄行、边界直、有农机痕迹；地块大小随地形 | 与"人工草地/大棚"区分：前者有垄行纹理 |
| 乔木林 | 冠幅 2–10 m 的圆/星形冠层，有明显阴影；密时连片"西兰花"质感 | 幼林（冠幅 <2 m）像灌丛 → 看行距与地形 |
| 灌丛 | 低矮、细碎丛团（1–3 m），无大冠层与冠影；常成片在坡地/林缘 | 与"灌草丛"难分 → 看木本是否占优（≥4 成算灌丛） |
| 草地 | 均匀柔滑无丛团；可有割草条纹 | 高原草甸：细碎斑点（鼠兔/草丛） |
| 水体 | 深色均匀/带波纹；养殖塘有投饵机、增氧机 | 与"淹水稻田"区分：稻田有格田与秧行 |
| 不透水面 | 屋顶规则几何、灰色沥青、车流；村庄=小屋顶簇 | 光伏=深色棋盘格矩形阵列 |
| 裸地 | 亮白/土黄无植被纹理；有冲沟、沙纹 | 与"翻耕地"区分：翻耕地有垄行方向一致 |
| 冰雪 | 纯白带纹理，常在阴坡/高处 | 与"盐田/盐湖"区分：盐田有格田与堤 |
| 稀疏植被 | 沙/砾基质上散点状植丛，覆盖 10–30% | 覆盖 >30% 且木本为主 → 灌丛 |

## 2. 作物决策树（核心）

### 2.1 先定"农时窗口"（按区域）

| 区域 | 主要熟制 | 关键窗口（用来看影像） |
|---|---|---|
| 东北（黑吉辽） | 一年一熟 | 4 月末–5 月播种；6 月出苗；**7–8 月抽穗/开花**；9 月末–10 月收获；水稻 **5 月中–6 月淹水** |
| 黄淮海（冀鲁豫皖北） | 冬小麦 + 夏玉米 | **6 月麦收（金黄）**；6 月中玉米播种；9–10 月玉米收；10 月播麦 |
| 长江中下游 | 稻–麦/油轮作 | **3–4 月油菜花（黄）**；5–6 月早稻淹水；7 月早稻收；7–8 月晚稻淹水 |
| 华南（粤桂闽） | 双季稻 / 甘蔗 / 果园 | **3 月早稻淹水**；6–7 月早稻收；7–8 月晚稻淹水；11 月晚稻收；甘蔗全年绿、11–3 月收 |
| 新疆 | 棉花 / 玉米 / 小麦 / 果园 | **4–5 月棉花铺膜（白/银条带）**；6–7 月棉花团棵；7 月玉米抽穗；9–10 月采收 |
| 云南 | 甘蔗 / 咖啡 / 香蕉 / 橡胶 | 甘蔗全年；橡胶 2–3 月落叶（可判）、4 月返青 |

### 2.2 逐作物判据（高分看什么 / 时序看什么）

**水稻 Paddy rice**
- 高分（关键在**淹水期**）：格田方正、有田埂与灌排渠；**移栽期田面是镜面黑水**，水中可见成行秧苗（散点状绿点行）；中后期成整齐行栽、行距 0.25–0.3 m。
- 时序：NDVI 曲线呈"**低—陡升—平台—速降**"；淹水期 NDWI 高、哨兵一号 VV 明显下降；抽穗期 NDVI 峰值高而平台短。
- 与"养殖塘"区分：塘常年有水、无秧行、多见投饵机/增氧机（白点）；稻田水只在移栽窗口出现。

**玉米 Maize / corn**
- 高分：行距 0.6–0.7 m 的**宽行**，株间土面可见；抽雄期顶端发黄（雄穗）；收获后**高茬**（残茬成行、比大豆茬高）。
- 时序：NDVI 峰值高、出现时间略晚于大豆，灌浆后下降慢。
- 与大豆区分：玉米行更宽、冠层更"起伏"，收获更晚（东北 9 月末–10 月 vs 大豆 9 月下旬）。

**（东北实测对照·2023 生长季，5 期哨兵时序）**

| 作物 | 关键窗口 | NDVI 峰值日 | 振幅 | 成熟期外观 |
|---|---|---|---|---|
| 水稻 | 5 月中淹水/移栽 | **最早（7 月中）** | 0.67 | 9 月整田转黄 |
| 玉米 | 5 月播种 | 居中（7 月末–8 月初） | 0.71 | 9 月末收割，茬高 |
| 大豆 | 5 月播种 | **最晚（8 月上旬）** | 0.71 | **9 月中起叶片先黄**（比玉米早显黄） |

用法：先看峰值日期排序（稻 < 玉米 ≈ 大豆），再看成熟期是否"先黄"（大豆）与茬高（玉米），叠加高分图的行距/管理痕迹定案。

**大豆 Soybean**
- 高分：行距 0.6–0.7 m 但**冠层封行早**，叶色深绿均匀、行间几乎不露土；无雄穗、无高茬。
- 时序：NDVI 峰值略低于玉米，回落更早；成熟期叶片转黄快。
- 与玉米的实用判法：**同一地块的轮作格局**（东北玉米–大豆轮作常见相邻田块互换）+ 收获日期 + 茬高。

**小麦 Wheat**
- 高分：早春细密均匀绿（无宽行），齐穗后金黄一片；**大面积平展、田块方正**。
- 时序：春季 NDVI 快速升高，**5–6 月成熟后骤降**（黄淮海 6 月金黄）；与玉米的"夏季绿"互补。

**油菜 Rapeseed / canola**
- 高分：**3–4 月盛花期整田亮黄**，田块边界清楚；花期后转绿结荚。
- 长江流域最常见；与小麦区分：花期颜色独一无二。

**棉花 Cotton**
- 高分：**播后地膜期：白/银（或黑）薄膜成行**，行距 0.4–0.6 m；团棵期中等高度、叶片阔；秋季吐絮期白点成片。
- 新疆特有：滴灌管+膜下滴灌形成的整齐条带；地块大而方。
- 与玉米区分：棉花行更密、无高茬、秋后有吐絮白点。

**甘蔗 Sugarcane**
- 高分：**高而密的条垄**（2–4 m 高），行距 1–1.4 m，冠层深绿、纹理粗；收获后地面留成行蔗茬。
- 时序：常绿期长，冬季仍绿（华南）；1–3 月收获时大面积裸田+蔗茬行。

**果园 Orchard**
- 高分：**成行排列的独立树冠**（行距 3–6 m），行间可见草地/裸土；树冠大小一致（同批栽植）。
- 与"防护林带"区分：防护林通常单行/双行、沿地块边界呈直线。
- 树种线索：柑橘/荔枝=暗绿圆冠密集；苹果/梨=行距大、行间裸土常被管理。

**茶园 Tea**
- 高分：**等高梯坎上成排矮绿篱**（被修剪成连续条带，宽 1–1.5 m），丘陵坡面呈等高线纹理。
- 与"梯田耕作"区分：茶园条带连续、颜色深绿均匀；梯田作物有季节裸期。

**大棚 Greenhouse**
- 高分：**成排的白色/浅色拱顶或矩形结构**，间距均匀、常连片；有棚间作业道。
- 与"厂房"区分：厂房多为深色平顶/坡顶、有停车场；大棚呈规则长条、反光强。

**蔬菜 Vegetable（含地膜菜地）**
- 高分：地块**小而碎、种类混杂**（不同颜色/高度的畦），地膜条带常见（白/黑/银）；田块边界不规则。
- 时序：NDVI 无统一节律（多茬口、频繁翻耕）——"乱"本身就是判据。

**地膜 Mulch（辅助判据）**
- 白色/银色膜：亮点状条带、反光强；黑色膜：暗色条带对比周围土色。
- 有膜 = 该地块为经济作物（棉/玉米/蔬菜/瓜），可显著缩小候选。

**橡胶 Rubber（云南）**
- 高分：山坡上**成行、冠层匀整的落叶性树**；2–3 月落叶期整片灰褐（落叶），4 月起返青。
- 时序：常绿但有明显落叶窗口（与常绿阔叶林区分点）。

**养殖塘 Aquaculture pond**
- 高分：规则方形/圆形水面，堤埂笔直；白点=增氧机/投饵机；冬季可能干塘（露塘底）。
- 与稻田区分见"水稻"条。

## 3. 时序指标速查（用于自动生成判读提示）

| 指标 | 含义 | 典型判读 |
|---|---|---|
| `ndvi_amp`（振幅） | 最大−最小 NDVI | >0.4 一年生作物；<0.2 常绿林/水体 |
| `ndvi_peak` | 峰值 | 峰值高且晚=玉米；峰值早=小麦/油菜 |
| `flood_evidence` | 生长季早期 NDWI/淹水信号 | 有 → 水稻/湿地 |
| `ch_mean`（冠层高度中位） | GEDI/ETH 冠高 | <1.5 m 草本；1.5–5 m 灌丛/幼林；>5 m 乔木（但 2 km 均值会向上偏，仅作旁证） |
| `tc2000`（Hansen 树覆盖） | 2000 年树覆盖 % | >50% 偏林地；0 且高 NDVI 振幅 → 农田/草地 |

**判读提示的生成口径**：把上表指标连同年份、季节窗口一起写进表单的"指标提示"列，供判读时交叉验证；**冲突时以影像为准，并在证据列写明冲突**。

## 4. 常见混淆与解法（速查）

| 混淆对 | 分辨手段 |
|---|---|
| 玉米 vs 大豆 | 行宽+茬高+收获日期+轮作格局；单期不可判则看 6–8 月时序 |
| 水稻 vs 藕田/芦苇湿地 | 淹水期稻有秧行与格田；藕田叶大（浮叶斑块）、芦苇期长无格田 |
| 大棚 vs 厂房/光伏 | 形状（长条拱顶 vs 矩形深色板）、排列密度、周边（农田 vs 园区） |
| 果园 vs 人工林 | 果园行距大、树冠大小一致、行间管理痕迹；人工林冠层连续 |
| 茶园 vs 灌丛 | 茶园条带被修剪（连续等高绿篱）；灌丛团块不规则 |
| 灌丛 vs 幼林 | 幼林有行距（造林行）与地块边界；灌丛边界随地形 |
| 草地 vs 荒草地 | 荒草地灌草混合、有小径与侵蚀斑；草地平整连续 |
| 裸地 vs 收获后农田 | 收获田有行茬纹理与地块边界；裸地无纹理（风蚀/沙地） |
| 水面 vs 冰面 | 冰面有裂纹白纹理、边缘雪；水面深色反光 |
| 盐田 vs 雪 | 盐田有格田堤埂与蒸发池色阶（粉/白/灰） |

## 5. 判读证据的写法（强制格式）

每条判读的"证据"列必须能独立复查，写法示例：

- `[Esri z18 2024Q2 高分] 格田+镜面水+成行秧苗；[S2 2023-05 NDWI 高、VV 降 4 dB] → 水稻（高）`
- `[Esri z18] 宽行+行间露土+顶端雄穗黄；[S2 NDVI 峰值 8 月中、收获后高茬] → 玉米（高）`
- `[Esri z18 影像模糊/云] [S2 生长季合成 云占比>60%] → 无法判读（云）`

**没有坐标日期出处的判读不算完成。**
