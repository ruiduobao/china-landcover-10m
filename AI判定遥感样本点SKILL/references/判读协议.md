# 参考：判读协议（操作定义 · 盲判 · 质控 · 报告口径）

> 本协议的目的是让**判读结论可复核、可复现、不被先验标签污染**。
> 正式成果（论文/交付）必须按第 4 节出"质控三率"，并声明是否经人工复核。

---

## 1. 判定三态与操作定义

| 结论 | 什么时候写 | 反例（不许写） |
|---|---|---|
| **正确**（确认先验/目标类） | 影像上能指出该类的**判别性特征**，且无相反证据 | "看着像"、"大概率" |
| **错误**（否定） | 能指出与先验类**矛盾**的特征，且能给出**实际类别** | 只写"不是"，不填实际类 |
| **无法判读** | 云/雾/阴影/影像分辨率不足/目标为混合像元且无主导 | 没耐心看图就写"无法" |

**硬规则**
1. 三态必须**带置信**（高/中/低）+ **证据**（影像特征 + 来源 + 日期/季节 + 辅助指标数值）；
2. "无法判读" **单列**，不并入"错误"，不参与"确认率"分母，但要在报告里给出占比；
3. 每条证据必须能**独立复查**（写清哪张图、什么源、什么时候）；
4. 判读**以影像为准**：辅助指标（冠层高度、NDVI、先验产品）只作旁证，冲突时写进证据列并说明取舍。

## 2. 盲判纪律（防锚定）

- 判读批次（联系表/清单）**只给 point_id**；不得出现先验类、分层、臂别、来源等字段；
- 先盲判 → 再与先验对照算一致率；**反过来会系统性高估一致率**（本项目实测：AI 单遍在被提示"低置信是"的点上判是率 100%，独立二审只认 12%）；
- 联系表上不要写"这批是灌丛点/A 臂"之类标题；批次顺序随机或按编号，不按先验类分组。

## 3. 判读执行流程

```
1) prep_points.py      点位质检 + 表单骨架 + 盲判清单
2) fetch_chips.py      高分切片（z18/19，十字丝+目标框）
3) build_sheets.py     2×2 联系表（≤1568 px）+ 批次清单
4) （可选）s2_timeseries.py  生长季多时相 + 指标 → 写入"指标提示"
5) 判读：逐表读，逐点写 [结论 + 实际类别 + 置信 + 证据]
6) qc_protocol.py sample   抽复判/审计批次
7) 复判/审计 → qc_protocol.py review  → 最小复核清单（人工只核这些）
8) merge_stats.py      合并 + 统计 + 报告；points_to_shp.py 出 GIS 版
```

**效率经验**：2×2 表（4 点/张）判读质量最好；3×3 会缩水；单点单独读适合疑难复核。
**判读节奏**：同一区域/同一作物类型的点连续看效率高，但**每 20–30 点插入一次"反例自查"**（回看是否把某类一律判成答案）。

## 4. 质控三率（正式成果必须给）

| 指标 | 算法 | 默认门槛 | 不达标的处理 |
|---|---|---|---|
| 复判自一致率 | 随机 ≥10% + 全部低置信 + 全部无法判读，重判一次，比二值（确认 vs 非确认） | ≥0.90 | <0.90 时复核全部分歧点并扩大复判 |
| "否定"审计准确率 | 各层随机否定点重判，看有多少其实是"确认" | ≥0.90 | <0.90 时否定结论不可用，扩大审计或整体重判 |
| 敏感性 | "推翻当前判定需要多大错判率" = (阈值所需确认数 − 当前确认数)/否定数 | 所需错判率应远大于实测错判率（如 ≥3 倍） | 若两者接近 → 结论不稳健，需加样本 |

**报告口径**（写进报告，不许含糊）：
- "确认率/一致率"是**判读结果**，不是精度；
- 精度必须来自独立于判读源的真值；
- 从训练池/先验产品里抽的点，只能评**标签质量**，不能评成品精度；
- AI 判读标注为"AI 预判读/二审"，并写明"是否经人工复核"。

## 5. 预注册（先写死判据再跑）

任何"要不要采纳某类/某策略"的决策，**先落盘判据**（阈值、样本量、分层方式、抽样种子），再判读；判完不得改判据。
示例（本项目 D2 灌丛裁决）：`真灌丛率 ≥0.70 保留 / ≤0.40 全筛 / 0.40–0.70 折中`——判读前写死，判读后照办。

## 6. 表单字段（标准列）

| 列 | 说明 |
|---|---|
| `point_id` | 唯一键，与点位表一致 |
| `结论` | 正确 / 错误 / 无法判读（**不要用 是/否 之外的近义词**） |
| `实际类别` | 结论=错误或无法判读时填主要地物（用目标体系的类名） |
| `置信（高/中/低）` | 影像清晰+特征典型=高；需旁证=中；勉强=低 |
| `证据（影像特征+日期+辅助指标）` | 见 `地类判读图谱.md` 第 5 节写法 |

**填表禁止**：空证据、把"无法判读"填成"错误"、把实际类别填成"不确定"。

## 7. 常见判读争议的处置

| 争议 | 处置 |
|---|---|
| 灌丛 vs 森林（宽窄定义） | 按"木本高度 + 覆盖度"操作化：<5 m 且灌团占优=灌丛；否则乔木林。争议点单列并给干湿/区域分层统计 |
| 稀疏灌丛 vs 稀疏植被 | 覆盖 <30% 且灌草混合 → 稀疏植被；灌团明显占优（≥30–40%）→ 灌丛 |
| 耕地细分不可判 | 先给"耕地（不确定作物）"，再用时序判；仍不可判就保留大类，不硬猜 |
| 与先验产品大面积冲突 | 不修改先验产品；出"先验 × 判读"混淆表 + 分区叙述，交决策者 |
