## 一、样本数据（核心资产）

### 1.1 GLC 全球提纯样本库（可直接复用于本项目）

| 项目 | 内容 |
|---|---|
| 路径 | `数据/样本数据/GLC_Samples_Grid_2x2/` |
| 规模 | **64,800 个 CSV 文件**（全球 1°×1° 分块），估算总样本量 **约 1.6 亿个点** |
| 中国区估算 | 经度 73–135°E、纬度 17–55°N 范围内约 **3,000 万个点** |
| 字段 | `lon, lat, class, year, tile_id` |
| 类别编码 | GLC_FCS30 原始类别码（10/11/12/20/51…220，共 35 类 + 0 填充值） |
| 基准年份 | **全部为 2020 年**（源自 GLC_FCS30-2020 产品） |
| 提纯方法 | ① GLC_FCS30 2016–2022 七年时序稳定掩膜（min=max）；② 半径 1.5 像元的形态学腐蚀（45 m 内部核）；③ 每 1° 格网分层采样 ≤1000 点（scale=30） |

**对本项目的意义**：
- 这是现成的"2020 年黄金样本底座"，已通过时间稳定性 + 空间纯度双重过滤；
- 但**只有 2020 单年**，生产 2017–2025 逐年产品需要按第 3 章"逐年样本生成"扩展；
- 类别码为 GLC_FCS30 体系（30 类精细系统），与刘良云 GLC_FCS10 分类体系同源，可直接沿用。
