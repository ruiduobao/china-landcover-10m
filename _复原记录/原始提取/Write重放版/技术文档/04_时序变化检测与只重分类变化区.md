# 时序策略：基于嵌入的变化检测与"只重分类变化区"

> **⚠️ 2026-09-05 北京试点实测后路线调整（优先级高于本文）**：PIF 探测证实 **AEF 跨年嵌入存在系统性漂移**（强不变城市点 2024 vs 2017 余弦仅 0.94–0.98，水面 0.87）——本文的"两点变化检测"会把漂移误判为变化，**GEE 内变化检测路线暂不可用**。生产主路线改为**逐年全量分类（实测 ~1840 EECU·h/年，弹药充足）+ 本地时序一致性后处理**（试点平滑 27.7% 像元，证明必要）。本文保留：①嵌入空间变点检测的数学框架（待漂移校正方法成熟后重启）；②CUSUM/PELT/逻辑规则/**HMM 全部移到本地执行**（p7 已落地短波动抑制+城市化不可逆规则，QC 层随产品发布）。
>
> 本专篇响应设计决策：**不做逐年全量分类，改用"变化检测 + 只对变化像元再分类"的时序策略（CCDC 式）**。
> 核心论点：AlphaEarth 年度嵌入（64 维单位向量，2017–2025）**不能直接用 CCDC**，但 CCDC 的"稳定建模 → 偏差告警 → 分段分类"思想可以整体迁移到嵌入超球面上，得到 10 m、无云空洞、语义级的逐年变化检测。
> 关联文档：《02_主技术方案》第 7 章（时序一致性）、《03_高精度样本构建方法论》（CCDC 用于样本稳定性筛选）。

## 1. 为什么不能直接用 CCDC

CCDC（Continuous Change Detection and Classification）的前提是 **Landsat 密集时间序列**：

| CCDC 假设 | AlphaEarth 年度嵌入的现实 | 结论 |
|---|---|---|
| 每像元有每年几十景无云观测（子年度稠密） | 每像元每年只有 **1 个年度合成嵌入**（9 年 = 9 个点） | 无法拟合谐波模型 |
| 输入是有物理意义的反射率，可拟合"年际谐波 + 趋势 + 突变" | 输入是 64 维**语义向量**（无波长物理意义），谐波拟合无意义 | 模型形式不适用 |
| 检测像元光谱轨迹的突变（tBreak/nBreaks） | 检测"语义状态"的跳变 | 目标同构，**手段需换** |

**关键点**：不能用的只是 CCDC 的"谐波拟合算法"，不是 CCDC 的"变化检测思想"。而且嵌入有自己的独特优势——**每年 1 景但无云、无空洞、10 m、语义级**，反而规避了 Landsat 的云污染和 30 m 限制。

> 补充：`Global CCDC V1`（GEE: `projects/gee-ccdc/assets/global_ccdc_v1`，基于 Landsat 的 30 m 变化参数）在本项目**仍然可用**，但只作为**独立交叉验证信号**（就像 SEA-PNF 论文里用它做样本稳定性筛选），不作为 10 m 产品的主变化检测器。

## 2. 三条时序路线对比与推荐

| 路线 | 做法 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| A. CCDC on Landsat | 用 Global CCDC 的 30 m 变化掩膜 → 只重分类变化区 | 成熟、现成 | 30 m 漏掉细碎变化；云区有空洞；与 10 m 产品尺度不匹配 | 仅作交叉验证 |
| B. 逐年全量分类 + HMM 平滑 | 每年独立 RF 分类，再 HMM/Viterbi 修轨迹（SEA-PNF 路线） | 简单、已验证（OA 98%） | 每年全量重分类成本高；时序一致性靠事后修 | 保留为**兜底/基准对照** |
| C. **嵌入原生变化检测 + 只重分类变化区** | 在 64 维超球面上做变点检测，只对变化像元再分类 | 10 m、无云、语义级；**时序一致性由构造保证**；算力省 ~95% | 误差会在未变化区累积，需周期重锚 | **推荐主路线** |

**推荐：C 为主，B 作首年/重锚年的对照，A 作独立验证。**

## 3. 嵌入变化检测的数学基础

记像元 p 的年度嵌入序列为 `V = {v_t ∈ S^63, t = 2017…2025}`（64 维单位向量，分布在 64 维超球面上）。**"土地覆盖变化"等价于"该像元在超球面上从一个语义簇跳到了另一个语义簇"**。

### 3.1 距离度量（单位向量 → 角距离）

- 余弦相似度：`s(v_i, v_j) = v_i · v_j ∈ [-1, 1]`
- **角距离**：`θ = arccos(s) ∈ [0, π]`——超球面上的测地距离，比欧氏距离更适合单位向量；
- 弦距离 `‖v_i − v_j‖ = √(2 − 2s)` 与之单调等价，工程上可用 `‖·‖` 简化计算。

### 3.2 语义参考向量（CCDC"稳定模型"的替代物）

CCDC 给每个像元拟合一条稳定光谱曲线作为"正常模型"。嵌入上，对应的是**该像元的"主导语义状态"**，即序列的 Karcher 均值（超球面几何中心）：

```
r = argmin_{u∈S^63} Σ_t arccos(u · v_t)
```

对"围绕一个主导状态小幅度抖动"的像元（大多数未变化像元），用不动点迭代快速求解：
`r ← normalize(Σ_t v_t)`，迭代 2–3 次即收敛（向量已单位化、且聚集时近似成立）。

### 3.3 偏差序列（CCDC"残差"的替代物）

每个像元得到一条**年际偏差序列**：

```
d_t = arccos(r · v_t) ∈ [0, π]      # 第 t 年偏离主导状态的角度
δ_t = arccos(v_{t-1} · v_t)          # 相邻年语义跳变（年变化图用）
```

- 未变化像元：`d_t` 全年都很小（仅在物候/气候年际波动下小幅抖动）；
- 发生变化的像元：变化年后 `d_t` 出现**持续抬升**（状态跳走后不再回来）。

## 4. 算法设计（CCDC 式的四步）

### Step 1 — 参考构造

对每个像元，用其 9 年向量算 Karcher 均值 r 作为"稳定参考"。（可选进阶：只用"主导簇"——9 年中占多数的语义簇——算均值，避免变化像元被旧状态拉偏参考。）

### Step 2 — 偏差序列

算 `d_t = arccos(r · v_t)`，得到逐年偏差。

### Step 3 — 变化检测（两步：粗筛 + 变点定位）

**(3a) CUSUM 累积和粗筛（抑制年际抖动，类比 CCDC 的"多观测超阈才算突变"）**

对偏差序列做累积和控制图（Page's CUSUM）：

```
S_0 = 0
S_t = max(0, S_{t-1} + (d_t − κ))     # κ=容许漂移(小角度容差)
变化告警：当 S_t ≥ h                    # h=决策阈值
```

- κ 吸收正常的年际抖动，`d_t` 必须**持续**超过 κ 才能累积到 h → 单年尖峰（洪涝、异常物候）不触发；
- 告警年 = **变化年（tBreak 类比）**。

**(3b) 分段变点检测定位（处理多次变化）**

对需要精细定界的像元，在序列上做分段变点检测（PELT / 二分分割，代价函数用角距离），把 9 年切成若干段：`{2017–2019: 状态A} → break → {2020–2023: 状态B} → break → {2024–2025: 状态C}`。这直接对应 CCDC 的"段 + 断点"结构，支持一个像元多次变化。

### Step 4 — 只重分类变化像元，未变化继承

对每个像元，产出一条"状态段"时间线：

- **未变化像元**（整段无告警）：全部年份共用同一标签（来自基准图或该段 RF 分类）；
- **变化像元**：每个状态段用**该段内的嵌入均值** `v̄_seg = normalize(mean(v_t), t∈seg)` 做一次 RF 分类；段内所有年份共用该段标签。

结果：**时序一致性由构造保证**——没有"逐年独立分类再平滑"的假性跳变。

## 5. 生产流水线：基准图 + 只重分类变化区 + 周期重锚

```
[基准图] 2020 年全量 RF 分类（复用已有 2020 黄金样本，最高精度锚定）
    │
    ▼
[前向/后向传播] 以 2020 为锚，向 2017 与 2025 双向推进：
    每步：嵌入变化检测 → 得到本年变化掩膜（通常 <3–5% 像元）
          ├─ 未变化像元：继承邻近年标签
          └─ 变化像元：用本年嵌入均值 RF 再分类
    │
    ▼
[周期重锚] 每 3 年（2019 / 2022 / 2025）做一次全量重分类，
    阻断"未变化区误差累积"，修正基准误差
```

### 效率对比（为什么省 ~95%）

| 项 | 逐年全量分类（路线 B） | 变化检测 + 只重分类（路线 C） |
|---|---|---|
| 每年重分类像元 | 9.6×10¹⁰（全国全量） | 通常 0.5–5%（城市扩张快区更高） |
| 时序一致性 | 靠 HMM 事后修 | 构造保证 |
| 首图精度要求 | 一般 | **极高**（错误会沿未变化区传播） |
| 适配场景 | 快速变化、短周期 | 稳定区占优的逐年长时序（中国多数区域） |

> 中国城市扩张、农业结构调整使部分区域年变化率达 5–10%，但仍远低于全量。变化率高的局部（珠三角、长三角）可按"动态瓦片"策略对高变化瓦片提高重分类频率。

## 6. 关键工程细节

### 6.1 变化检测的"语义粒度"——必须粗于分类粒度

嵌入变化检测应作用在**粗语义（一级类）**层面：只检测"发生了本质性改变"（如农→城、林→农），而**不**把类内变化（如小麦→玉米的轮作、水稻年份丰枯引起的水体扩张）当变化。

原因：年度嵌入是全年合成，物候/气候的年际波动会让"仍是耕地"的像元产生类内嵌入偏移；把这些当变化会导致大量伪变化。实现：把阈值 κ 校准到"一级类间转移"的量级，且变化告警要求偏差**持续多年**（κ 吸收年际波动）。

### 6.2 阈值标定（数据驱动，最关键的一步）

1. **稳定样本**：从《03》提纯样本中取"多年标签稳定"的像元 → 统计其 `d_t` 的经验分布（未变化基准）；
2. **变化样本**：Hansen GFC loss/gain、GHSL 城市扩张、Global CCDC 断点、人工解译变化点 → 统计其 `d_t` 分布；
3. 按**分区（生态区/2°格）× 类组**画 ROC，选阈值平衡变化召回率与误报率（建议假阳性率 ≤1–2%，变化召回 ≥90%）；
4. CUSUM 的 κ、h 同理按分区标定，可在 GEE 内用稳定/变化样本批量求解。

### 6.3 跨年嵌入漂移校正（PIF 伪不变地物法）

风险：若 AEF 各年度嵌入空间存在**系统性年际漂移**，跨年余弦会混入漂移噪声。对策——用**伪不变地物（Pseudo-Invariant Features, PIF）**估计并校正：

- PIF 选取：稳定深水湖泊、戈壁裸岩、永久冰雪等"几乎不可能变化"的像元；
- 估计：逐年算 PIF 嵌入的均值偏移 `m_t`；若 `arccos(m_t · m_ref)` 逐年有系统漂移，说明存在全局漂移；
- 校正：按漂移量对全图嵌入做旋转/归一化校正后再做跨年比较。

> **开工必做**：先在 GEE 里跑一个"PIF 逐年余弦相似度"探测脚本，若相邻年 PIF 相似度稳定 ≈1（如 >0.999），说明 AEF 已做好跨年对齐，无需校正；否则按上述校正。

### 6.4 渐进变化 vs 突变

- **突变**（砍伐、城市化、开垦）：`d_t` 突然跃升，CUSUM 立即告警；
- **渐进变化**（森林退化、灌丛入侵、荒漠化）：`d_t` 缓慢爬升。CUSUM 取小 κ 可累积捕获缓慢漂移；分段变点检测对渐变也能定位转折段。

### 6.5 与独立变化信号的交叉验证

用 **Global CCDC（Landsat 30 m）** 与 **Hansen GFC** 作为独立变化真值，对嵌入变化检测的漏检/错检做交叉统计：两者一致的变化区判为高置信；不一致区（CCDC 报、嵌入没报，或反之）重点人工核查，反哺阈值。

## 7. 与 HMM 时序优化的关系

| | HMM（SEA-PNF 用，路线 B） | 嵌入变化检测（路线 C） |
|---|---|---|
| 定位 | 分类**之后**修轨迹 | 分类**之前**定"哪里/何时变了" |
| 输入 | 逐年分类标签 | 逐年嵌入向量 |
| 输出 | 平滑后的标签轨迹 | 变化掩膜 + 状态段 |
| 关系 | — | **变化掩膜 = HMM 转移矩阵 T 的强先验**（哪里允许转移、哪里禁止） |

**最佳实践**：路线 C 的变化检测结果**直接生成 HMM 的转移矩阵 T 的先验**，或干脆取代 HMM（因为"只重分类变化区"已经消灭了假性跳变）。若仍需 HMM 做最后一道保险，用"变化掩膜约束"版本：HMM 只在变化检测允许的时间/位置允许状态转移。

## 8. GEE 实现要点与代码骨架

### 8.1 内存管理

9 年 × 64 维 = 576 个 float 波段/像元，直接 `toBands` 堆叠内存压力大。对策：**按 1°×1° 瓦片分块**，用 `ee.Image.toArray()` 把 576 波段转成 `[9, 64]` 数组做逐像元向量运算；`shardSize` 调小（256）；`tileScale` 按需上调。

### 8.2 核心代码骨架（GEE JavaScript）

```js
// 0) 加载年度嵌入（2017-2025）
var col = ee.ImageCollection('GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL')
            .filterBounds(tile).filterDate('2017-01-01','2026-01-01');

// 1) 堆叠为 [9, 64] 数组影像（每像元一个 9x64 矩阵）
var stack = ee.ImageCollection(
  ee.List.sequence(2017, 2025).map(function(y){
    return col.filter(ee.Filter.calendarRange(y, y, 'year')).first();
  })).toBands();                       // 576 bands
var arr = stack.toArray();             // 每像元 [576]
var V = arr.reshape([9, 64]);          // 每像元 [9, 64]，V[t] = v_t

// 2) 参考向量 r（Karcher 均值，单位化后迭代1-2次足够）
var meanVec = V.reduce(ee.Reducer.mean(), [0]);   // [64]
var ref = meanVec.divide(meanVec.norm2());        // [64]

// 3) 逐像元偏差序列 d_t = arccos(v_t · r)
var dots = V.matrixMultiply(ref);      // [9, 1]
var dev  = dots.acos();                // [9]，角度偏差

// 4) 变化检测（简化：最大偏差 + 持续超阈）
var maxDev = dev.reduce(ee.Reducer.max(), [0]);   // 标量
var changePx = maxDev.gt(theta);        // 阈值化：是否有过变化
//    进阶：对 dev 序列做 CUSUM/分段，得 change year（tBreak）

// 5) 只重分类变化像元：变化像元用"变化后段嵌入均值"再分类
var segMean = V.reduce(ee.Reducer.mean(), [0]).normalize();  // 简化用全序列均值
var newClass = segMean.classify(rf);    // 分区 RF（64维）
// 未变化像元继承基准图标签
var out = baseline.where(changePx, newClass);
```

### 8.3 产出

| 层 | 内容 |
|---|---|
| 逐年分类图 | `CNLC10_{year}.tif`（变化像元更新、未变化继承） |
| 变化掩膜 | `CHANGE_{year}.tif`（1=变化，含变化方向编码） |
| 变化年份 | `TBREAK_{year}.tif`（首次变化的年份，CCDC tBreak 类比） |
| 质控层 | 检测置信度 / 是否经漂移校正 / 是否人工核查 |

## 9. 变化检测的验证

1. **独立变化点集**：人工解译若干变化区（城市扩张、毁林开垦、退耕还林、湿地变化等），判读"变化前后类别 + 变化年份"，作为变化检测真值；
2. **指标**：变化漏检率（Omission）、误检率（Commission）、变化年误差（±1 年容差）；
3. **交叉验证**：与 Global CCDC、Hansen GFC 的变化做一致性矩阵；
4. **面积校验**：变化面积 vs 国土三调/统计年鉴的变化量（趋势合理）。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 嵌入跨年漂移 | 伪变化激增 | 6.3 PIF 漂移探测+校正；开工先验漂移 |
| 年际物候波动误判为变化 | 耕地/湿地伪变化 | 变化检测用粗语义 + 持续多年告警（κ 吸收波动）；类组阈值 |
| 未变化区误差累积 | 基准错则整条时间线错 | 周期重锚（每 3 年全量重分类）+ 基准图高精度 |
| 变化漏检（渐进变化） | 缓慢退化未捕获 | CUSUM 小 κ 捕获渐变；与 CCDC 交叉验证补漏 |
| 类内变化误报（作物轮作） | 假变化 | 6.1 粗语义检测 + 阈值标定到类间转移量级 |
| GEE 内存/算力 | 数组运算溢出 | 1° 瓦片分块、toArray 逐像元、shardSize/tileScale 调参 |
