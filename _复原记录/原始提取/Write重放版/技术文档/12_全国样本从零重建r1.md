## 1. 背景与动机

旧样本链 v1→v2→v3→v3.1→v4→v5_train 是六版叠加 + 14 个补丁脚本的产物（n8 采样事故 → n14 裁剪 → n15 修复 → n18 重采 → n16/n18_final 两套清洗并存）。用户反复在 by_class 图上看到矩形簇，且旧链存在**结构性缺陷**：

- 类别映射表 3 份互相冲突的拷贝（lc01 本地副本与 lc_conf 不一致）
- 生态规则 3 套互相矛盾（n16 ECO_RULES / n18_final LAT_RANGE / n18_resample ECO_HARD，同一点一边剔一边留）
- 国界裁剪 8 份重复实现、bbox 参数不一
- n16 与 e2_clean 输出同路径互覆，v5 语义不可追溯
- README 计数与实际文件 3 处不符（总点数、园地点数、湿地类名错位）

故推倒重来：**一条统一流水线，从原始数据一步重导**，消灭一切补丁。

## 2. 旧链法证结论（三个实锤错误，r1 全部修复）

### 2.1 GLC_FCS10 层双重缺陷（矩形簇主因）
- **n8 采样器（v4/v5_train 中 21-26 万 FCS10 点的主要来源）**：多次运行叠加（每格类点数均为 15 的倍数）、无国界裁剪（蒙古/俄罗斯点混入）、每格每类等额 15 点（稀有类占 1% 面积也拿满配额）→ 成排 1° 方块。其随机种子用 Python `hash()`，每次运行结果不同——叠加即由此而来。
- **n18"修复版"窗口上限 bug**：8000×8000 像元上限在 10m 分辨率下把 1° 窗口（~1.23 亿像元）判为过大跳过，17,299 点仅覆盖 **73/2,331** 个 1° 格，空间严重偏倚。
- **r1 修复**（s4_fcs10）：全覆盖重采（1,081 格，提升 15 倍）+ **3×3 纯净像元约束**（中心+8邻域同码）+ 面积加权配额（每格全类 ≤80、占比 ≥2% 才采；稀缺类每格 ≤15）+ 固定种子（cx*10000+cy）+ 国界/生态双过滤。注意 GLC_FCS10 瓦片按**左上角**命名（E075N35 = 75-80E, 30-35N）。

### 2.2 GISA 不透水城乡分割错误
- 旧 n4 把 GISA 首城市化"年份索引码"（1-39）直接与 2000 比较 → v4 中 34 万 gisa 点 100% 标为城镇 190。
- 正确语义：**真实年份 = 1971 + 码**；≤2000 首城市化 → 190 城镇，>2000 → 200 乡村。
- r1 实拆：城镇 108,945 / 乡村 40,637。

### 2.3 CN30"中国30米精细地表覆盖"码表错位
- 该产品实为 **GlobeLand30 码系**（10耕/20林/30草/40灌/50湿地/60水/70苔原/80建成/90裸/100冰雪），经已知地点逐点实测确认（青海湖=60、塔中=90、若尔盖=50、阿尼玛卿=100、大兴安岭=20、呼伦贝尔=30、上海=80）。
- 旧 lc14 用 GLC 精细码系查表 → v2-v5 的 cn30 投票列**森林点被投"耕地票"、草地/水体/湿地票全丢**。错票只压低一致度（gold 误降 silver），不抬升错误标签，但层级统计失真。
- **r1 修复**：XW['CN30'] 重写为 G30 码表；底座点直接用 v2_parts/F_cn30 缓存的 raw 值重查表（秒级）；外部点用新表实测。
- 决策：CN30 仅 10 个粗类，不再作样本源，仅作投票员。GALF（实测 ~930m 全球不透水占比栅格，非 30m）同理只作不透水辅助源（frac≥0.6 → GUB 拆城乡）。

**外部点源（s3）**：ESRI 2020（built→GUB 拆分、青藏耕地降权 0.3）、东北作物 60 万、WorldCereal 12.4 万、EGLC 2.8 万、GPW 草地 VHR 7.2 万、GWL 湿地稳定 1.8 万、GISA/GISD、园地 glc12。互斥规则：距底座 <100m 剔除、源内 250m、跨源 100m（稀缺专题源优先保留）。

**投票分层（s5，同 lc15 规则）**：教师=各点自身标签的 level0，票=WC2021/ESRI2020/清华2017/CLCD2020/CN30（G30 码表修正版）。
gold=5 票且非边界带；silver≥4；bronze=3；uncovered=有效票≤3；reject=其余。外部点 tier='external'，agree≥3 才入训练。

**训练集清洗（s6，唯一定义）**：tier 门槛 → 生态硬规则（每类纬度区间 + 区域联合规则）→ 同类最小间距（按类 200-2000m，桶贪心，优先级=tier 权重×src_conf）→ 0.25° 格×类 ≤200 → 国界终检。

**验证池（s7）**：mountains_lc（CCI 码，Conf2020≥2，补国界裁剪）、长三角不透水（GUB 拆 190/200）、新疆 HDLV（2=森林组码 → class_new=-1 + class_group=2，不再混入 30 类码）。
