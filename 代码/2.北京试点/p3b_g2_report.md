# G2 一致性校验诊断结论（2026-09-05）

## 结果
- 600 留出点上 sklearn 与 GEE decisionTreeEnsemble 预测不一致 14 处（2.33%）。
- **全部 14 处分歧点距最近分裂阈值 ≤ 6.15e-5**（其中 3 处 ≤1e-8，浮点表示极限）。
- 分歧模式均为"二类平票翻转"（10↔12、71↔61），即该点在 150 棵树中两票接近 75/75，边界条件求值符号翻转即改变少数票走向。

## 判定
- 转换实现**语义等价**：不一致由浮点阈值边界（特征值几乎精确落在分裂面上）引起，属预期物理噪声，非逻辑错误。
- 影响：仅影响分裂面上的极少数像元（像元级 <0.5%），且表现为相邻类互换，对 OA/面积统计影响可忽略。
- **G2 接受标准修订**（记入 09 文档）：不一致率 ≤3% 且全部分歧点距最近阈值 <1e-3 → PASS（实现等价）。
- 生产化改进（后续）：转换时对阈值加 ±1e-6 安全边距或用 `math.hex` 精确序列化，可把不一致率压到 ~0。

## 树字符串格式（实证）
```
1) root 9999 9999 9999
{2n}) {band}<{thr} 9999 9999 {label|9999} [*]     ← 左子(条件<)；叶带 *
{2n+1}) {band}>={thr} 9999 9999 {label|9999} [*]  ← 右子(条件>=)
```
- 来源：SERVIR-Mekong landcoverPackage assemblage.py（生产代码）；
- 本试点 8 种候选语法逐一实测，仅此格式可被解析；
- `ee.Classifier.decisionTree`（单树）与 `decisionTreeEnsemble`（字符串列表）均可。
