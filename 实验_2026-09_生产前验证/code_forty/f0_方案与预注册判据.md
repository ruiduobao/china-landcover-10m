## 二、处理流程（本地 / GEE 分工）

| 步骤 | 位置 | 脚本 | 说明 |
|---|---|---|---|
| 1. 文件→地理范围映射表 | 本地（E 只读读头） | `f1_map_files.py` | 135,542 行 CSV：CRS/尺寸/原生 bounds/WGS84 bbox/中国标记 |
| 2. 中国文件拷 D 盘 | 本地 | `f2_copy_china.py` | 8,570 文件逐字节校验；E 盘零写入 |
| 3. 既有 160,931 点 × ForTy | 本地（D 副本） | `f3_points_screen.py` | 中心类 + 5×5/11×11 第5类占比 + 11×11 众数（坐标重投影到各文件 CRS） |
| 4. 250 m 块扫描（正/难负/背景） | 本地（D 副本） | `f4_candidates.py` | 每个 25×25 像元块统计类5占比/众数/纯度；一次扫描同时产出三类候选 |
| 5. 配额抽稀 + 去重 + 去自相关 | 本地 | `f5_negatives.py` | 0.005° 去重、距 v7 ≥1 km、0.5° 格上限 200、正负 1:1 |
| 6. ForTy 概率 5 波段 | **GEE** | `f6_gee_features.py --mode forty` | 全部点；已对 v7 160,931 点完成（命中 100%） |
| 7. AEF64 逐年面板（新点） | **GEE** | `f6_gee_features.py --mode aef` | 2017–2024，scale=10，多账号分片 |
| 8. 地形（高程/坡度） | **GEE** | `f6_gee_features.py --mode terrain` | SRTM 30 m，辅助分层 |
| 9. 装配/评/文档 | 本地 | `f7_assemble.py` | v8 样本集 + 前后对比 + 质量指标 |

**性能设计（千万级点/数万级切片）**：① 一切"点×栅格"操作按**文件分块**并行（进程池 6），每进程只开一个 tif、整幅入内存（13.8 MB uint8），点在其 bbox 内批量投影后切片——不做全量拼接、不把点集与栅格同时全量载入；② 候选提取用 250 m 块聚合（13.8 M 像元 → 4.5 万块/文件），只在块级保留统计量，内存 O(块数)；③ Parquet **流式写**（每文件一批），中间件可续跑；④ GEE 侧按 4,000 点/块、多账号分片、块级幂等。

## 三、预注册判据（**先写死，再执行；不得在看到结果后修改**）

### 3.1 现有样本提纯（在 v7 160,931 点上判）

定义：`A1 = p_treecrop/250 ≥ 0.5`（GEE 概率）；`C5 = 本地栅格中心类 == 5`；`CTX = c5_11x11 ≥ 0.3`（110 m 上下文纯度）。

| 子集 | 处置 | 依据 |
|---|---|---|
| `rubber`（三层）、`hainan_official` | **保留**，标 `forty_ok=A1`；`A1=1` 者进"共识核心" | 实测 A1：A_三源 99.9% / B_双源 99.5% / C_单产品 96.7% / 官方 93.8% |
| `multi` | 保留；`A1=1` 进共识核心，否则留作普通档 | 实测 A1 49.3% |
| `apple`、`tea` | **保留但标 `forty_conflict=1`**（不因 ForTy 否定） | 实测 A1：苹果 0.5%、茶 4.6%——ForTy 的树作物类以热带大田块作物为主、2020 单期+有效分辨率偏粗，对温带小地块果园与灌木型茶园的漏检已被其自身文档承认（small patches / canopy threshold / 有效分辨率粗） |
| `anchor` | 保留（目视证据优先于 ForTy） | 实测 A1 12.5%（n=48，亚型以灌木/待判为主） |
| `citrus` | **三源冲突 → 剔除**；仅保留 `A1=1` 的子集（≈4.1%）并标 `citrus_confirmed=1` | ForTy A1 4.1% + 此前影像判读 7.3% + 图面面积 8× 官方统计，三路独立证据同向 |

**判据（数值门）**：
- 提纯后"共识核心"（A1=1 的 rubber/official/multi 点 + 全部保留的 apple/tea/anchor）≥ 90,000 点；
- 剔除量 ≤ 30,000 点（即不做大清洗，ForTy 只做"三源同向"的否决）；
- 若 rubber/official 的 A1 < 85%，则**停止提纯**并报告"ForTy 与中国样本系统性不一致"（实测 93.8–99.9%，已排除该情形）。

### 3.2 扩量（ForTy 类 5 → 新正样本）

- 候选：250 m 块 c5_frac ≥ 0.50 且 valid_ratio ≥ 0.90；
- 去重与隔离：0.005°（≈550 m）每格 1 点；距**既有 v7 点 ≥1.0 km**（防训练/验证泄漏）；0.5° 格上限 200（空间均衡）；
- 目标 **N_pos_new = 120,000**；若候选不足按可用量降级（门槛：≥60% 目标，否则报告）；
- **空间均衡门**：省级最大占比 ≤ 25%；0.5° 格内点数变异系数 < 1.5；
- **循环性声明**：扩量点按 ForTy 类 5 选出，ForTy 一致性**不能**作为其精度证据；新点精度需靠 AEF 可分性与独立目视抽查（计划 150 点 z18 判读）。

### 3.3 负样本（1:1 平衡）

- 难负（hard）：ForTy 森林类 1/2/3 纯块（≥0.70），仅取正样本 0.02°（≈2.2 km）邻域；距正样本 ≥0.5 km、距 v7 ≥1 km；
- 背景（bg）：ForTy 类 6 纯块（≥0.80），排除正样本 0.02° 邻域；距正样本 ≥1 km、距 v7 ≥1 km；
- 各占 50%；总负 = 正（比例 1.00±0.05）；0.005° 去重、0.5° 格上限 200。

### 3.4 精度评价（前后对比）

| 指标 | 定义 |
|---|---|
| 共识率（前） | v7 全体 A1 比例（实测 43.4%） |
| 共识率（后） | v8 提纯集 A1 比例（预期 >90%）；柑橘剔除后必然大幅上升 |
| 分层保留率 | 各 srcset/grade 的保留比例 |
| 新点质量 | AEF64 可分性（新点 vs 难负/背景的 RF AUC，5 折）；150 点目视确认率 |
| 前后对比 | 样本量、A1 率、子集构成、空间覆盖（省数/0.5° 格数）、最小间距分布 |
