## 一、命名规则（从 135,542 个文件反推，已用 georef 校验）

```
raster_<UTM带号+纬度带字母>_<YY>_<row>_<col>.tif
例：raster_49R_20_10_6.tif
```

| 段 | 含义 | 校验证据 |
|---|---|---|
| `raster_` | 固定前缀 | — |
| `<UTM带号+纬度带字母>` | **粗格 = UTM 带（1–60）+ MGRS 纬度带字母（C–X）**，每格约 6°×8° | 例 `raster_49R` 全部文件 bbox 合并 = 107.77–114.27°E、23.91–32.07°N（恰为 6.5°×8.2°）；`raster_48R` = 101.77–108.27°E；同带相邻字母（S）纬度整体北移 8° |
| `<YY>` | 年份两位（全部为 `20` = **2020 年**） | 全库唯一取值 20 |
| `<row>` | 粗格内**行序号**（按投影 Y 从南向北递增） | 例 22T 的 row 16→19 对应 y 5,149,600→5,279,000 m；row 每 +1，y 平移 ≈44,960 m |
| `<col>` | 粗格内**列序号**（按投影 X 从西向东递增） | 例 22T 的 col 1→4 对应 x 266,400→369,920 m；col 每 +1，x 平移 ≈25,840–25,920 m |

- **分块尺寸**：3072×4512 或 2592×4512 像元（随粗格边界裁剪），10 m 分辨率 → 约 **26–31 km × 45 km**；
- **CRS**：各粗格自身 UTM（如 49R=EPSG:32649、10J=EPSG:32710=南半球），**必须先按 georef 重投影再取行列**（本项目 f3 首版曾误用经纬度直接套 transform 导致全量越界，已修）；
- **取值**：单波段 uint8，1–6 类，**255 = nodata**（海洋/无数据）；本包为 GEE 5 波段概率的 **argmax 分类版**（GEE 集合 `forest_typology_2020_v1_0_collection` 135,542 片，与本包文件一一对应）。

## 四、使用约定（本项目）

1. **一切空间查询以 `forty_file_index.csv` 的 bbox 为准**，不要从文件名推断范围（仅能推断粗格）；
2. 点→文件匹配用 bbox STRtree；取像元前必须把点从 EPSG:4326 重投影到该文件 CRS；
3. 候选提取按 250 m 块（25×25 像元）聚合，分块文件之间不重叠（列/行序号连续拼片），无需重叠缓冲；
4. 拼接大图时按 (粗格, row, col) 排序、按 georef 定位，**不要按文件名排序**（col 有 1–5，需数值排序）；
5. E 盘原始数据全程只读；工作副本在 D 盘，处理完成并备份后删除。
