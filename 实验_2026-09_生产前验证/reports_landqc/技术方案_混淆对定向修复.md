# 混淆对定向修复技术方案（2026-10-14，预注册）

> 触发：`大区内类间可分离度报告` 暴露 6 组"最易混类对"。本方案用**常识/生态逻辑**（SAR 结构、植被有无、
> 干旱区异常）对**两端样本**做定向修剪；**只删点，不改类**；**删前全量备份**。
> 脚本：`h1_confuse_evidence.py`（证据）、`h2_calibrate.py`（分布标定）、`h3_fix_rules.py`（判据冻结+删除清单）、
> `h4_apply_fix.py`（备份+执行）｜判据文件：`data/confuse_fix/out/criteria_confuse_v1.json`

## 一、判据（v1，先冻结后执行；实证据标定）

以 **2023 年证据**为准（年匹配）；仅对"交付态"点生效（land 类已剔除 quarantine；沼泽/灌木/园地全量）。
括号内数字＝该分支实际删除量。

| 类 | 删除规则（reason） | 依据（生态/常识） | 删 / 交付 |
|---|---|---|---|
| **草本沼泽** | ① `NDVI夏<200 且 DW bare≥0.30`（BARE_LIKE_FLAT, 601）② `dw_trees_150≥0.30 或 (≥0.15 且 S1 VH冬≥-19dB)`（WOODY_LIKE, 1,631） | 草沼应有植被；像裸滩的删·像木本的删。实测：草沼 NDVI 中位 430 vs 湖河滩地 14（植被有无＝主判据）；木本沼泽 VH冬 中位 -21.1 vs 草沼 -23.2（**冬季雷达差 2.1 dB**，木质结构在冬季保留） | 2,225 / 38,360（5.8%） |
| **木本沼泽** | `dw_trees_150<0.06 且 (S1 VH冬 缺失或 <-23.5dB)`（HERB_LIKE, 1,206） | 两端（光学树概率＋雷达体散射）都判"草"的，从木本沼泽中删 | 1,206 / 10,656（11.3%） |
| **湖河滩地** | ① `NDVI夏≥250 且 DW植被和≥0.15`（VEGETATED_LIKE, 228）② `max_extent=1 且 seasonality≥10 且 DW water≥0.60`（PERMANENT_WATER, 1,666） | 滩地应为无植被消落带：长植被的删、常年水面的删 | 1,894 / 26,507（7.1%） |
| **常绿灌木** | ① `dw_trees≥0.65`（FOREST_LIKE, 10,632）② `dw_grass≥0.25 且 dw_trees<0.20`（GRASS_LIKE, 1,854） | 树概率很高＝实为森林；草概率高且无树＝实为草地 | 12,486 / 61,751（20.2%） |
| **落叶灌木** | ① `dw_trees≥0.50`（5,383）② `dw_grass≥0.30 且 dw_trees<0.15`（1,664） | 同上（阈值按两类分布差放缓） | 7,047 / 113,761（6.2%） |
| **草地** | `dw_trees≥0.40 且 dw_grass<0.15`（SHRUB_FOREST_LIKE, 585；SHRUB_LIKE 分支 0 命中） | 无草信号却强树信号＝非草地 | 585 / 170,653（0.3%） |
| **乔灌园地** | ① `dw_crops≥0.40 且 dw_trees<0.25`（CROP_LIKE, 9,976）② `dw_trees<0.15 且 NDVI夏<400`（NON_TREE_BARE_LIKE, 5,939） | 园地是树木类：像一年生作物的删、无树又不绿的删（实测园地 dw_trees 中位 0.543 vs 灌溉 0.072/旱地 0.078；冬季 NDVI 636 vs 243） | 15,005 / 160,931（9.3%） |
| **稀疏植被** | `NDVI夏<50 且 DW bare≥0.55 且 dw_shrub<0.12`（BARE_LIKE, 3,456） | 无任何植被信号且 DW 判裸＝硬矛盾（比 doc67 的 <40/0.12/0.45 略放宽到 50/0.55） | 3,456 / 47,177（7.3%） |
| **灌溉耕地** | `NDVI夏<250 且（干旱省，含经度守门）`（ARID_BARE_ANOMALY, 638） | 灌溉地块在干旱区不可能这么"秃" | 638 / 124,533（0.5%） |
| **草本旱地** | `NDVI夏≥700 且（干旱省，含经度守门）`（ARID_OASIS_ANOMALY, 5,859） | 干旱区却高绿度＝绿洲灌溉，非雨养 | 5,859 / 203,096（2.9%） |
| **裸地** | `NDVI夏≥250 且 DW 植被和≥0.30`（VEGETATED_LIKE, 33） | 有明确植被的裸地（该规则近似惰性） | 33 / 222,514 |
| **水体** | `max_extent=0 且 DW water<0.30 且 seasonality≤1`（0 命中） | 无任何水证据的水体（重试后仍 0——水体本来干净） | 0 / 67,879 |

**干旱省判定（含经度守门，防半湿润区误删）**：`新疆/甘肃/宁夏/青海/内蒙古/西藏`，
但 **内蒙古仅 lon<112°E**（东部属半湿润）、**甘肃仅 lon<104°E**（河西走廊）。

**首轮草案→v1 的两处修正**（防止过度删除）：① 稀疏植被原阈值（NDVI<80 且 bare≥0.5）会删 48.8% → 收紧到
50/0.55/0.12（实删 7.3%）；② 旱地/灌溉的"干旱省"必须加经度守门（内蒙东部/陇东陇南不是干旱区）。
**合计删除 50,434 点**（跨 12 类，含点重复计入；裸地/水体≈0）。

## 二、执行与备份

- **备份**：`数据/备份/单类样本_混淆对优化前_2026-10-14/<类>/`（受影响的 10 个类目录全部年份 GPKG 原样复制；
  备份后逐文件 sha 可核）。
- **执行**：逐类逐年份 GPKG 删点（几何/AEF 其余字段原样保留；幸存者抽检 20 点；A00 空值必须为 0），
  删除清单留痕 `<类>/删除清单_混淆对修复_<类>.csv`（含 reason 与关键证据列）；
  `逐年质检统计.csv`、`逐年池成员数.csv` 按修复后重算；README 追加修复说明。

## 三、复测（修复效果验证）

对全部受影响类**重跑大区可分离度**（g4 同口径），比较修复前后：重点看各"最难分单元"的 acc_vs_rest 是否上升、
以及"最易混类对"的频次是否下降。结果写入《混淆对定向修复报告》。
