## 1. 先算清楚：哪些环节贵、哪些便宜

GEE 不按 flop 计费，但有**硬性限制**：单次计算的**内存上限 / 时间上限**（超限报 `User memory limit exceeded` / `Computation timed out`）、**每账号并发任务数**、**Drive/Storage 配额**。所以"降计算量"的真正含义 = **更少/更小的批处理任务、更快周转、更省 Drive 配额、更少账号**。

| 环节 | 数据形态 | 成本量级 | 能否本地 |
|---|---|---|---|
| 样本稳定性筛选（标签+CCDC） | 点/小表 | 低（点抽取） | **可本地**（样本已导出） |
| 样本嵌入特征提取 | 30M 点 × 64 维 × 9 年 | **中高（一次性）** | 部分：GEE `sampleRegions` 一次导出 → 本地分析 |
| 样本提纯（原型/马氏/置信学习） | 点表 | 低（点运算） | **可本地** |
| PCA 载荷 / 特征重要性 / 阈值标定 | 点表 | 低 | **可本地** |
| RF 训练 + 调参（160 区 × 9 年） | 点表 | 中（迭代多） | **可本地（sklearn）** |
| 变化检测（9 年 × 64 维全图） | 全图栅格 | **最高** | 必须 GEE，但**降维后做** |
| 全图推理（64 维 RF/原型分类） | 全图栅格 | **高** | 必须 GEE，但**变化优先+特征选择** |
| 时序后处理（HMM/平滑） | 类别栅格 | 低（UInt8） | **可本地（GDAL/numpy）** |
| 镶嵌/重投影/裁剪/压缩 | 类别栅格 | 低 | **可本地（GDAL）** |
| 精度验证（混淆矩阵） | 点表 | 低 | **可本地** |
| PIF 漂移估计 | 千级点 | 极低 | **可本地** |

**结论**：GEE 真正躲不掉的只有两件事——**① 从嵌入集合读取并做全图像元运算（变化检测 + 推理）**。其余全部可以本地。这两件事也正是《04》里最贵的部分，是降本主战场。

## 2. 分工金线：本地 vs GEE

> **金线：这一步是否需要触及"25 TB/年、576 波段/像元"的嵌入全图栅格？**
> - 不需要（只碰样本点 / 类别栅格 / 少量点）→ **本地**；
> - 需要（要读全图嵌入做像元运算）→ **GEE，但最小化**。

```
              ┌─ 样本/标签/点表 ──────────→ 本地（sklearn/pandas/GDAL）
  每一步 ─────┤
              └─ 嵌入全图栅格像元运算 ────→ GEE（降维/级联/特征选择/量化）
```

## 3. 本地化清单（把计算从 GEE 搬出来）

| 计算 | 本地做法 | 从 GEE 省下什么 |
|---|---|---|
| **样本嵌入提取** | GEE `sampleRegions` 一次性导出（子采样后 ~50–100 万点 × 64×9）→ 存本地 Parquet，后续全部分析本地做 | 之后所有重复读取嵌入都免了 |
| **样本提纯** | 马氏距离+卡方、置信学习、kNN 原型过滤，全部 numpy/scipy/sklearn 本地 | 逐点清洗的反复 GEE 调用 |
| **PCA 载荷矩阵** | 本地对样本嵌入求 SVD → 得到 64→K 投影矩阵 W（只上传 W 到 GEE，几十 KB） | 不用在 GEE 里跑 PCA |
| **特征重要性/选择** | 本地训练 RF 得 `feature_importances_` → 选 top-M 波段 | 免去 64 维全量推理的 I/O |
| **RF 训练 + 调参** | sklearn 本地训练（网格搜索、类权重、概率输出），产出决策树结构 | 免去 GEE 里数百次训练调用 |
| **阈值标定（变化检测）** | 本地对稳定/变化样本的偏差分布画 ROC 定 τ/κ/h | 免去 GEE 内调参 |
| **PIF 漂移估计** | GEE 导出 ~1000 个 PIF 点 9 年嵌入 → 本地算逐年偏移 | 免去全图漂移校正试算 |
| **时序后处理（HMM/平滑）** | 导出的 9 年 UInt8 类别栅格（~1 GB）→ 本地 numpy/numba 做 Viterbi/平滑 | 免去 9 期全图在 GEE 的时序运算 |
| **镶嵌/重投影/裁剪/压缩** | GDAL 本地（COG、LZW、Int8、palette） | 免去 GEE 导出后再处理的往返 |
| **精度验证/面积统计** | 混淆矩阵、Olofsson 面积置信区间、省级统计，全部 pandas 本地 | 免去 GEE 统计计算 |

> **一次导出、无限本地复用**：把"样本点嵌入表"导出一次（Parquet），后面的提纯、降维、特征选择、训练、阈值标定、漂移估计**全部免费本地跑**。这是最大的单项节省。

## 4. GEE 侧的算法级降本（不损质量）

必须留 GEE 的只有"全图嵌入像元运算"，用以下五招压缩：

### 4.1 变化检测降维（最大单项节省）

变化检测不需要 64 维全保真——**检测"语义状态是否变了"只需要主成分**。做法：

1. 本地对样本嵌入求 PCA 载荷 W（64→K，K=8~16，解释方差 ≥90%）；
2. GEE 内把每年 64 维嵌入 `matrixMultiply(W)` 投影到 K 维；
3. 在 K 维上做《04》的超球面变化检测（参考向量 + 角距离 + CUSUM）。

**成本**：9 年堆栈从 576 波段降到 9×K（如 9×12=108 波段），**降 5 倍**；且 K 维 Int16 量化后更小。**质量影响**：主成分保留绝大部分语义方差，变化检测（粗语义）几乎不损召回（用独立变化点集验证，见第 7 章）。

### 4.2 级联两阶段（粗筛 → 精分）

```
阶段一（便宜）：K 维降维嵌入 + 原型余弦/KNN 快速粗分类/变化检测
阶段二（贵）：   仅对"变化像元"或"低置信像元"用 64 维全量 RF 精分
```

- 粗筛过滤掉 >95% 的稳定、高置信像元，精分只跑 <5%；
- 粗筛用**原型余弦**（K=30 的矩阵乘，极便宜），精分用 RF（准）。

### 4.3 特征选择（推理 I/O 减半）

本地训练 RF 后，按 `feature_importances_` 取 top-M（M≈20~32）波段，GEE 里只 `select()` 这些波段参与分类。**质量影响**：RF 对冗余维度不敏感，砍掉低重要度波段通常 OA 波动 <0.5%，可先用本地验证集确认不损再砍。

### 4.4 量化（float32 → int16）

嵌入在 GEE 是 float32；对变化检测/粗筛这类对微小数值不敏感的计算，用缩放因子把 K 维投影结果量化为 **Int16**（`round(x*scale)`），内存/带宽减半，余弦相似度几乎不变（单位向量量化误差 <1e-4 量级）。精分阶段仍用原始 float32 保精度。

### 4.5 缓存中间产物为 Asset（一次性成本换复用）

把"降维投影 + 特征选择 + 量化"后的**年度精简嵌入栈**（9 年 × K 维 × Int16）按 1° 瓦片**物化一次存为 GEE Asset**。此后变化检测、粗筛、重分类反复复用这个小数量的资产，不再每次重读 64 维 float32 并重投影。**代价**：一次性的物化导出 + 存储；**收益**：多轮复用零重算。

## 5. 关键技巧：本地训练、GEE 推理

GEE 的 `smileRandomForest` 只能在 GEE 内训练（迭代消耗 GEE、调参不灵活）。解法：**本地 sklearn 训练，把决策树"搬"回 GEE 推理**。

### 5.1 方案一：sklearn → `ee.Classifier.decisionTreeEnsemble`

GEE 支持手工构造决策树集成：

```js
var clf = ee.Classifier.decisionTreeEnsemble({
  features: ['A00','A03', ...],          // 本地特征选择后的 top-M 波段
  trees: [                                // 由 sklearn 树转换而来
    ee.Tree(ee.Dictionary({featureIndex: 3, value: 0.012, 
      left: ee.Tree({label: 12}), right: ee.Tree({label: 10})})),
    ...
  ]
});
```

转换脚本：遍历 sklearn `RandomForestClassifier.estimators_`，读每棵树的 `tree_.children_left/children_right/feature/threshold/value`，递归生成 `ee.Tree`（内部节点 `{featureIndex, value, left, right}`，叶子 `{label}` 或 `{probabilities:[...]}`）。**收益**：训练全部本地（网格搜索、类权重、概率输出、早停都免费），GEE 只做一次推理。

### 5.2 方案二：原型余弦（最廉价推理）

上传各类原型向量 μₖ（本地对提纯样本求 Karcher 均值，K=30 个 64 维向量，作为 FeatureCollection Asset），GEE 内推理 = `argmax_k (v · μₖ)`，即 64 维影像与 30 个原型的矩阵乘。**极便宜**，且是 AlphaEarth 官方推荐的下游范式（嵌入语义空间里"近原型者同类"）。**适用**：粗筛、变化像元的快速再分类；若某类余弦分类精度不足，回落方案一 RF。

### 5.3 方案三：GEE 原生 RF（兜底）

对余弦/迁移 RF 都不达标的少数分区，退回 `ee.Classifier.smileRandomForest` 在 GEE 内训练。三者可混用：**原型余弦做粗筛 → 迁移 RF 做主分类 → GEE 原生 RF 做疑难区兜底**。

## 6. 资源预算表（优化前后对比）

| 指标 | 朴素方案 | 优化后 | 降幅 |
|---|---|---|---|
| 变化检测输入波段 | 576（9×64 float32） | 108（9×12 Int16） | ~10×（含量化） |
| 全图重分类像元 | 每年 9.6×10¹⁰ 全量 | 每年 1–5%（变化区）+ 周期全量 | ~95% |
| 推理波段数 | 64 | 20–32（特征选择） | ~2–3× |
| RF 训练 | GEE 数百次迭代 | 本地 sklearn（免费） | 趋近 0 |
| 样本提纯/调参 | GEE 反复调用 | 本地一次导出后无限复用 | 趋近 0 |
| 时序后处理 | GEE 9 期全图 | 本地 GDAL/numpy（1 GB） | 趋近 0 |
| 需要账号数 | 多（吞吐压力大） | 显著减少 | — |

## 7. 质量不损失的保证与防御性验证

每个降本动作都附"为什么不损精度"+"如何验证"：

| 优化 | 不损质量的理由 | 防御性验证（本地） |
|---|---|---|
| 变化检测降维（PCA top-K） | 主成分保留 ≥90% 语义方差；变化检测只判粗语义 | 独立变化点集上比较 K 维 vs 64 维的召回/误报，差异应 <2pp |
| 级联粗筛+精分 | 粗筛只做"高置信快刀"，低置信/变化像元全部落入精分 | 粗筛的"直接判定"像元抽样复核 OA，应与全量一致 |
| 特征选择 top-M | RF 对冗余维度不敏感 | 本地验证集：top-M 与全 64 维 OA 差异 <0.5pp |
| Int16 量化 | 单位向量量化误差 <1e-4，余弦几乎不变 | 量化前后变化掩膜一致性 >99.9% |
| 原型余弦替代 RF | 语义空间类内聚、类间分离时余弦≈RF | 本地：余弦 vs RF 在验证集上的混淆矩阵对比，差则回落 RF |
| 缓存精简嵌入栈 | 无损（同一数学结果） | 缓存资产与原算结果逐像元一致 |
| 本地训练迁移 RF | sklearn 与 GEE 决策树推理等价 | 本地 sklearn 与 GEE `decisionTreeEnsemble` 对同一样本预测一致 |

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 降维丢信息 → 漏检渐进/细碎变化 | 变化召回下降 | K 取到解释方差 ≥95%（而非 90%）；变化点独立验证，不达标则调 K |
| 本地训练模型迁移 GEE 出错 | 推理错误 | 转换后先在样本子集上对比 sklearn 与 GEE 预测，逐类一致再上线 |
| 缓存资产过期（换分区/换年） | 复用错数据 | 资产命名带版本号与瓦片/年，变更即失效 |
| 粗筛误放行（低置信被判高置信） | 错分累积 | 粗筛置信度阈值保守（宁可多送精分）；周期全量重锚兜底 |
| 本地 Parquet/模型管理混乱 | 复现困难 | 固定目录结构 + 版本号 + 复现脚本（见《01》代码目录规划） |
