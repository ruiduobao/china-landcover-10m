## 一、项目目标与技术路线（最终定型）

**目标**：中国区 2017-2024（2025 待 AlphaEarth 发布）10m 30 类精细年度土地覆盖，对标刘良云 GLC_FCS10（ESSD 2025，OA 83.16%）。

**特征**：Google AlphaEarth Foundations 年度卫星嵌入（`GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`，64 维，10m，2017 起年度）。**关键认知：AEF 嵌入跨年有系统性漂移（PIF 0.87-0.98），两点变化检测不可靠 → 采用逐年全量分类 + 本地时序一致性后处理。**

**分类器**：scikit-learn RF（区域化训练）→ top-24 特征重训 → 转 GEE `decisionTreeEnsemble` 树字符串（rpart 风格）→ GEE 端逐年 batch/交互分类。sklearn→GEE 迁移一致性已验证（边界浮点噪声 2.33%，不影响业务）。

**样本**：多源教师交叉验证 + 生态规则 + 空间抽稀（详见 §二）。

## 二、完整技术流程（七阶段，全部已跑通）

```
【S1 原始资产】GLC_FCS30D 稳定样本网格 64,800 CSV（主教师）
              + 8 类外部点源 + GLC_FCS10 10m 栅格 + 11 个稀缺类专题产品
        │
【S2 r1 样本重建】代码/5.样本重建/（s0-s8，固定种子，零 GEE）
        │   底座重导(849万) → 外部点统一入库(58.6万) → FCS10 全覆盖重采(6.9万,3×3纯净)
        │   → 专题产品采样(2.9万) → 五产品投票分层(917万池) → 训练清洗(299万,30类)
        │   → 独立验证池(2.6万) → 交付(gpkg/图/README 程序化)
        ▼
【S3 嵌入提取】e1_worker.py ×N 账号并行（交互式 sampleRegions，逐块 parquet 断点）
        │   测试已 134/709 块；全国 299 万点约 258 块、2-4h
        ▼
【S4 嵌入空间清洗】e2_clean.py：马氏+卡方(P<0.001 删/0.001-0.01 剪70%) + 原型检查
        │   实测 157 万点 → 139.9 万干净（剔 11.7%）
        ▼
【S5 分区训练】e3_train_zones.py：2° 网格 + 邻区借样 + 分层权重 + GroupShuffleSplit
        │   实测 95 区加权 OA 87.5%（仅 19% 数据）
        │   小区域路线：b1 子集 → p2 提取 → p3 训练（100树） → trees_bj.json
        ▼
【S6 GEE 逐年分类】batch：p5_submit(0.25°瓦任务) + p5b_monitor
        │   交互式（小区域）：p5d_interactive.py（0.05° 分块直下，免排队）
        ▼
【S7 本地后处理】p6_download(分瓦) → p7_postprocess(镶嵌+裁剪+3年投票平滑+城市化不可逆)
        ▼
【S8 精度验证】p8_validate（留出集 OA/κ/UA/PA）+ 独立验证池（r1_validation 2.6万）
```

**区域参数唯一入口**：`数据/本地处理/生产配置.json`（bbox/years/anchor_year/n_trees/train_file/out_dir/task_prefix/region）。全国生产只改此文件。

## 三、踩坑与修复（重大问题全记录）

### A. 旧样本链（v1→v5）的四个实锤缺陷（r1 全部修复）
1. **n8 FCS10 采样器**：hash 种子不可复现+多轮叠加+无国界+等额采样 → 矩形簇主因；v4/v5_train 的 21-26 万 FCS10 点多为污染。
2. **n18_resample 窗口上限**：8000×8000 在 10m 下静默跳掉 96% 的 1° 格（17,299 点仅落 73/2,331 格）——1° uint8 窗口仅 123MB 可整读。
3. **GISA 城乡 bug**：n4 把首城市化索引码(1-39)直接比 2000 → 34 万点全误标城镇；正确：年份=1971+码。
4. **CN30 码表错位**："中国30米精细"实为 GlobeLand30 码系（10耕/20林/30草/40灌/50湿地/60水/70苔原/80建成/90裸/100冰雪，已知地点实测破译）；旧 lc14 用 GLC 码系查表 → 森林投耕地票（只降级不抬错，但层级失真）。

### B. r1 流水线自身修复的问题
5. shapely 2 `STRtree.query` 返回 [点索引, 树索引] 顺序；`query_nearest` 向量输入返回 2×n。
6. GLC_FCS10 瓦片**左上角命名**（E075N35 = 75-80E, 30-35N），按右下角理解会全部跳格。
7. **pandas 元组索引对齐陷阱**：`set_index` 后 reindex/赋值回 RangeIndex 静默全 NaN（v2 投票列 join 全空 → 底座全 reject）；修复=`.to_numpy()` 绕过对齐。
8. 清华分省 tif 为 float32 且各省 bbox 重叠 → 采样入口 cast uint8 + 点按省界多边形唯一归属（防邻省 nodata 后写覆盖）。
9. 底座点 cn30 票从 v2_parts/F_cn30 的 raw 值按 G30 码表重查（不重读 7GB 栅格）。
10. **盲区类规则**：五产品无湿地/灌丛细分图例 → 120/121/180-186/140/91/92 的 uncovered≠错标，保留仅剔 reject；专题产品点豁免 agree≥3 门槛（一致度 0.57 属正常）。
11. 沿海滩涂点省界外 → `query_nearest` 就近归属兜底（5.66 万点）。
12. **GPKG 写 SMB 网络盘极慢**（30 分钟 25MB）→ F 盘本地暂存写完整体拷回（122 秒完成全部交付）。
13. 门禁 NN 检查 km/m 单位笔误（cKDTree 建在 km 上）——数据健康，检查代码错。

### C. GEE 平台与工程问题
14. **Windows 凭证隔离**：HOME+USERPROFILE 必须双设；**ee 全局态禁止进程内切换账号**（多账号=每账号独立进程）。
15. batch 并发=账号级 1；PENDING>2 天可能被废弃；RUNNING 真卡死则 cancel 重提。
16. **batch vs 交互式的适用边界**（本次新实证）：
    - 交互式 getDownloadURL：像元边 ≤32768；总包 ≤50MB；**表达式含 100+ 棵树分类时块必须 ≤0.05°**（0.1°/0.25° 触发 User memory limit）；高频请求触发 429/503 → 3s 间隔+退避重试（15/30/45s…）后稳定。
    - batch：无内存限制但排队不可控（8 任务 READY 25 分钟未启动）。
    - 经验：小区域/流程验证用交互式 p5d；全国用 batch p5。
17. 树字符串格式（rpart 风格）：`1) root 9999 9999 9999` 头，`N) band{<|>=}thr 9999 9999 label[*]`，左 2n 右 2n+1。
18. AEF 年度集合 UTM 多瓦片必须 mosaic（first() 静默丢 98%）；下载上限 50MB → 0.25° 分瓦。
19. 代理 socks5h://127.0.0.1:7890（http:// 前缀必死）；晚高峰偶发断连整夜。

## 四、获得的新认知

1. **样本质量 > 模型调参**：r1 清洗后北京留出 OA 91.65% vs 旧样本 90.11%（+1.54pp），端到端验证了"标签修正+纯净像元+生态规则"的价值。
2. **嵌入自带的类间结构极强**：64 维嵌入 + RF 即可 87.5%（19% 数据自验），无需任何光谱指数。
3. **五产品投票是廉价高效的质检器**：一致度分层 + 盲区类豁免的规则设计，让 917 万池自动析出 299 万可靠训练集。
4. **稀缺类的正确打开方式是专题产品**：GMW/海岸湿地/盐沼/苹果/柑橘/茶园等开放产品（全部 CC-BY）补齐了通用产品的结构性盲区。
5. **逐年分类+时序一致性优于变化检测**：在嵌入漂移现实下，"全量分类+本地 3 年投票平滑+城市化不可逆"是稳健且便宜的组合。
6. **降耗三件套**（陆地掩膜 -15~25%、top-24 特征 -20~35%、树 150→100 -20~30%）合计可把全国 8 年从 ~13,400h 压到 ~7,000-9,500h，且留出集验收 ΔOA≤0.44pp。
