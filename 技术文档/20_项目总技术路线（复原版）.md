## 一、项目目标与技术指标

| 项 | 内容 |
|---|---|
| 目标 | 中国 2017–2024 年 10 m、30 类精细年度土地覆盖（2025 待 AlphaEarth 2025 嵌入发布） |
| 对标 | 刘良云 GLC_FCS10（ESSD 2025，全球 OA 83.16%） |
| 特征 | Google AlphaEarth Foundations 年度卫星嵌入 `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`，64 维（A00–A63），10 m，2017 起年度 |
| 分类器 | scikit-learn 随机森林（2° 分区训练）→ top-24 特征重训 → 转 GEE `ee.Classifier.decisionTreeEnsemble`（rpart 风格树串）→ GEE 端逐年分类 |
| 最终精度（独立验证） | **OA 0.7943 / macro-F1 0.6077 / balanced accuracy 0.6048**（8 年汇总 n=29,831，空间块留出，30 类；2026-09-09 第二次更正后重跑） |
| 已实证的保守精度 | 北京小窗口 8 年像元级 OA 86.81%（κ 0.757）；点级 86.3% |
| 算力预算 | 8 年全量 ~12,000–15,500 EECU·h（降耗三件套后 ~7,000–9,500）；缺口约 10% |

**核心路线决策（已实证）**：AEF 嵌入跨年存在系统性漂移（PIF 实测 0.87–0.98），
两点变化检测不可靠 → **采用"逐年全量分类 + 本地时序一致性后处理"**，而非变化检测继承。
（变化检测 vs 逐年分类对比实验：未变化像元 L2 中位 0.22 vs 变化像元 0.25，分布重叠、
TNR 仅 0.51–0.52；CD 继承版虚警 8 倍 —— 结论：逐年分类胜，维持现行路线。）

| 阶段 | 产物 | 关键结果 |

| P2 年度嵌入提取（`e1b_*`） | `chunks_index_r7.parquet`（14,272,711 point-years / 4,758 块×3,000） | 12 账号编队 + 指纹差异化，断点续跑 |
| P3.1/2 年度 QC（`e2b_yearly_qc_f.py`） | `sample_year_qc.parquet`（566 MB）、八套 `r7_train_{2017..2024}.parquet` | keep 94.41% / downweight 4.00% / exclude_year 1.52% / persistent_change 0.07%；年度子集 1.53M–2.13M |
| P3.3 稀有类补样（`r8/r8b/r9/e1c/e7`） | `r7_rare_samples.parquet` | 初版 91/140/183/184 各补到 2,000（4,677 点）；**经省级白名单复检，剔除错位 1,800 点 → 终版 2,877 点**（140 仅存 194），失衡比实际 **≈2,295×**（121 vs 140），精度优先未回补 |

**年度 QC 四态判定规则**：① 有效性（有限值且 norm>1e-6）；② 逐类×年类心余弦，按类内 P01/P05 分位；
③ 相邻年 L2 的逐类×年 robust z-score（median/MAD×1.4826）；④ `exclude_year`=无效/类心 P01 以下/单年突变；
`downweight(0.5)`=类心 P01–P05；`persistent_change(0.3)`=相邻两年 z>5；权重 `w = w_tier × w_qc × (0.7+0.3·src_conf)`。

**年度评估结果（空间块留出）**：2017–2021 OA 0.836–0.863，**2022–2024 降至 0.719–0.728** —— 标签年份错配风险在数据上可见，八套年度子集即为按年隔离此问题而建。

## 六、分类与全国生产

### 6.1 配置驱动（全国只改一个 JSON）
唯一入口 `数据/本地处理/生产配置.json`：`bbox / years / anchor_year / n_trees / train_file / holdout_file / out_dir / task_prefix / region`。

### 6.2 北京小窗口 8 年试验（路线可行性已验证）
- 链路：`b1 子集 → p2 嵌入 → p3 训练(100树) → p5d 交互式分年下载 → p7 时序一致性 → p8 验证`。
- 结果：像元级 **OA 86.81%、κ 0.757**；点级 86.3%；三档精度 64维 0.8902 / top-24 0.8858 / 留出(已知类) 0.9165。
- 最大混淆：**12 水田 ↔ 10 旱地**（12 的 PA 仅 0.488）；200 全部并入 190。
- **降耗三件套实测有效**：陆地掩膜 −15~25%、top-24 特征 −20~35%、树 150→100 −20~30%（ΔOA≤0.44 pp）。

### 6.3 GEE 逐年分类（batch 为主，交互式为辅）
- batch `p5_submit.py`(0.25° 瓦任务) + `p5b_monitor.py` + `p5c_poll.py`；0.25° 分瓦约 250–350 任务/8 年；队列深度 ≤2–3 仓/账号（PENDING >2 天可能被废弃）。
- 交互式 `p5d_interactive.py`：像元边 ≤32768、总包 ≤50 MB；**含 100+ 棵树分类时块必须 ≤0.05°**（0.1°/0.25° 触发 User memory limit）；429/503 退避 15/30/45s×6 + 块间 sleep 3s；配额耗尽可 `argv` 传账号换号续跑。
- 树串格式：`1) root 9999 9999 9999` 头，`N) band{<|>=}thr 9999 9999 label[*]`，左 2n 右 2n+1；sklearn→GEE 迁移一致性验证通过（边界浮点噪声 2.33%）。

### 6.4 本地后处理（`p7_postprocess.py`）
分瓦下载 → 镶嵌裁剪 → 3 年投票平滑 → **城市化不可逆修正**（北京试验修正 861 万像元）。

## 八、踩坑总清单（必守）

### 几何/坐标
1. `rasterio.rowcol` 返回 **(row, col)**；numpy ≥2 多值 rowcol 返回 float64，须 `.astype(np.int64)`。
2. GLC_FCS10 瓦片按**左上角**命名（E120N40 = 120–125E, 35–40N），勿按文件夹下缘判断。
3. 国界裁剪必做（`s1_geom.py` + `china_100000_full.json`）；bbox 裁剪会带入约 70 万境外点。

**结论三点**：
1. **FCS10-2023 派生样本（120/121 灌丛为主，62.4 万点）跨年使用毒性实锤**：
   2022/2024 上这些点的评估精度仅 ≈0.49（由基线与实验臂加权反推）——近乎随机；
   且把它们从 2024 训练中拿掉（训练量 2.11M→1.50M）后，剩余样本精度反升 11.7pp——它们在主动污染决策边界。
2. **"年度下探"主要是 FCS10 系评估点拖累**：非 FCS10 样本在 2022/2024 高达 0.85–0.87，
   产品真实质量显著好于汇总数字；论文里应分来源报告精度。
