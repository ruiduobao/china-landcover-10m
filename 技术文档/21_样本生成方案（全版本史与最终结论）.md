## 一、目标与样本体系设计

**目标**：中国 2017–2024 年 10m、30 类精细土地覆盖（对标刘良云 GLC_FCS10，ESSD 2025 全球 OA 83.16%）。
**特征**：Google AlphaEarth Foundations 年度嵌入（64 维，10m）。
**样本的定位**：样本 = 模型学习的唯一监督来源；样本质量决定产品上限。

**样本体系的三层设计（本项目自 r1 起确立）**：

| 层 | 内容 | 作用 |
|---|---|---|
| 标签层 | `class_new`（30 类）+ `src`（来源）+ `src_conf`（来源置信度） | 学什么 |
| 时间层 | `valid_from` / `valid_to` / `qc_scope` + 逐年 QC 状态与权重 | 哪一年可用 |
| 空间层 | 国界裁剪、省界白名单、生态规则、同类最小间距、格网配额 | 在哪里可信 |

## 二、版本演进的完整历史

### 2.1 旧链时代：v1 → v5（2026-08 至 09-06，已废弃归档）

| 版本 | 做法 | 规模 | 发现的问题 | 为什么继续优化 |
|---|---|---|---|---|
| v1 | GLC_FCS30D 全球样本网格中国区提取 + GUB 城乡拆分 | 849 万 | 来源单一 | 扩展外部源 |
| v2 | 六产品采样 + 五产品投票 + CLCD 稳定列 → 置信分层 gold/silver/bronze/uncovered/reject | 849 万（gold 47.3 万） | 教师覆盖不均 | 引入 10m 教师 |
| v3/v3.1 | + GISA/GISD 不透水、GWL 湿地、WorldCereal、东北作物、EGLC | 908.6 万 | 园地仅 632 点 | 补 10m 教师 |
| v4 | + GLC_FCS10 2023 本地采样（园地 2→3.2 万）+ ESRI 全国年度 2017–2021 | 1022.3 万 | **矩形簇污染** | 需回查采样器 |
| v5 | 三重过滤：生态硬规则 + 500m 同类最小间距 + 0.25° 格配额 | 273.8 万 | 保留率仅 26.8% | — |

**旧链四大实锤缺陷（新链全部规避，教训入档）**：
1. `n8` FCS10 采样器：hash 种子不可复现 + 多轮运行叠加 + 无国界 + 等额采样 → **矩形簇主因**；
2. `n18_resample`：8000×8000 窗口在 10m 下静默跳掉 96% 的 1° 格；
3. GISA 城乡 bug：首城市化索引码（1–39）直接比 2000 → 34 万点全误标城镇（正确：年份 = 1971 + 码）；
4. CN30 码表错位：该产品实为 GlobeLand30 码系，旧代码按 GLC 码系查表 → 森林投耕地票。

### 2.2 r1 从零重建（2026-09-06/07）

**动机**：旧链补丁叠加、不可复现。**决策：从 0 重造全国样本，统一性与正确性优先。**

新链路 `代码/5.样本重建/`（s0–s8，固定种子、零 GEE、逐阶段审计）：

```
s2 底座(GLC_FCS30D 7年稳定 + GUB 城乡)          → 849.2 万
s3 外部点(ESRI/专题源)                          → +57.8 万
s4 GLC_FCS10 全覆盖重采(3×3 纯净像元)            → +6.85 万
s4b 稀缺类专题产品采样                           → +2.9 万
s5 五产品投票分层(盲区类豁免/专题源豁免)          → 917 万池
s6 训练清洗(生态硬规则 + 同类间距 + 格配额)       → 299 万
s7 独立验证池                                    → 2.56 万
s8 交付(gpkg/图/README 程序化生成)
```

**r1 终态**：pool 9,174,744 / train 2,991,161 / validation 25,644。
**关键机制**：①盲区类 BLIND_CLASSES（120/121/湿地亚类/91/92/140）保留 uncovered 只剔 reject；②专题产品豁免 agree≥3；③CN30 票用纠正后码表重查。

**遗留问题**：120/121 灌丛被统一 1000m 间距抽稀成碎片；62 疏闭落叶阔叶、92 疏混交林样本不足。

### 2.3 r2：提质尝试 → 暴露 trans 层污染（2026-09-08）

**做法**：①水田加权（WorldCereal irrigation_status 实测全空→改用东北 ne_crops 水稻 30,074 点）；②FCS10 过渡带加密（605 个林/灌草共存 1° 格）；③120/121 按类自适应抽稀修复；④SDPT V2 树种融入（中国区 232 万种植园多边形）。

**结果**：train 2,409,193。**但引入致命污染**：过渡带层（`glc_fcs10_2023_trans`，池内 376.8 万点）被错误加入投票豁免名单 → 绕过 agree≥3 门槛。华北平原草地样本 95% 来自该层；独立投票实证 CLCD 60% 判耕地、CN30 66% 判耕地。

**教训**：任何新样本源必须过同一投票门槛；专题豁免只适用于产品图例盲区的类。

### 2.4 r3：剔除污染层（2026-09-08）

整体剔除 trans 层；SDPT 走投票门槛（10,956 点补票后保 49%）；保留按类自适应抽稀。
**r3 终态**：train 1,630,806 / pool 9,180,149。华北平原草地 12,488 → 3,411。

### 2.5 r4：灌丛硬边界修复（2026-09-08）

**现象**：云南/广西/甘肃出现"线一侧有点、另一侧全无"的硬边界。
**法证两条根因**：①盲区规则 × 产品覆盖不均（有无票源决定去留）；②**FCS30D ↔ FCS10 灌丛谱系分歧**（我们 120 点 89.8% 被 FCS10 判常绿阔叶林）。
**修复**：120/121 整体替换为 FCS10 2023 全国纯净像元重采（raw121→120、raw120/122→121，689,435 点）；其他盲区类改"FCS10 同位置一致才保留"。
**r4 终态**：train 2,152,624；120=110,223、121=400,589。

### 2.6 r5 → r6/r7：缺失带补采与定稿（2026-09-08）

- r5：E 盘 FCS10 缺 E130–E135 带 → 中国最东部形成 130°E 直线截断补齐（145,359 点）；
- r6/r7：合并缺失带、门控/生态复核、自适应抽稀（`r7_clean.py`）。
- **r7 终态（交付版）**：pool 9,646,715 / **train 2,241,785** / validation 25,644。

### 2.7 年度适用性改造 P0–P3（2026-09-09，评审驱动）

**评审核心意见**：r7 工程质量不错，但直接用于 2017–2024 逐年分类有四类风险——标签年份错配、来源依赖、类别失衡、验证泄漏。**结论：不推倒重建，把 r7 当母库，叠加年度适用性层。**

| 阶段 | 产物 | 关键结果 |
|---|---|---|
| P0 基线诊断 | 样本诊断 9 CSV | 12 类单源占比 >94%；1°格全覆盖（3,685 格，比率 1.014）；50km Gini 0.277；**验证池 99.6% 距训练点 <5km（中位 1.1km）= 空间泄漏** |
| P1.1 标签有效期 | `r7_train_validity.parquet` | 底座 2017–2024；FCS10-2023 系 2022–2024；2020 专题 2019–2021；东北作物原年 |
| P1.2 验证池重构 | `validation_pool_v2.parquet` | 25km Albers 块整块留出 + 块内侵蚀 5km → 结构性保证 ≥5km 隔离 |
| P1.3 三套分布 | `class_balance_design.json` | 四大类截顶 15 万（224万→172万）；稀有类缺口登记 |
| P2 年度嵌入提取 | `chunks_index_r7.parquet` | 14,272,711 point-years / 4,758 块 × 3,000 点，12 账号编队 |
| P3.1/2 年度 QC | `sample_year_qc.parquet` + 八套年度子集 | keep 94.41% / downweight 4.00% / exclude_year 1.52% / persistent 0.07% |
| P3.3 稀有类补样 | `r7_rare_samples.parquet` | 91/140/183/184 定向补样 |
| P3.4 空间独立评估 | `评估_P3.4/` | 修复泄漏后 OA 0.7923（虚高前 0.987，虚高 19.5pp） |

**关键教训**：修复空间泄漏后 OA 从 0.987 掉到 0.79 —— 任何"高精度"结论必须先验证验证池的空间独立性。

### 2.8 第二次更正：错位样本剔除（2026-09-09）

用户复核分布图发现 **140 地衣苔藓大量出现在上海/浙江/江苏**。核查属实：FCS10 在东部湿润区把**养殖塘/潮间带错标为 140**（1,806 点）、**长江中下游淡水湖错标为 183**（148 点）。
**处置**：新增省级白名单硬规则 `ECO_PROVINCE` + `s1_geom.province_violation`；剔除 1,959 点（基线 159 + 补样 1,800）；`r7_rare_samples` 4,677 → 2,877；精度优先，未按数量回补。
**母库同步修复**：新增显式 `row_id` 列 + 删除 159 基线违规点 → 2,241,785 → **2,241,626**（`r11_fix_motherlib.py`）。

### 2.9 Z 盘事故与复原（2026-09-11/12）

Z 盘格式化导致项目目录损毁。技术路线与代码从 ZCode 会话库重放复原（147 文件）；样本实物从 F 盘暂存抢救；嵌入块 862/4,758 幸存于 `F:\r7_prod`。

### 2.10 生态规则修订与二次清洗（2026-09-12）

**一键质检脚本 `e10_sample_qa.py`** 上线后立刻暴露两批问题：

1. **规则版本错位（35,010 点洗清嫌疑）**：复原版 `s0_conf` 的 ECO_LAT 是"计划修订但从未落地"的旧值。落地 3 处修订后，12 万灌丛/海岸点恢复合法（这些不是样本错误，是规则未同步）。
2. **真实生态违规 8,993 点剔除**：51 郁闭常绿阔叶林 1,831（>34°N）、71 郁闭常绿针叶林 7,136（>48°N，阿尔泰/北疆老师错标）、183 4、184 22。
   **母库 2,241,626 → 2,232,633**；剔除清单累计 11,076 条。

同时修复 **e2b 幽灵行缺陷**：元数据 left-merge 使已出库的点以 NaN 元数据混入子集（每年约 8,300 行）→ 改 `valid_from.notna()` + inner join。

**修复后评估**：**OA 0.8034 / macro-F1 0.6260 / bal-acc 0.6168**（n=31,468）——较原终版 0.7943 **+0.91pp**。

### 2.11 A/B 实验：FCS10 跨年毒性实锤（2026-09-12）

**假设**：2022–2024 精度下探（0.74 vs 0.86）由 FCS10-2023 标签跨年使用导致。
**设计**：62.4 万 FCS10 系样本收紧为 2023 单年 vs 现行跨年。

**结果**：

| 年份 | 基线（跨年） | 实验臂（限 2023） |
|---|---|---|
| 2022 | 0.7514 | 0.8708 |
| 2023（本命年） | 0.7389 | 0.7461 |
| 2024 | 0.7371 | 0.8538 |

**但要正确解读**：实验臂同时改变了验证集组成（FCS10 系验证点被排除），因此不能简单说"精度从 0.74 提升到 0.87"。严谨结论是：FCS10 系样本的时间适用性不足。

### 2.12 B 方案实施与来源分层证据（2026-09-13，当前版本）

**用户决策：采用 B —— 跨年保留但降权 0.5**（不与全国生产的覆盖需求冲突，同时抑制毒性）。

**实施**：e2b 权重公式增加因子：
```
train_weight = tier权重 × qc权重 × (0.7 + 0.3·src_conf) × B因子
B因子 = 0.5  若 src 含 fcs10 且 year != 2023
      = 1.0  其他
```
**作用范围**：1,227,435 point-years（2022: 615,296 / 2024: 612,132 / 2021: 7）。
**加权点总数**：10,636,264 → 10,234,156。

**新增来源分层评估（e6 补丁）**，在相同的验证点上分别统计：

| 来源 | n | OA | macro-F1 | balanced-acc |
|---|---|---|---|---|
| **FCS10 系** | 3,031 | **0.5104** | 0.308 | 0.482 |
| **非 FCS10** | 6,608 | **0.8326** | 0.714 | 0.693 |

（2022+2024 合并口径）

**这是本项目最关键的一条样本质量证据**：在同一批年份、同一批空间块留出验证点上，模型对**非 FCS10 标签**的精度达 83.3%，而对 **FCS10 派生标签**只有 51.0%。**亏损不在模型，而在标签本身。**

**B 方案实施后的完整结果（8 年，25km 块留出，n=31,468）**：

| 年份 | B（跨年降权0.5） | 参照：C（降权前） |
|---|---|---|
| 2017 | 0.8616 | 0.8616 |
| 2018 | 0.8655 | 0.8655 |
| 2019 | 0.8528 | 0.8528 |
| 2020 | 0.8563 | 0.8563 |
| 2021 | 0.8423 | 0.8423 |
| 2022 | 0.7375 | 0.7514 |
| 2023 | 0.7389 | 0.7389 |
| 2024 | 0.7250 | 0.7371 |
| **汇总** | **OA 0.7996 / macro-F1 0.6187 / bal-acc 0.6101** | OA 0.8034 / macro-F1 0.6260 / bal-acc 0.6168 |

**如何解读 B 的聚合 OA 略降（−0.38pp）**：这是"标签噪声主导"的典型症状——FCS10 系验证点的标签本身只有约 51% 正确，任何训练侧调整都救不回它们，而这些点又占了 2022/2024 验证集的 1/3。因此：
- **聚合 OA 不是衡量 B 优劣的正确指标**；正确指标是**非 FCS10 验证子集上的表现**（B 下 0.8326，与降权前同量级），以及生产制图上灌丛区域不再被错误标签牵引；
- **论文与交付必须按来源分层报告精度**（e6 已内置该分层），否则汇总数字会被标签噪声主导，既低估产品真实能力、也掩盖问题本身。

## 四、下一代方案的检验标准（已固化）

### 4.1 样本级硬门槛（每次生成必过）

```
国界外点 = 0 ；省界白名单违规 = 0 ；生态规则违规 = 0
非法坐标 = 0 ；重复 row_id = 0 ；显式 row_id 缺失 = 0
```

### 4.2 空间门槛

```
50km 等面积格 Gini < 0.35
主要一级类适生网格覆盖 ≥90%；稀有类适生生态区覆盖 ≥70%
同类 NN 中位 ≥500m（带状类如 184/185/186 改用海岸段分层 + 1–5km 格网配额）
训练/验证空间距离 ≥5km
```

### 4.3 年度适用性门槛

```
单年 exclude_year > 5%  → 触发复核
persistent_change > 2%  → 触发复核
FCS10 系与非 FCS10 系 OA 差异 > 5pp → 必须分层报告
```

### 4.4 评估口径（唯一）

```
validation_pool_v2（25km Albers 块留出 + 块内侵蚀 5km）
报告：总体 OA / macro-F1 / balanced-acc / 30 类 UA-PA-F1
     × 分年 × 分生态区 × 分来源（FCS10 / 非FCS10）× 稳定区/变化区
     + Olofsson 面积置信区间（制图后补算）
```

## 六、结论

1. **样本质量已从"能跑"升级为"有明确质量控制逻辑"**：三层体系（标签/时间/空间）+ 一键质检 + 空间独立验证 + 来源分层报告。
2. **当前最佳版本 = B 方案版本**：母库 2,232,633 点、0 硬违规、空间独立评估 OA 0.8034（非 FCS10 区 0.833）。
3. **最重要的方法论结论**：**报告精度必须按标签来源分层**。FCS10 系验证点自身标签准确率仅约 51%，把它们混入总体 OA 会同时低估产品能力、掩盖真实问题。
4. **后续改进重心**不在数量，而在：①稀有类的高置信人工解译（140）；②带状湿地的海岸段均衡（183/184/185）；③森林结构与园地亚类（91/52/11）；④水田的 SAR 时序特征（12）。
5. **技术路线已验证可复现**：e0b 有效期层与幸存版本 MD5 逐位一致；全链（e0→e2b→e7→r10→e6→e8/e9）一次跑通，随时可重跑。
