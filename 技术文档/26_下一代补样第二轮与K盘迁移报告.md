### 2.1 过程中修掉的真错

1. **shrub 门槛本来全中国零命中**：原判据 `WorldCover==灌丛(20) ∩ Dynamic World 灌草概率>0.5` —— 实测全中国**一个像元都不剩**。诊断：WorldCover 把北方灌丛大量标成草地(30)/裸地(60)（WC==20 仅占 0.3%），DW 的 `shrub_and_scrub` p60 中位只有 0.128、p99 仅 0.421（>0.5 占 0.1%）。
   **修正为四证联合**：`DW>0.25（p90 水平）∩ WC∈{20,30} ∩ 0.3<GEDI rh98<5 m（矮木本的物理判据）∩ NDVI<0.62`，通过率 3.6–4.2%，四个来源相互独立。重扫后非空 parcel 从 **0 → 177**。
2. **GEDI 大区域超时**：`GEDI02_A_002_MONTHLY` 取 2020–2023 四年窗，在 2° parcel 上计算量放大 4 倍，分片 420 s 看门狗连续超时。收窄到单年（2021）后正常。
3. **`ee.Image` 没有 `.isin()`**：要用 `.eq(a).Or(.eq(b))`。
4. **ng6 的 row_id 起点必须动态**：第二轮若仍从 12,000,000 起会与第一轮撞号 —— `ng8` 的冲突保护拦下来了（这正是它存在的意义），改为"母库最大 row_id + 1"。
5. **同名快照目录会被覆盖**：`母库_并入下一代前_20260914` 被第二轮覆盖过一次 → `make_snapshot_ng.py` 改为同名时追加时刻。

**这是本轮最重要的诚实结论**：
**补样对 `12 / 121 / 186 / 201 / 202 / 220 / 150 / 185 / 184` 这类"样本原本就够、或补后够"的类有效**（F1 0.61–0.98，属可用区间）；
但 **`91 / 140 / 52` 即使本轮分别新增 1,978 / 1,455 / 1,673 个训练点，模型仍然几乎不预测它们**（n_pred 仅 4 / 4 / 9）。说明这三个类的瓶颈**不是训练样本数量，而是特征可分性**：
- 91 与 71/72/61/62 在 64 维嵌入空间高度重叠（针阔混交本身就是光谱混合体）；
- 140 与 150/201 重叠（稀疏植被/裸地/地衣苔藓在嵌入上接近）；
- 52 与 51/61 重叠（疏林/郁闭林边界）。

**下一步应做的是"加特征"而不是"加样本"**：91 需要针叶比例与物候振幅的组合特征（已在门槛里用，但训练特征仍只有 AEF 64 维）；140 需要红边/短波红外；52 需要郁闭度。此外这三类的验证点只有 19–46 个，指标本身噪声极大，**不适合作为论文主结论的依据**。
