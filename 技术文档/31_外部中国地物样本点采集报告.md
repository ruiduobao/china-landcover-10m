## 三、⚠️ 决定性检验：这些物种点能不能当地类样本？

三个来源本质都是**物种分布**，不是土地覆盖标签。我做了两层检验。

### 3.1 空间一致性检验（用母库 225 万点建 KD 树）—— 无效判据

20 个组的"最近母库点地类构成"**几乎完全一样**（190 城镇 20–30%、121 灌丛 15–23%、森林 7–15%）。
→ 这不测地类关联，测的是**采集可达性**（标本点/观测点集中在城市与路边）。且仅 0.2–1.3% 的物种点在母库点 100m 内（母库太稀，判据不成立）。

### 3.2 AEF 嵌入检验（**这才是有效判据**）

在物种点上提取 AEF 2023 嵌入，与母库各类质心比余弦相似度：

| 物种组 | 最相似的母库类质心 | 判读 |
|---|---|---|
| 常绿灌丛（杜鹃等） | **常绿灌丛 0.640** / 疏闭常绿阔叶 0.640 | ✅ **验证通过** |
| 常绿阔叶（栲/樟等） | **郁闭常绿阔叶 0.716**（明显第一） | ✅ **验证通过** |
| 灌丛 | **落叶灌丛 0.557**（第一） | ✅ **验证通过** |
| 荒漠稀植 | 草地 0.543（稀疏植被/草地混淆，合理） | ✅ 通过 |
| 园地（苹果/柑橘/茶等） | **乔灌园地 0.616**（第一）但仅领先 0.007 | ⚠️ **弱信号，需扩样确认** |
| 苔藓 | 落叶灌丛 0.451（绝对值低=嵌入 atypical） | ❌ 弱 |
| **地衣** | 落叶灌丛 0.495，**140 质心排名 18/30** | ❌ **失败** |
| 湿地类 | 落在园地/灌丛，非湿地 | ❌ 失败 |

**结论（诚实版）**：
- **能用的**：常绿灌丛、常绿阔叶、灌丛、荒漠稀植 —— 但**这些恰恰是我们已经做得不错的类**。
- **失败的**：**地衣苔藓（140）、湿地类、园地（弱）** —— 恰恰是我们最缺的类。
- **机理**：标本点只证明"此处采到某物种"。**地衣常长在树干或岩石上**，它的 10m 像元是森林或裸地而不是"地衣苔藓地类"；园地记录多是野生苹果/林下柑橘而不是果园；芦苇苔草在任何草甸都有。
- **旁证（排除"模型不输出"的干扰）**：质心检验不依赖模型输出——地衣点的嵌入本身就离母库 140 质心很远（排名 18/30），所以**不是模型的问题，是数据本身不指向该地类**。

### 3.3 顺带得到一个独立证据：类别混淆是特征空间的固有属性

母库自身各类质心的两两余弦相似度：

| 最相似的类对 | 余弦 |
|---|---|
| 疏闭针阔混交 ↔ 郁闭针阔混交（92/91） | **0.990** |
| 疏闭常绿阔叶 ↔ 郁闭常绿阔叶（52/51） | **0.985** |
| 疏闭落叶针叶 ↔ 疏闭针阔混交（82/92） | 0.978 |
| 郁闭落叶针叶 ↔ 疏闭落叶针叶（81/82） | 0.978 |
| 疏闭落叶阔叶 ↔ 郁闭落叶阔叶（62/61） | **0.973** |

**这从母库本身（不用任何模型）证明了"疏闭/郁闭"这几对在 64 维 AEF 空间里天生不可分**，与 `27`/`29` 号文档的诊断完全一致。是个可直接写进论文的结论：**类别混淆结构可在特征空间直接测量，无需训练模型**。

**❌ 不可用（预测分散或落在无关地类）**

| 组 | 证据 |
|---|---|
| **地衣（全部属）** | Cladonia 26%→郁闭阔叶、Graphis 38%→郁闭阔叶、Hypogymnia 33%→针叶、**Physcia 46%→城镇不透水**。地理上集中在昆明/成都/广州周边（采集便利），不是高山苔原或荒漠结皮 |
| **苔藓（全部属）** | Brachythecium 45%→草地、Bryum 38%→草地。苔藓生长在草地/岩石 **表面**，不构成"苔藓地类" |
| **园地（全部属，14 个）** | Actinidia 46%→郁闭阔叶、Camellia 39%→郁闭阔叶、Citrus 20%→城镇、Malus 24%→落叶灌丛…**无一指向 11**。苹果/猕猴桃/茶的标本记录绝大多数是野生或零散种植 |
| 湿地草本（Carex/Cyperus/Juncus/Phragmites/Scirpus） | Carex 579 点散在阔叶林/灌丛/草地——**苔草属是全国草甸的常见成分，不是湿地专有** |
| 木本沼泽（Myrica） | 19% 落叶灌丛 / 16% 常绿灌丛，不指向 180 |
| 城市绿化属（Pinus / Cunninghamia / Cupressus / Juniperus / Sabina） | 大量落在城镇不透水与阔叶林 → 是人工林/城区绿化，不能当天然针叶林样本 |

**入库判据（重要）**：上表"命中率"都在 25–70% 之间，**直接当标签用会注入 30–75% 的噪声**。
正确用法有且只有两种：
1. **交叉验证**（推荐）：用"物种 + 模型预测一致"的点作为**独立证据**，核验模型在 51/71/121 上的预测是否可信——这是论文里比跟 WorldCover 对照更硬的验证材料。
2. **弱标签增密**（谨慎）：仅在"物种暗示的类 = 模型预测的类"时保留，这样既不引入冲突标签，又能给稀有类（尤其 184/185）增密。

## 三·补：后两批数据（GBIF 下载 + OSM）的验证结果

### 补 3.5 GBIF 下载 A（8 个高精度标本馆，867,351 条）—— **决定性失败**

用账号开通后的异步下载 API 拿到全量 DWCA（145 MB zip → `occurrence.txt` 942 MB + `verbatim.txt` 316 MB）。

**坐标质量最好**：99.3% ≥4 位小数（≤11m），83.6% 是 6 位；覆盖 326 科 / 3,019 属 / 29,637 种。

**两个硬伤**：
1. **`habitat` / `verbatimLabel` / `occurrenceRemarks` / `elevation` 全部 0% 填充**——这 8 个馆只发布了 `locality`（83.7%，但是地名不是生境，如"上庙山""猫儿山山顶电视台下"）。
   → **"生境文本挖掘地类标签"这条路作废。**
2. **年份集中在 1810–2008**：≤1950 年 477,015 条（55%）、1951–1980 年 300,053、1981–2000 年 84,957、**>2000 年只有 5,326 条（0.6%）**。

**决定性测试**：取 1,037 个空间独立（2 km 间隔）的历史标本点，看它们的 2023 年 AEF 嵌入被预测成什么：

| 标本属对应的类 | 点数 | 2023 年预测构成 | **命中本类** |
|---|---|---|---|
| 51 郁闭常绿阔叶 | 477 | **城镇不透水 41%** / 郁闭常绿阔叶 16% / 乡村不透水 9% | **16%** |
| 121 落叶灌丛 | 469 | **城镇不透水 46%** / 落叶灌丛 11% / 草本旱地 9% | **11%** |
| 71 郁闭常绿针叶 | 56 | 城镇不透水 41% / 乡村不透水 16% | **4%** |
| 202 水体 | 35 | 城镇不透水 34% / 灌溉耕地 26% | **0%** |

按年份分组无差异（>1960 年 15% vs ≤1960 年 12%）。

**机理**：这些标本是 80 年前采的，**当年的采点今天有 41–46% 已经是城市**。
→ **历史标本点不能当 2017–2024 的地类标签。GBIF 这条路封死。**

| **residential/industrial/commercial → 190** | 4138 | **城镇不透水 65%** / 乡村 16% / 灌丛 6% | **65%** | ✅✅ **强** |

**关键点**：
1. **OSM 对"有物理实体、标注者不会标错"的类极准**（冰川 93%、城镇 65%、耕地 66%），对**需要专业判读的类无效**。
2. **`orchard` 873 个点、命中 0%** —— 这是一个**独立的第三条证据**（另两条：物种果树属全部失败、母库 11 类 F1=0），共同指向：
   **类 11 乔灌园地在当前特征体系下不可得**，不是标注问题（873 个点随机命中也会有几个）。
3. `landuse=forest` 只有 9% 命中 61，说明中国的 OSM forest 标注混了人工林/经济林/疏林。
4. `grass` 大量落在城镇不透水——**城市公园草坪**是重要偏差源。

| CVH 标本馆 | 39.1 万点 | 88% ≤11m | 51(52–68%)、71(46%)、121(30%)、184/185(42%) | 140、11、湿地 |
| iNaturalist | 22.5 万条 | 93% 亚米级 | 弱（内容=城市杂草） | 多数 |
| GBIF 下载(8馆) | 86.7 万条 | **99.3% ≤11m** | ❌ **全部失败**（时间错位：采点 41–46% 已城市化） | 全部 |
| **OSM** | 102 万面 → 1.2 万点 | 面内点 | **220(93%)、190(65%)、10/12(66%)、200(32%)、121(31%)** | 11、130、61 |

**贯穿全部来源的规律**：
> **外部数据对"有物理实体、可被独立验证"的类有效；对"需要专业判读"的类无效。**
> 有效：冰川、城镇、耕地、灌丛 —— 看一眼就知道是什么。
> 无效：园地 vs 耕地 vs 灌丛、郁闭度、地衣苔藓、湿地细分 —— 需要专家在场判断，众包标注和标本记录都不携带这个信息。

### 补 3.8 「需要重新下载吗？」——三个逐条实测的「不需要」

用户提出可参考 GBIF species API 的分类树接口（`getRootUsages`）重新筛。逐条验证后**结论是不需要重下**：

**(1) 为 `habitat`（生境文本）重下 —— 无意义。**
`habitat` 不是那 8 个馆的问题，是**全中国数据集的普遍情况**。抽样中国最大的 8 个植物数据集（合计 400 万条）：

| 数据集 | 中国记录数 | `habitat` 填充 |
|---|---|---|
| 2023 Contributions of Plant Specimen Data inside China | 2,585,250 | **0/30** |
| PE Herbarium 500k | 500,000 | 0/30 |
| KUN-IBSC-NAS | 224,598 | 0/30 |
| iNaturalist Research-grade | 201,306 | 0/30 |
| PE 云南 | 163,197 | 0/30 |
| PE 1900-1950 | 136,701 | 0/30 |
| IBK 广西 | 116,673 | 0/30 |
| CDBI 成都 | 103,310 | 0/30 |

唯一填 `habitat` 的是 `International Barcode of Life`（720 条，20/20 填），量级可忽略。
→ **生境文本挖掘在全中国范围内都无料可挖。**

**(2) 为「更新的数据」重下 —— 无意义。**
中国植物记录的时间分布：1900–1949 有 790,628 / **1950–1979 有 2,652,322** / 1980–1999 有 432,932 / 2000–2009 有 180,190 / 2010–2014 有 61,938 / 2015–2019 有 99,203 / **2020–2026 有 205,481**。
看似 2020–2026 有 20.5 万条很新，但按数据集 facet 拆开：

| 数据集 | 2020–2026 条数 | 备注 |
|---|---|---|
| **iNaturalist Research-grade** | **184,668** | **我已直接拉过 22.5 万条，且已判定为城市杂草** |
| 2023 Contributions… | 9,413 | 坐标被降到 2 位小数（1.1 km） |
| Invasive species dataset | 4,773 | 外来种专题 |
| INSDC Sequences | 2,182 | 分子样本 |
| Pl@ntNet | 1,636 | 小 |
| iBOL | 720 | 小（但 habitat 全填） |
| 其余 19 个小数据集合计 | ~1,500 | — |

→ **"最近的中国植物数据" ≈ iNaturalist，已经拿过且已否决。**

**(3) 按分类树重新枚举类群（即 `getRootUsages` 的用途）—— 思路对，但救不回来。**
`/v1/species/root` 直调返回 400；等价能力走 `/v1/species?rank=KINGDOM` 可用（返回 20 个界，可逐级下钻）。
借此做了一个**用户提示带来的、之前漏掉的关键实验**——**按生长基质拆分地衣/苔藓**（原先把它们当成一整类）：

| 生长基质分组（属级人工判读） | n | 140 质心排名 | 140 质心余弦 | 判读 |
|---|---|---|---|---|
| **土生结皮地衣**（Collema/Psora/Toninia/Endocarpon/Cetraria/Thamnolia/Cladonia 等 27 属） | 2,404 | **10/30** | **+0.372** | 最好 |
| 石生地衣（Umbilicaria/Rhizocarpon/Xanthoria/Peltigera） | 328 | 11/30 | +0.360 | 对照 |
| 土生藓类（Bryum/Racomitrium/Aloina/Distichium 等） | 1,921 | 14/30 | +0.343 | |
| 附生地衣（Usnea/Bryoria/Ramalina/Evernia/Physcia 等） | 2,007 | 16/30 | +0.313 | 对照 |
| 林床藓（Brachythecium/Hypnum/Dicranum/Polytrichum 等） | 7,960 | 20/30 | +0.247 | 对照 |
| 泥炭藓（Sphagnum） | 1,343 | 23/30 | +0.241 | 对照 |

**排序完全符合生长基质的预测**（土生结皮 10 名 > 附生 16 名 > 林床 20 名 > 泥炭藓 23 名）——
**机理被证实了**：地衣/苔藓能否指示"地衣苔藓地类"，取决于它长在**土**上而不是树上或石头上。
但**量级不足**：最好的土生结皮地衣也只有 140 质心排名 10/30、余弦 +0.372，且 33% 仍被判为城镇不透水、23% 判为草地。
→ **信号方向对、强度不够，仍不能直接当标签。**

**结论**：**GBIF 不需要重新下载。** 瓶颈不在覆盖度（该覆盖的类群都覆盖了），而在
① 物种记录本身不携带地类信息；② 历史标本时间错位；③ 生境文本字段全空。三者都是数据性质，换谓词重下无解。

## 五、我的建议（重要）

**不要再花力气在"物种分布 → 地类样本"这条路上补 140 / 园地 / 湿地。** 实测已经证明它无效，机理清楚（物种 ≠ 地类）。

**这些数据真正的价值在两处**：
1. **森林/灌丛类的交叉验证与增密**（常绿灌丛、常绿阔叶、灌丛、荒漠稀植已验证通过）——对已经在 0.7+ 的类做质量核验。
2. **类别系统的决策依据**（§3.3 的质心相似度矩阵）——用它能定量说明"哪些类必须合并"，这比任何模型实验都干净。

**要真的补 140 / 园地 / 湿地，正确的路是**：
- **140 地衣苔藓**：靠**物理判据**（高寒/干旱区 + 生物土壤结皮的光谱与物候特征）+ WorldCover 的 Moss & lichen 层做候选掩膜，再用 AEF 验证。项目记忆里已有的套路（"阈值卡死改物理判据"）。
- **11 园地**：靠**园地专题栅格**（AOMC 苹果 / 茶地图 / 柑橘 / 橡胶）+ 纹理特征，不是物种点。
- **湿地细分**：靠**物候 + SAR 淹水时序**（Sentinel-1 后向散射），不是物种点。
