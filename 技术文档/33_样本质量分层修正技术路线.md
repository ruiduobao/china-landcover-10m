## 一、问题的重新定位（本轮的核心发现）

### 1.1 用 GLC_FCS10 的样本生成口径反查本母库

GLC_FCS10 生成样本的四条硬机制：

| 机制 | 他们的做法 |
|---|---|
| **多产品求交取信** | 不透水面样本 = `GISD30 ∩ GISA2.0 ∩ WorldCover不透水 ∩ ESRI不透水`（四产品交集）；红树林 = `GWL_stable ∩ GMW_stable` |
| **时空稳定性筛选** | 只保留 1985–2022（或 2000–2022）**类别未变过**的像元 |
| **最大边界掩膜** | `MaxBound_imp = 四产品并集`、`MaxBound_wet = 五产品并集`；自然覆被样本必须落在两个边界**之外** |
| **形态学腐蚀** | 3×3 腐蚀去除边缘混合像元，只留空间均质区 |

本母库**已有**对应字段：`stab_years`（稳定年数）、`agree_n`（一致产品数）、`wc_l0/esri_l0/th_l0/clcd_l0/cn30_l0`（五个先验产品的 L0 标签）、`border`（边缘标记）、`tier`（来源层级）。

### 1.3 来源追查（决定性证据）

| 类 | 主要来源 | 该源的 `stab` / `agree` |
|---|---|---|
| **落叶灌丛 121** | `glc_fcs10_2023_shrub` **435,593（98%）** | NaN / **−1** |
| **常绿灌丛 120** | `glc_fcs10_2023_shrub` **110,783（100%）** | NaN / **−1** |
| 乔灌园地 11 | `teamap_2022` / `citrus_2020_10m` / `aomc_apple_2020` | −1 / 1–3 |
| 郁闭针阔混交 91 | `ng_mixed91` 1,978 + `glc_fcs10_2023_band130` 761 | NaN / NaN |
| 疏闭常绿阔叶 52 | `glc_fcs10_2023` 3,944 + `ng_evergreen52` 1,670 | −1 / NaN |
| （对照）城镇不透水 190 | `v2_glc_fcs30d2020_7yr_stable` **56,299** | **23 / 5.0** |

**结论：121/120 共 55.6 万点（占母库 24.7%）100% 来自单一源 `glc_fcs10_2023_shrub`，完全没有时间稳定性与多产品一致性背书。** 强类全部走 `GLC_FCS30D 7yr_stable` 高质量通道。

### 1.4 这条发现要修正的既有结论

`29`/`30` 号文档判定"**121 落叶灌丛是海绵类、特征不可分**"，并据此建议"121→130 合并"。
但 44.6 万个 121 样本既然零质量背书，**更可能的解释是"样本脏"而不是"类不可分"**——若训练标签本身采自耕地与森林之间的混合像元，模型学到的就是"混合像元=121"，在图上自然表现为海绵。

**这是一个可证伪的假设，本轮要测。**

## 二、技术路线（四阶段，每阶段有明确判据）

### 阶段 A：质量分层的实证检验 —— 分层加权是否有效

**要回答**：把 `stab_years`/`agree_n` 变成样本权重，精度是否提升？弱类是否受益？

**做法**
- A1 构造质量分层权重：
  ```
  w_quality = w_base(现有 train_weight)
            × f_stab(stab_years)      # 分段：≥20年→1.0；10–19→0.8；1–9→0.5；−1/NaN→0.3
            × f_agree(agree_n)        # 分段：≥4→1.0；3→0.9；1–2→0.6；0→0.4；−1/NaN→0.3
  ```
- A2 在**同一 25km 块留出验证池**（`validation_pool_v2` + `holdout_blocks`）上对比 5 个口径：
  | 口径 | 说明 |
  |---|---|
  | ① 现状 | 用现有 `train_weight`（v-final 口径） |
  | ② 只加稳定年数 | `w × f_stab` |
  | ③ 只加一致产品数 | `w × f_agree` |
  | ④ 两者都加（推荐候选） | `w × f_stab × f_agree` |
  | ⑤ 只留高质量（上界参照） | 训练集只保留 `stab≥10 ∧ agree≥3` |
- A3 记录 OA / macroF1 / balanced-acc / LEVEL1 / LEVEL0 / 逐类 F1

**判据**
- 若 ④ 的 **OA 提升 ≥ +0.3pp 且 macroF1 不降** → 采纳为新版权重，进入阶段 E
- 若 ④ 无提升 → 假说被否，母库权重不动，只保留诊断结论
- 口径 ⑤ 只作上界参照（会清空弱类，**不采用**）

**成本**：本地，单次约 15–30 分钟（含 5 个口径）

---

### 阶段 B：121/120「伪类」假设检验 —— 是类不可分还是样本脏

**要回答**：121 无法与耕地/森林分开，是特征空间固有属性，还是脏样本造成的？

**做法**
- B1 **嵌入内聚性对比**（不需要训练模型）：对 121 的三个子集分别算 64 维嵌入的类内离散度与到其他类质心的区分度
  - B1a 母库 121（全部来自 `glc_fcs10_2023_shrub`）
  - B1b 外部干净 121 候选：OSM `landuse=scrub`（已实测 31% 命中 121）+ CVH 灌丛属（Caragana/Rosa/Cotoneaster/Spiraea/Vitex/Lespedeza）
  - B1c 对照：其他类的内聚性（如 61 郁闭落叶阔叶、10 草本旱地）
  - 指标：类内平均余弦距离、类间最近质心余弦、`k=5` 近邻同类比例
- B2 **只含干净 121 的对比训练**：训练集把 121 全部换成 B1b 的干净点（数量对齐，如各 3,000），其余类不动，看：
  - 121 的 F1 是否显著提升
  - 121 预测面积是否从"海绵态"收缩到物理合理量级
- B3 同步对 **120 常绿灌丛** 做同样检验（理由同上，100% 单源无背书）

**判据**
- 若 B1 显示"干净 121 内聚性显著优于 FCS10 121"（如类内余弦距离低 20%+）→ **假说成立**
  → **推翻"121→130 合并"建议**，改为"用干净样本重建 121"，并回写 `29`/`30`
- 若两者内聚性无差异 → 假说不成立，"类不可分"结论维持，合并建议保留

**成本**：本地；B1 纯统计（分钟级），B2 需一次训练（约 10 分钟）

---

### 阶段 C：局部自适应建模 —— 绕开 GEE 单次 2 万点上限

**要回答**：把"一个全国模型"改成"每格一个本地模型"，精度是否显著提升？

**背景**：GLC_FCS10 全球切 984 个 5°×5° 格、**每格独立训练 RF**，训练时纳入 3×3 邻域样本。
我们的死结是"GEE 单次训练只能吃 ≈2 万点，全国摊开则每格只有几十个点"。**局部建模正好对症**：我们的生产链路**本来就逐瓦片导出**，改成逐瓦片训练只是把训练样本换成局部样本。

**做法**
- C1 **本地模拟**：按 **2° 网格**分块（与生产瓦片一致），每块用"本块 + 8 邻域"的样本训练一个 RF，严格用同一留出池评估
  - 对照臂：全局模型（现状）
  - 实验臂：局部模型（每格独立）
  - 每格训练点数固定（如 2 万，模拟 GEE 上限），**这才能反映真实增益**
- C2 **与 K 模型投票叠加**：局部 × K=5 投票
- C3 若有效 → 改 `代码/8.全国生产/pw_template.tpl`：训练样本由 `filterBounds(tile)` 取本格 + 邻域

**判据**
- 局部 vs 全局的 OA 差 ≥ +1pp → 采纳，改生产模板
- < +0.5pp → 不采纳（改造成本不值）
- 注意记录**接缝风险**（GLC_FCS10 自认局部建模有空间不连续问题）

**成本**：本地模拟约 30–60 分钟；若采纳，模板改动 + 一次 GEE 对照导出

### 阶段 D：MaxBound 后处理 + metric centroid 净化

**要回答**：两条"纯后处理"手段各值多少？

**D1 MaxBound 掩膜（与已证伪的路线 B 的本质区别）**
- 路线 B（已证伪，−0.97pp）：用**模型 A 的输出**做硬门控 → 门控来自不可靠模型
- MaxBound（GLC_FCS10 做法）：用**多个独立先验产品的并集**限定某类最大范围
- 应用：
  - `220 冰雪 ⊂ 冰川/高程边界`
  - `184 红树林 ⊂ GMW v3`、`186 潮滩 ⊂ GTF30`、`185 盐沼 ⊂ GSM10`
  - `190/200 不透水 ⊂ GISD30 ∪ GISA2.0`
  - 越界像元按"最近的合法类"或"邻域多数"校正
- 可在**已产出的东北 36 片上直接做**，无需 GEE

**D2 metric centroid 30m→10m 净化**
- 母库 **67%（149.9 万点）来自 30m 的 `GLC_FCS30D` 底座**
- 做法：对每个 30m 来源的样本点，取其所在 30m 像元对应的 **9 个 10m 子像元**，算光谱均值作质心，**保留最接近质心的那个 10m 子像元**作为新样本点
- 需要 10m 光谱（GEE：`COPERNICUS/S2_SR_HARMONIZED`），按 2° 分块取

**判据**
- D1：越界像元占比与校正后面积变化；对东北成品做 A/B（`p8_audit.py` 反审）
- D2：净化后的样本子集与原始子集在嵌入空间的一致性；再用它训练看 OA 变化

**成本**：D1 纯本地（分钟级）；D2 需 GEE 取数（1–2 小时）
