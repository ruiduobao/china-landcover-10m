# 36. 「52/62 疏/郁闭森林不可分」结论 · 文献查证背景说明

> 2026-09-24 ｜ 用途：**转交他人查文献**，核对我们的"52/62 真不可分"结论是否站得住、有无被文献推翻或已有解法
> 我方证据出处：`技术文档/27`（诊断原始报告）、`33`（质心矩阵）、`34`（121 对照）

---

## 一、要查证的结论（一句话）

> **在 AlphaEarth 64 维年度嵌入（纯光谱-时序表征，无 lidar）上，"疏闭 vs 郁闭"森林（canopy cover 阈值二分的类对）不可分（二分类 AUC 0.785/0.833）；文献上这类区分被认为必须外挂覆盖度层（VCF/GEDI）才可解。**

## 二、类的定义（查文献时的术语对齐）

我方分类体系对标刘良云组 GLC_FCS30/GLC_FCS10（Zhang, Liu et al., *ESSD* 2021/2025），30 类精细体系。争议类对：

| 产品码 | 英文名 | 中文名 | 定义依据 |
|---|---|---|---|
| 51 / 52 | Closed / Open evergreen broadleaved forest | 郁闭 / 疏闭常绿阔叶林 | **郁闭度（canopy cover, fc）阈值** |
| 61 / 62 | Closed / Open deciduous broadleaved forest | 郁闭 / 疏闭落叶阔叶林 | 同上 |
| 71 / 72、81 / 82 | 针叶林同构 | | 同上 |
| 91 / 92 | Closed / Open mixed-leaf forest | 郁闭 / 疏闭针阔混交林 | 同上 |

**关键**：GLC 系产品图例中，森林的 Open/Closed 划分**不是光谱类别而是覆盖度阈值编码**——
**Open = 0.15 < fc < 0.4；Closed = fc > 0.4**（fc = fractional tree canopy cover）。
即这对类的**类边界是人为阈值切在一个连续变量上**。

## 三、我方实测证据（可复现，脚本 `代码/7.vfinal/v1_sep_probe.py`）

### 3.1 二分类探针（5 折 CV，2022 年全域，64 维嵌入，RF 分类器）

| 类对 | AUC | 我方判读 |
|---|---|---|
| **52 vs 51**（疏/郁闭常绿阔叶） | **0.785** | 真·不可分 |
| **62 vs 61**（疏/郁闭落叶阔叶） | **0.833** | 真·不可分 |
| 91 vs 71（混交 vs 常绿针叶） | 0.997 | 完全可分（**对照**） |
| 91 vs 61（混交 vs 落叶阔叶） | 0.978 | 完全可分（对照） |
| 140 vs 150 / 201 | 0.987 / 0.990 | 完全可分（对照） |
| 11 vs 10 / 121 | 0.949 / 0.956 | 完全可分（对照） |
| 121 vs 10 / 130 / 61 | 0.971 / 0.963 / 0.964 | 完全可分（对照） |

→ **探针方法本身有效**（其余类对都是 0.95+），只有"疏/郁闭"四对掉到 0.78–0.83，且与文献的 fc 阈值定义吻合。

### 3.2 特征空间质心余弦相似度（免训练的独立旁证，`技术文档/31`）

| 类对 | 质心余弦 |
|---|---|

| **62 ↔ 61** | **0.973** |
| 92 ↔ 91 | 0.990 |

→ 同一冠层类型内"疏/郁闭"的类中心在 64 维空间几乎重合。

### 3.3 样本与特征条件（复现条件）

- 特征：**AlphaEarth Foundations 年度嵌入**（GEE `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`，64 维 A00–A63，10 m，2023 年）
- 样本：52 共 5,754 点 / 62 共 10,880 点（母库 2,252,207 点，多源投票+提纯；52/62 主要来自 `glc_fcs10_2023` 第二教师）
- 训练量已验证不敏感：给 52/62 补样本（+1,673/+5,183）后 F1 仍 ≈0（`技术文档/26`）——**样本量不是瓶颈**
- 局部建模（`技术文档/34`）能修 121（0.43→0.68）**但修不了 52/62**——**建模也不是瓶颈**

## 四、请文献查证的问题清单（按优先级）

1. **阈值类的可分性理论**：canopy cover 是连续量、Open/Closed 是阈值二分——有没有文献明确讨论"阈值二值化类在光谱/嵌入特征空间的分类上限"？
   （关键词：*continuous variable discretization classification limit*、*canopy cover threshold classification ambiguity*）
2. **解法文献**：区分 open/closed forest 的公认手段是不是**必须外挂覆盖度层**？
   - MODIS VCF（MOD44B）、GEDI `cover`/`rh98`、ICESat-2 ATLAS、Sentinel-1 SAR 极化/相干性、Landsat 光谱混合分解（SMA/NSMA）
   - 期望找到"光学/嵌入单独分不开、加 VCF/lidar 后显著提升"的定量证据（关键词：*forest canopy density classification lidar VCF*、*open vs closed forest remote sensing*）
3. **同类产品自报精度**：GLC_FCS30/FCS30D/WorldCover/ESRI/CLCD 等产品对 51/52、61/62 的 PA/UA 是多少？
   我方预期**它们也分不好**（若如此则佐证"类定义本身难"而非"我们方法差"）。GLC_FCS30（Zhang et al. 2021 *ESSD*）的混淆矩阵里这几对的互混比例是重点。
4. **异源参照**：Landsat/Sentinel-2 光谱指数（NDVI/EVI/LAI）能否代理郁闭度分级？SAR（Sentinel-1 VV/VH）对郁闭度的敏感性文献？
5. **术语确认**：GLC 图例的 fc 阈值（Open 0.15–0.4 / Closed >0.4）出处确认（GLC_FCS30 User Guide / Zhang et al. 2021 附表）；与 IPCC/FAO 的 forest canopy cover 阈值定义（如 FAO 10% 树冠）差异。

## 五、我方倾向（供参考，不必迎合）

结论**大概率成立**——因为：① 探针对照组全 0.95+，方法没问题；② 质心余弦独立佐证；③ 补样本/局部建模都无效，排除样本与建模瓶颈；④ 类边界是连续变量阈值，物理上就该重叠。
**但要留意反例**：若文献显示 VCF/SMA 之外、纯 Sentinel-2/Landsat 也能分开（如用物候+纹理），则"不可分"应改口为"在 64 维 AEF 嵌入上不可分"（AEF 可能丢了纹理/混合分解信息）——这是我们最可能的盲区。
