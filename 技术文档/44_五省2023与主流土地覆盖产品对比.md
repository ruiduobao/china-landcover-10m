## 三、关键发现

**F2 灌丛是最大分歧源（直接呼应 E12/E13 与 D2 待决）**
- 我方组级灌丛占比：黑 16.1%、川 17.8%、粤 19.0%、宁 41.3%、闽 16.7%；而 FCS10/FCS30D/ESA 在我方掩膜内给出的灌丛仅 2.9–11.4%（FCS10：川 5.6/粤 2.9/宁 7.6/黑 8.3/闽 4.7%）；ESRI 无独立灌丛类，其 rangeland（灌草合并）占比 黑 7.9/川 41.4/粤 3.6/宁 69.0/闽 4.9%——在川/宁与我方灌+草合计（43.3/66.1%）相当接近，在粤/闽则大多被判为森林。
- 去向（细类）：湿润区**"我方灌丛"被主流产品判为森林**（黑→落叶阔叶林 53%＋落叶针叶林 19%；粤→常绿阔叶林 80%；闽→常绿阔叶林 71%；川→常绿针叶林 31%）；干旱区**判为草地/裸地**（宁→草地 77%/裸地 39%）。
- 机制：我方 2023 训练池按 E13 预注册裁决保留 FCS10-2023 **灌丛专题层**（占池 25.3%），模型复现的是"灌丛层"的宽定义；FCS10 **主产品栅格**、FCS30D、ESRI、ESA 的 shrubland 范围都窄得多。即"灌丛 vs 疏林/幼林（湿润区）或草地/稀疏灌丛（干旱区）"的边界是**惯例之争的空间呈现**——M3-B 863 个灌丛仲裁点的人工判读是唯一裁决途径（判据预注册见 `42`）。
- 在此惯例差下解读一致率：黑 85.0% 中约 10pp 由灌丛-森林惯例差贡献；若 M3 仲裁后改判灌丛口径，一致率结构将显著变化。

**F3 ESRI built：我方不透水基本被认出，但 built 大量多分（2026-10-07 修正后结论，替代旧"欠映射"说法）**
- **行条件一致率（我方不透水 → ESRI built）89.7–98.3%**（黑 89.7/川 98.3/粤 98.0/宁 90.9/闽 98.1%）——旧报告"0.1–0.5%"是码表错误产物（实为"被判为裸地"的比例），已撤回。
- 但 ESRI built **多分**：其 built 面积占比 黑 3.0/川 11.4/粤 17.7/宁 7.6/闽 11.9%（我方 2.2/1.5/9.1/4.1/5.2%）；precision（其 built 中确为我方不透水）仅 黑 66.0/川 13.3/粤 50.3/宁 48.9/闽 42.8%。
- 四川其 built 的 **74.5% 落在我方耕地**（山区梯田/村居被误判为 built 的已知混淆），广东 35.3% 落在耕地。
- ESRI"树木"对我方森林：黑 97.0/川 88.6/粤 97.9/闽 98.1% 很强，但宁夏仅 27.2%（其余判为 rangeland）——干旱区疏林识别弱（维持原结论）。
- 引用 ESRI built 数字必须同时带"行条件高 + 多分严重 + 类系最粗"三条警告；我方不透水面积与 FCS10 互相吻合（粤 9.1% vs 8.8%）。

**F4 耕地与湿地的分歧集中在山区/沿海**
- 黑龙江耕地与 FCS10 一致 94.3%（平原农区高度一致）；四川只有 54.2%（FCS30D 82.8%）——山区旱地/轮歇地在 FCS10 主栅格中被划入草地/灌丛（其主栅格耕地组成 11.0% vs 我方 18.6%），山区耕地边界是惯例分歧第二大的区域。
- 湿地：ESRI/ESA 对我方沿海湿地（潮滩/盐沼/红树林）几乎不认（粤 ESA 2.4%、ESRI 0.7%）——专题湿地类不在其类系或年份差所致；FCS10 51.2% 最高。
- 黑龙江湿地 FCS30D 48.6%、ESRI 30.6%：沼泽与水田/草地的边界惯例差异。

**F5 水体与主要森林高度一致**
- 水体 producer agreement：四产品 66–99%（ESRI/ESA 95%+，FCS10 黑 85.6%）；主要森林（黑/川/粤/闽）FCS10 96.8–99.1%。主导类型可靠性与 G7 结论互相印证。

## 六、局限与使用注意

1. 全部结论是**产品间一致率**：受我方"教师泛化"标签惯例与各产品惯例共同影响，不能当作精度；我方精度仍以 M3 人工判读为准。
2. FCS30D-2022（30 m）/ESA-2021 含年际变化成分；ESRI 类系最粗（9 类，rangeland=草+灌合并，云像元已排除），其一致率优势部分来自类系粗带来的"天然容错"，跨产品排序比较时要注明口径不同。
3. ESRI built"行条件高 + 多分严重"并存（F3）；ESA moss/lichen→稀疏植被的归并是通行做法但存在解释空间。
4. 掩膜含近岸被分类海面（政策 A）；若改政策 B（海面置 nodata），粤/闽的一致率将略升（海面四产品都判水体，现况是抬升一致率的）。
5. 预览图为 400 m 抽样最近邻取点，仅供目视定位分歧热点，不作统计依据（doc 43 概览页纪律不适用于普通 PNG）。
