## 0. 一句话与总图

用 Google AlphaEarth Foundations 年度嵌入（AEF 64 维 / 10 m）+ GEE 服务端随机森林，生产中国 2017-2024 逐年 10 m 土地覆盖（24 类），对标刘良云 GLC_FCS10。

总流程（文字版流程图）：
原料层（225万样本母库 + AEF指纹） -> 菜谱层（30类到24类主产品 + 9大类） -> 训练层（GEE服务端局部RF，每瓦正负2度借样约2万点） -> 生产层（313瓦乘8年=2504任务，batch导出 + getPixels下载） -> 质检层（G1-G8门 + 保真100% + ov_build金字塔） -> 交付层（分省合幅10m成品 + QA + 面积表 + 色卡） -> 考试层（留出评估 + M3独立人工点 + E14跨产品对比）

记忆顺序：样本 -> 指纹 -> 菜谱 -> 本地专家 -> 切块生产 -> 质检 -> 交付 -> 独立考试。

## 3. 模型：GEE 服务端局部单 RF
生产配置：24类定义全年统一；局部训练正负2度借样；单RF 100树minLeaf2 maxNodes5000约2万点，不宣称逐年最优，训练端v31重标用 ee.Dictionary 查表；K=5不进默认；C臂17维不进默认保留专题；训练标签逐年年度子集；跨年同模型只作对照；时序后处理保留并检验真实变化是否被抹掉（修正标记；静态精度与变化漏检误检双口径）。方法论：同一方法同一体系年度匹配样本与嵌入逐年局部训练。
为什么局部 E1/E2：加权负3.7pp证伪、灌丛脏样本证伪（121 vs邻居AUC 0.96-0.99）、局部2度 +6.56pp三种子全正；GEE三臂 A 0.744/0.682 到 B 0.829/0.770 到 C 0.863/0.785，局部单模型以1.2倍成本拿85-95%增益。为什么单模型：K=5贵6.5-7倍。为什么2万点：E4浅容量下2万0.6498到20万0.5737负7.6pp。证伪勿重跑：硬门控专家负0.97pp、浅容量加样本、训练端合并类别已撤销、非最近邻重采样。GEE侧惰性对象图不get到本地；RF服务端本地只评估。smileRandomForest 支持 setOutputMode(MULTIPROBABILITY)，概率融合未测。方法学纪律：先预注册判据；单次种子噪声正负1.5pp，小于2pp单次增益不可信须多种子配对；报告区分实测值与正确解读。
