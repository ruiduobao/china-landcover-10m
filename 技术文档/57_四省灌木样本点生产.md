## 二、方法链（为何这么设计）

**1. 多源候选（避免单源污染）**——doc56 已证 FCS10 灌丛层真灌丛率仅 0.139–0.165；故此轮**不再依赖单一来源**：

| 源 | 覆盖（4 省，100 m 像元） | 特点 |
|---|---|---|
| Dynamic World v1 | 宁夏 106 万 / 四川 818 万 / 黑 368 万 / 闽 256 万 px | Sentinel-2 10 m、2015–2024、含 shrub_and_scrub 概率；单源最富 |
| ESA WorldCover v200(20) | 宁 9.3 万 / 川 6.5 万 / 黑 37 万 / 闽 **12 px** | 离散类，**福建几乎无灌丛** |
| Copernicus LC100(20) | 宁 3.0 万 / 川 84 万 / 黑 40 万 / 闽 1.6 万 px | 100 m 年际系列 |
| MODIS MCD12Q1(6/7) | 宁 5.1 万 / 川 0.5 万 / 黑 1.6 万 / 闽 1 px | 500 m 粗空间先验 |
| **OSM** | 四川 1,039 ／ 黑龙江 829 ／ **福建 1,834** ／ 宁夏 0（Overpass） | 最独立的众源标签；宁夏无记录 |
| FCS10 灌丛层（我方训练池） | 521,400 点 | 单源精度 13.9%–16.5%，仅作对照 |

**L1 层**=DW + (WC20 或 LC100) 多源一致；**L2**=DW 概率≥0.4；**L4**=仅 DW；**L3**=WC/LC 而 DW 不认；另加 **OSM** 与 **FCS10** 两层抽样。40,000 个随机点打标签分层，得 1,138 候选。

**2. 目视判读**——z18 切片 + 2×2 联系表，6 个子代理按 rubric（Q1 是否灌丛 / Q2 常绿落叶 / Q3 若否实际类）判 454 点：**是 78 / 否 328 / 无法判读 48**。

**3. 判别器验证**——用 78 正 + 328 负训练，特征集三级对比（AEF 64 / +S2 物候 / +地形气候）：

| 特征集 | AUC | F1 |
|---|---|---|
| AEF64 | **0.868** | 0.606 |
| +S2 物候 | 0.863 | 0.594 |
| +地形气候 | 0.864 | 0.592 |

**重大发现**：AEF 单源最好，加特征不增益——**此前 AUC 0.746 是标签污染所致，不是特征不够**。留一省验证：宁 0.791 / 川 0.897 / 黑 0.800 / 闽 0.857，**平均 0.836**（跨区泛化可用）。

**4. 常绿/落叶划分**——S2 物候振幅（NDVI_jja − NDVI_djf）：

| 方案 | AUC |
|---|---|
| AEF64 | 0.977 |
| +S2 物候 | **0.997** |
| 仅 ndvi_amp | **1.000** |

即**单凭物候振幅即可完美区分常绿/落叶**（68 个确认点上）——这是本集质量最高的判据。

## 三、T2 480 点（扩增）说明

- 取点规则：p_shrub ≥ 0.60；每省 ≤120；与判读点间距 **≥1 km**（防空间自相关虚高）；省内点间 ≥300 m
- 构成：灌丛层内（A）282 点 / 全池发现（B）198 点
- p_shrub 分布：0.66–0.88（判别器概率上限偏低属小样本正常，不应解读为置信度 66–88%）
- **状态：尚未目视复核，T2 单独成文件，不与 T1 混用**
- 本轮 120 个随机抽检点的目视判读因本会话模型无图像输入**未能完成**；子代理改用定量代理（Q1 准确率 0.79、出证精度 0.989@否/0.765@是），结论详见 `t2_imagery/`，**仅供参考**

## 四、局限（必须随数据引用）

1. **视觉通道**：判读为第一轮 6 个有视觉通道的子代理完成；本会话（10-10）多轮尝试均无图像输入，T2 未复核。
2. 判读置信以"中/低"为主（78 点中 conf=低 57、中 21），川西影像过暗、川西与高山多无法判读。
3. T1 78 点每省 13–30，规模仍小，**不支撑单类 F1 级别结论**（doc39 纪律：<30 的类只报合并级）。
4. 常绿/落叶阈值 0.15/0.30 来自森林实验迁移到灌丛、样本 68 点，**跨省使用前需重校**。
5. 负样本 N1 同样有价值——建议一并交付，防止分类器把闲田/裸地当灌丛。
