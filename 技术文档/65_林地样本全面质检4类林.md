## 一、一句话结论

对 4 类林（常绿阔叶 125,499 / 落叶阔叶 138,649 / 常绿针叶 141,937 / 落叶针叶 60,050）做了三层证据（物候 2019+2023、生态气候、独立产品）的全面质检：
**隔离 35,246 点（7.6%）**（常绿/落叶轴被 ≥2 独立层决定性反驳且零支持，或触犯"冷区不可能"硬规则），
**推荐层（strict）159,347 点**、**可用层（clean）430,889 点**；
**混交林 91/92（6,864 点）按用户指令本版弃用**（另存备查）。
母库与 8 年子集**本体未动**（MD5 前后一致），结论以 `row_id` 为键的视图层交付，天然覆盖 8 年。

## 二、方法与证据层

| 层 | 内容 | 说明 |
|---|---|---|
| E1 物候 | S2 双窗 NDVI×1000，**2019 + 2023 两年** | 同 k17/k31 口径（SCL 剔 3/8/9、CLOUDY<60、DJF 上年12~当年3、JJA 6~9 月、scale=20）|
| E2 生态 | SRTM dem + WorldClim bio01/bio06/bio11/bio12 @1km | bio06=最冷月最低温（分带键）、bio11=最冷季均温 |
| E3 独立产品 | ESA WorldCover v200 / Dynamic World 2023 / **MODIS MCD12Q1 LC_Type1**(2022) | MODIS 是唯一独立给"针/阔×常绿/落叶"四分的产品（500 m）|
| E5 嵌入 | AEF64（年度子集自带，命中 1.0000） | E/D 轴 LDA 判别（doc 54：该轴 AUC 0.990；针/阔 0.724 **不可判、不用于自动改判**）|

**判据（预注册）**：
- **轴1 常绿/落叶**：气候带校准阈值（修订 1）→ 逐年 verdict；**E/D 矛盾 = 隔离（≥2 层独立反驳且 0 层支持）**；≥2 层支持 = 推荐；其余 = 弱证据 flag（保留）。
- **轴2 针/阔**：仅区域生态硬规则 + 提示（R1 常绿阔叶不可能：bio11≤0 且 dem<2000；R2 热带落叶存疑；R3 干旱针叶存疑；R4 MODIS 针/阔冲突提示）。
- **框级**：Q1 非林框嫌疑（WorldCover 灌/草 + DW trees<0.25）；Q2 数据缺失。
- **不做自动改判**（标签来自 FCS30 7 年稳定层，改判风险大）——隔离点给出 `suggest_class4`（同类叶型内翻转 E/D）供下游决定。

### 修订 1（首轮结果后、重跑前写死；首轮数字作废）

首轮隔离 9.9%：解剖发现 **① 阈值适用域问题**（冷区常绿针叶的真实冬枯被全国阈值误判为落叶：被隔离类6 的 bio06 中位 −11.4℃、dem 1,661 m）与 **② 雪窗不可辨**（SCL 未剔雪）。修订：
- **R-a 气候带校准**（实现预注册中未落实的"并入气候带"）：按 bio06 分 5 带（z1>30 / z2 0~30 / z3 −50~0 / z4 −100~−50 / z5≤−100，℃×10）；
- **R-b 雪窗守门**：某年 DJF<150 → 该年物候非决断；
- **R-c 极端冷区停用**：bio06 ≤ −100 → 物候层整体非决断（改由 AEF/MODIS 判；也不决断则落弱证据 flag 保留）。

## 五、局限（诚实清单）

1. **针/阔轴无法独立验证**（doc 54 AUC 0.724）：只做 R1 硬规则 + 提示，叶型标签沿用来源（FCS30 7 年稳定层为主）。
2. 物候阈值以 **2019 单年**校准、2023 独立应用（预注册）；暖区（z1）落叶样本不足，并入全国缺省。
3. 隔离是"**证据冲突**"而非"人工判定错误"：建议改判列供参考，**未自动改标签**。
4. 弱证据 flag 占比高（~58%）主要来自：cold-zone 物候停用 + MODIS 对 67% 点不表态（500 m 粗）——不是缺陷，是证据可获得性的客观写照。
5. 近岸海面点（202 个 env 空值）与被分类海面问题同源（政策 A/B 待用户定夺）。
6. 复核材料是单期影像——**不能**用于判 E/D（doc 54 已证 67% 冲突）。
