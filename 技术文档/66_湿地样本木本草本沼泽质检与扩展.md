# 66. 湿地样本（木本沼泽/草本沼泽）质检与扩展（2026-10-13）

> 生成 2026-10-13 ｜ 状态：**★当前（湿地样本）** ｜ 上游：doc 56（木本沼泽层精度 6.7% 废弃 / 草本 0.571）、doc 54（湿地可分性：草沼vs草地 0.708、水体vs草沼 0.967）、doc 64（灌木经验）
> 用户要求：**木本沼泽样本不得来自河道附近的防护林/自然岸林**；对现有样本过滤检验；不足则扩展；产出能支撑全国分类的两类点。
> 判据：`data/swamp_qc/预注册判据.md`（先写死再跑）+ `out/calibration_swamp.json`（分离度报告后冻结）。

## 一、一句话结论

对现有 **180 木本沼泽（4,968 点并集）/ 181 草本沼泽（29,644 点）** 做了三层证据质检，并扩展：
**最终交付 48,314 点（木本 10,612 / 草本 37,702）**，全部通过冻结判据
「**点级季节性淹水 ≥1 月** 或 **（8 方位中 ≥3 方位见水 且 平坦低洼）**」——
该判据在背景随机点上特异性极强（**森林 0.06% / 草地 0.35% / 耕地 2.1%** 通过），
**河道防护林/岸林被结构性排除**；现有样本中 **木本沼泽的 54%（2,687/4,968）被判为无水/堤岸型并隔离**（正是用户怀疑的那个问题）。

| 层 | 内容 | 口径要点 |
|---|---|---|

## 三、四个关键发现（全部为实测，含两个数据级修复）

1. **`sampleRegions` 联合掩膜陷阱（数据级）**：44 波段联合图像中任一波段在某点被掩膜 → **整点被丢弃**。GSW 对"从未有水"的 30m 像元整体掩膜 → 首轮 **71.6% 整行全空**（丢的恰是需要的干点负样本）。
   **修复**：逐源 `unmask(-1)` 再 cat（保留"从未有水"语义）→ 非空率 **28.41% → 100%**；机理闭环：旧口径"点级波段交集"精确等于旧非空数 21,268。
2. **邻域 focal 的哨兵污染（数据级）**：`focal_mean` 作用在已 unmask(-1) 的图像上 → `occ_150` 出现 (-1,0) 混合值（5.5% 行）。**修复**：邻域一律用 `unmask(0)` 后 focal；(-1,0) 按"部分无水"截断为 0。
3. **木本沼泽的水"在邻域不在点级"**：现有 180 点的点级淹水月数中位 = 0、方位水中位 = 1（单侧）——**树冠遮挡使点级看不到水**；而 181 草本沼泽点级淹水 3 月、方位水 3（环水）。这既是"堤岸型"的判别签名，也说明**"水优先"掩膜抽不出木本沼泽**：实测 `WC树覆盖 × GSW季节性水 × 平坦` 全国采样仅 **1 个候选点**（邻域膨胀版也近于空）。
4. **294 个 M3 缺口判读锚点不可用作真值**：其水证据全为 0（与背景随机点同分布），且坡度中位 6.7°（坡地）——与 doc 56 的"木本沼泽层精度 6.7%"一致。本次以**证据结构**（existing 180/181 vs 背景的分离）而非该锚点定标。

## 六、扩展（两条路线）

1. **遥感候选（子代理 `v2_swamp_candidates.py`）**：DW 淹没植被（A）/ WorldCover 90（B）/ GSW 季节性水+S2 植被（C）→ 去重后 41,740 点 → 中国境内 **29,474** → 过冻结判据 **21,159**（通过率 A 58.9% / B 45.0% / C 95.1%）；热点覆盖三江 4,992 / 太湖口 3,722 / 洞庭 2,867 / 北部湾-海南 2,746 / 辽河 2,596 / 苏北-黄河口 2,512 / 鄱阳 2,183 / 若尔盖 2,060。
2. **湿地复合体加密（`v4` 系列）**：在保留点 3 km 内加密 9,584 个新点（2,211 个复合体）→ 过判据 **2,765**（木本 1,606 / 草本 1,159）。
3. **OSM 湿地（独立矢量源，子代理交付 56,149 要素）**：中国境内 9,622 → 目标子集 **2,684**（`wetland=swamp` 208 木本 / `marsh|reedbed|wet_meadow|fen|bog|无值` 2,476 草本；`tidalflat|mangrove|saltmarsh` 等属他类排除）→ 过冻结判据 1,289 → **植被守门**（`trees+grass≥0.15` 或 `flooded_veg≥0.10`，剔除大湿地质心落水 252 个）→ 采纳 1,037 → 与成品 ≥1km 去重 → **新增 702（木本 44 / 草本 658）**。
   **OSM 的价值**：`wetland=swamp` 标签给"木本沼泽"提供了**独立的分型标注**（弥补 DW trees 分型弱的短板）；另：OSM 抓取的 82.9% 要素落在 bbox 内境外（中亚/西伯利亚湖区），境内仅 9,622。

## 八、局限（诚实清单）

1. **木本/草本分型弱**：DW trees 在两类间仅 0.08 vs 0.10（doc 54：湿地轴 0.708 不可分）→ 分型仅供参考；若生产侧可接受，建议按 doc 54 的"湿地合并 1 类 + 水体独立"口径使用，或对 14/15 类做合并报告。
2. 候选点用**轻量地形层**（dem/slope/relief500）替代 relief2000（半径 67 focal 在 GEE 交互式 API 下持续超时）；D 条件以 `relief500 ≤ 8` 替代（在保留集上保守）。
3. 加密/候选点的 `prov` 未回填（点级省归属可后续用 `k19_provattrib` 一次补齐）。
4. OSM 分型标签（swamp/marsh）本身也是众包质量（中国境内 swamp 仅 208 个）；已过同一冻结判据+植被守门，视为**补充点**（type_src=`osm_*_tag` 可筛）。
