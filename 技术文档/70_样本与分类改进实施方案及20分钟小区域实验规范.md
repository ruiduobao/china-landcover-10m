# 70. 样本与分类改进实施方案及 20 分钟小区域实验规范

> 建立日期：2026-10-15。执行依据：[文档 69](69_三省两轮分类与样本质量综合评价及改进建议.md)。
> 状态：**实施规范 v1.0；必须在首个分类实验启动前冻结**。实际范围、样本数和脚本指纹由实验注册表在运行前补齐；结果另写文档 71，不回改本规范中的原始判据。
> 用户授权范围：实施文档、相关实验代码／配置实际修改、若干小区域分类实验、统计与结果汇总；不涉及全国放量或覆盖既有省域交付。
> 分工：子 agent 承担全部资源检查、数据处理、代码实现、分类、计时、统计和独立复核；主 agent 综合判断、冻结实施规范、编写结论。

## 1. 目标及“提升”的操作定义

本轮目标是把文档 69 的优先问题转成能够运行、能够在 20 分钟内结束、能够拒绝无效方案的实施链，而不是同时改动所有样本后再整省重产。

具体目标为：

1. 以独立实验驱动实现平面裁剪／导出、原生网格和有效输入掩膜检查，验证规则纬线空白的几何修复。
2. 在四川、广东、宁夏已有开发参考覆盖的小区域，检验园地数量上限、森林筛选及地形代表性是否改善分类。
3. 实现来源命名空间安全的剔除、实际抽样 ID 留痕、同点评价、来源分层及超时控制；避免沿用已知的编号误剔与评价口径混用。
4. 形成实测结果、失败与超时记录、候选配置及明确的采纳／拒绝结论。

**不能预先保证未运行的算法提高真实精度。** 本轮将“保证提升”落实为：只有达到预注册改善门且未引入明显退化的方案才能进入候选配置；未过门时保持基线，不用删除不利参考点、反复窥视确认集或调整指标来制造增益。工程覆盖改善与分类标签一致率改善分别验收，均不自动外推为独立省域真实精度。

## 2. 实施范围与边界

### 2.1 本轮覆盖

- 年份：2023。
- 分类体系：沿用 24 类紧凑码空间；第二轮池实际含 23 类、缺类 8。所有评价采用一致类别表，不能对新池再套 30→24 映射。
- 区域：四川秦岭窗 w2 内至少两个小框，广东 w3 和宁夏 w4 内各至少一个小框；另设四川约 30°N 已定位缺口的小幅连续制图区域。
- 小框优先 0.5°–1°，由参考点支持决定；几何制图框优先 0.02°–0.05°，以下载和推理能够在截止前完成为前提。
- 训练抽样框：小框所属生产 2°瓦片各向外扩 2°，每模型最多 20,000 点。推理／评价只覆盖已注册的小框，不据此称完成整瓦或省域生产。

### 2.2 本轮暂不执行

不启动全国或整省重生产，不更改冻结母库，不覆盖第一／第二轮交付，不开展未经独立标签支持的东北万人级补样，不把尚缺的人工林型判读冒充已完成。东北稀疏植被定向补样和三省概率真值集保留为下一阶段工作包，理由及前置条件写入结果报告。

## 3. 资源与时间控制

### 3.1 本机与云端资源

采用本地 Python、numpy/pandas/pyarrow、scikit-learn、rasterio 及项目既有地理依赖；GEE 仅由几何实验子 agent 独占一个经串行项目健康检查通过的账号。RF 本地计算全程一次只运行一个重活，默认 `n_jobs=10`，全局 CPU 不超过 15 核，内存目标上限 10 GB。

GEE 凭证始终使用仓库外既有目录。代理及项目状态必须实际检查，不能仅凭历史健康记录。只允许小幅交互式请求；本轮不启动需要不可控排队的长 batch。请求设置超时与请求体限制，不以后台继续跑规避截止时间。

### 3.2 每个实验的 20 分钟定义

- 实验单元＝一个已注册区域×一个已注册训练／推理方案×预注册种子集合，通常三种子 `{7,11,23}`。不能运行后把一个超时实验拆成三个“均达标”的种子实验。
- **训练开始到推理、评价和本实验结果落盘结束，wall-clock ≤1,200 秒。** 云端调用等待、网络重试、下载、评价均计入。
- 数据准备单独记录总耗时；读取／筛选可共享缓存，但必须在报告中披露，不能借“准备”隐藏训练或模型调参。
- 监督进程设置硬超时，达到截止终止自己启动的子进程，记录 `TIMEOUT`、退出码、已完成阶段和残留检查。不清理其他会话或无关进程。
- 基线与候选各有独立计时记录；完整配对统计归为汇总步骤，另报耗时，不能把逐实验应有评价全部移到汇总以逃避限时。
- 若三种子规模不能在截止内完成，保留超时事实；缩小区域、减少点数或降至工程 2,000 点必须作为**新的预注册降级实验**，不能覆盖失败记录或声称等价原生产配置。

### 3.3 顺序与预计安排

下表为计划工时，不是已经完成的耗时，不作无人等待的日历承诺。

## 4. 必须先实施的代码与配置修改

### 4.1 限时、锁和结果注册

新增统一 runner，负责单实例／资源锁、超时、原子 JSON、stdout/stderr 日志和退出记录。每条注册至少包含：

`experiment_id、region_bbox、tile_id、training_bbox、input_identity、class_map_hash、candidate_rule、seeds、n_train_limit、rf_params、deadline_s、development_ids、confirmation_ids、target_metrics、expected_effect、stop_rules、code_hash、registered_at`。

范围、评价类别、种子、规则阈值在读预测前冻结。允许修纯工程 bug，但保留原运行记录，代码指纹变化时建新版本或注明修复后重跑，禁止悄悄覆盖旧结果。

### 4.2 命名空间安全样本视图

新增 `sample_uid=(dataset_namespace, original_id, year)` 或等价稳定字符串；`origin_row_id` 单列。只有明确源自母库 `row_id` 的字段可直接对母库编号清单排除。园地自有 uid 不得只因数字相同就当同一母库点。

所有来源仍统一做坐标／原生像元与保留空间块排除，检查跨类同位冲突。此改动先用小型自检与实验视图验证，不自动回填 4,238 个误剔点进入现有冻结池。字段缺失采用显式状态，不将未知质量或来源填成“高质量”。

### 4.3 公平样本抽样与局部分类

冻结 RF 为 100 树、minLeaf=2、maxNodes=5000、最多 20,000 点、64维 AEF、三个配对种子；本地与 GEE 参数语义核对后使用。sklearn RF 是本地筛选器，不能声称与 smileRF 完全等价。

基线使用新池原样的局部随机抽样。候选仅改变单一机制：

- **O-CAP 园地数量上限**：在局部 20,000 点中，类 2 上限固定为 **1%（最多200点）**，不足则保留全部；非园地按同一空间框与冻结种子补足总量。该规则有意改变类别先验，应明确评价园地遗漏与森林／耕地收益，不能声称“只提高了标签质量”。本轮不搜索多个比例以挑高分。
- **F-VIEW 森林筛选对照**：如果质量侧表回接可靠，森林 clean／strict 或旧全量视图保持每类相同抽样数，非森林选择不变；当 strict 不足时记录不足并停止该臂或按预注册公共支持范围比较，不额外重复点补数。
- **T-STRATA 地形代表性**：同每类 count，在可用 DEM 支持域内按高程带与坡向分层限制聚集；以独立标签条件错误或开发参考条件错误评价。不强制真实林型的阴阳坡比为1，不以地图OR下降当改善。

每臂输出选中点ID、候选池类别计数、每类实际训练数、来源回接率和空间块分布。本地固定 RNG 仅统计复现抽样机制，不是复现 GEE `randomColumn` 的逐点选择。

### 4.4 几何与连续制图

新增实际启用的平面几何 helper／实验驱动：`clip` 与 `region` 使用同一显式平面矩形，网格使用已验证的 `crsTransform`；与 `scale` 互斥参数正确处理。默认生产 c3 不直接改写，新实验驱动可明确选择 legacy-geodesic 或 planar。

同一模型／训练选择对小幅真实 AEF 分类，输出 legacy 与 planar GeoTIFF、原始64波段共同有效输入 mask、恢复像元 mask及类码比较表。有效输入 mask 不先应用旧错误裁剪。若仅有本地真实 AEF缓存，分类与几何模拟验证分别标注；不能将模拟图当真实云端修复。

类别栅格用最近邻、uint8、nodata=0、正确码表。小图无需为形式制作概览；一旦包含交付概览，只允许项目 ov_build＋PIL验收链。

## 6. 参考数据与评价实施

### 6.1 参考集角色

五窗参考点是多轮使用的教师标签开发集，不是新的独立人工真值。本轮按空间块一次拆成**本轮开发选择部分与本轮确认部分**；确认标签不用于调整阈值或挑臂，但不能因此称其恢复为最终盲测真值。

可将0.25°或0.5°空间块按稳定哈希固定分组，目标约60%开发／40%确认；选择块尺度由范围与有效块数在注册前确定。不为凑比例打散同块，也不将类别稀少的确认点复制。样本不足时报告支持不足，合并区域或仅作诊断，不制造窄区间。

### 6.2 同点与来源分层

所有臂共用相同参考点、类表及无数据规则。全点、FCS10、非FCS10分别报告；不删除不利来源。OA24为细类标签一致率，macro9按项目既有映射归并；十组另报时必须明确。

输出各类参考n、预测n、UA=precision、PA=recall、F1、固定labels的macro-F1；原始无数据单列。分类图的一致率、覆盖率和标签一致率分别命名。

### 6.3 不确定性

以配对预测差作空间块bootstrap，记录有效块数、重采样次数、三个种子均值与离散度。不能把跨种子波动和空间抽样CI混为同一统计量。少于30个有效空间块时，CI仅作该框描述，不能声称省域泛化；类参考n<30不作类级达标声明。

## 8. 风险与应对

| 风险 | 后果 | 应对 |
|---|---|---|
| 园地参考稀少、教师惯例与真实管理地块不一致 | 压缩园地可能提高开发OA却丧失真实园地 | 固定全类评价、单列园地UA／PA、独立资料确认后再推广 |
| 阴阳坡真实生态差异 | 平衡抽样可能抹掉正确结构 | 不以OR为唯一门，同量对照、独立配对判读仍保留为后续 |
| 本地RF与GEE差异 | 本地收益不迁移 | 结果限定本地筛选；有条件小幅GEE复核，不将两种模型混称 |
| GEE代理、项目受限、交互内存墙 | 实验超时或无输出 | 健康检查、硬截止、不排batch；降级路线预注册并明确非原生产配置 |
| 确认集信息泄漏、多方案择优 | 增益虚高 | 拆分／阈值先冻结、有限臂、确认只一次、全部结果报告 |
| 原几何同时影响训练窗 | 修推理时样本也变 | 几何实验固定训练选择；训练filterBounds修改单列，不混入纯覆盖改善 |
| 有效mask沿用错误几何 | 覆盖自证通过 | 原AEF全波段共同mask、不先clip、已验证平面region与固定grid |
| 多agent资源冲突 | 单实验超20min、内存超限 | 全局RF锁、串行slot、内存守卫，只终止自己任务 |
| 最新交付与冻结快照差异 | 实验无法追溯 | 原池只读，必要输入hash和mtime，来源侧表匹配率明报 |
