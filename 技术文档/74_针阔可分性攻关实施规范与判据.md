# 74. 针叶/阔叶可分性攻关 · 实施规范与预注册判据

> 日期：2026-10-15。目标（用户给定）：**解决针叶林与阔叶林混淆、可分度不高的问题，消除"针叶林按阴阳坡分裂"的伪影，使结果能支撑 2017–2024 逐年景观分类。**
> 状态：规范与判据**在实验执行前冻结**；后续只填实测值，不改判据。结果写文档 75。
> 分工：子 agent 承担全部计算、取数、评测与统计；主 agent 负责判据、证据裁决与结论。

## 1. 失败与成功的客观判据（先写死）

### 1.0 已实测的关键前提：标签坡向偏差（必须先看）

在评测前应知道一个已实测事实（本轮本地复算，证据 `F:/lc_work/nb_sep_2026/recon/关键证据_标签坡向偏差与AUC落差.json`）：

- **训练池标签本身即按坡向对立**：三个四川瓦片（slope>5°）上 ENF 的阴/阳坡点数为 738:109、1622:90、572:53，对应 ENF/EBF 阴阳坡 **OR = 2.64 / 6.64 / 4.32**，与文档69 记录的池标签 OR≈5.28 同向。
- **AEF64 在我们自己的标签上可分性极高**：ENF vs EBF AUC **0.976**、针/阔总体 **0.972**、常绿/落叶 **0.990**；林地质检 strict 表上 ENF vs EBF 为 0.961。
- **但文档54 用人工判读真值测针/阔仅 AUC 0.724。**

由此形成的待验假设：**高 AUC 可能是"标签按坡向系统性错标 + AEF 含地形光照"的假象**——模型学会了区分被错标的标签，而非真实针阔；这正好表现为成品"针叶林按阴阳坡分裂"。

因此本轮所有可分性结论都必须区分两种口径：

| 口径 | 含义 | 能否用于宣称"可分" |
|---|---|---|
| 池标签可分性（AUC≈0.97） | 我们自己标签上的可分性 | **不能**（可能含标签偏差） |
| 独立真值可分性（doc54 人工真值 0.724） | 外部/独立判读下的可分性 | 能（本轮须用外部产品与独立标签重测） |

后续评测若只在池标签上得高分，**不得**据此宣称针阔已可分；必须在独立参照（外部产品一致集或人工判读集）上达到 §1.1 门槛。

### 1.1 可分性（核心）

| 任务 | 基线（已知） | 成功门槛 | 测量口径 |
|---|---:|---:|---|
| 常绿/落叶（全林） | AUC ≈0.990（doc54） | 保持 ≥0.95 | 同批高置信点，五折分层 CV，固定种子，报多种子均值±sd |
| **针/阔（总体：ENF+DNF vs EBF+DBF）** | **AUC ≈0.724（doc54，AEF64）** | **≥0.85 且 PR-AUC ≥0.75** | 同上 |
| **常绿层内 ENF vs EBF（最难）** | ≈0.724（含在总体） | **≥0.80 且 macro-F1 ≥0.65** | 同上，单独评 |
| 落叶层内 DNF vs DBF | 未测 | ≥0.80 | 同上（DNF 样本少则标"支持不足"） |

说明：0.85 是本轮自定的"可分"门槛（区别于"完全不可分"0.5 与"高度可分"0.95）。若达不到，则**不宣称解决**，应转向层级/合并/附加层策略（§4）。

### 1.2 坡向伪影消除

- 判据1：成品上 ENF/EBF 阴阳坡 **OR 从 ≈3.1 降到 ≤1.5**（OR=(ENF阴/ENF阳)/(EBF阴/EBF阳)，正确坡向公式）。
- 判据2：在**外部多产品一致判为同一林型**的阴阳坡成对点上，我方预测的条件错误率在阴坡与阳坡之差 **≤5 个百分点**。
- 判据3：**不得通过强制配平抹掉真实生态结构**——若外部独立产品也显示 ENF 偏阴坡（即真实生态），则判据1/2 应改为"与生态一致"而非"OR≈1"，并在报告中说明，不以人为配平制造达标。

### 1.3 年度支撑（2017–2024）

- 判据4：推荐特征集在 **8 年每一年均可获得**（不含仅 2019–2023 的 GEDI 等作为必需项；GEDI 类结构特征只能作为"可用年份增强"，须有降级替代）。
- 判据5：逐年标签继承规则下，**每年可用样本点 ≥ 基准年(2023) 的 70%**，且每年林型标签有物候证据支持的点占比 ≥60%。
- 判据6：逐年结果跨年跳变率（相邻年同一像元林型改变且无变化证据）**≤5%**。

## 2. 数据与方法边界（必须遵守的现有纪律）

1. **母库冻结**（2,252,207 点，MD5 `11920eef…`）只读；任何样本操作只在训练/评估视图。
2. **类别栅格**一切派生/统计必须显式 `nearest`，面积以 10 m 原生网格为准。
3. **不能对 AEF64 做地形辐射校正**（AEF 是嵌入，非物理反射率）；C 校正/SCS+C/Minnaert 只能用于新增的 S2 SR 光学特征臂或指数。
4. **高分底图无拍摄日期**：常绿/落叶与针阔不得由无日期影像直接判定；物候结论必须由带日期的年度时序（S2 月合成/冬夏）支撑。
5. **盲判复判教训**（文档73）：10 m 无日期影像结构判读一致率仅 0.487、否定审计 0.360 → **不得用单遍判读造标签**；本轮标签走"多源一致 + 物候自洽"的交叉验证。
6. GEE：用前串行项目健康检查、单账号独占不与其它 agent 争号；`Image.sampleRegions` 的 Python API **没有 dropNulls**（丢任一 null 的点），改用 `reduceRegions(ee.Reducer.first(), scale, tileScale)` 或逐源 unmask；大图下载用 geefast 原生 getPixels + 资产 affine 对齐。
7. 单次种子噪声 ±1.5pp，<2pp 增益需多种子配对验证；本轮所有可分性指标报多种子均值±标准差。
8. 本地 RF ≠ GEE smileRF；本地结论为筛选证据，最终需在 GEE 服务端复核。

## 4. 若可分性门槛达不到的备选策略（预注册，不是失败掩盖）

1. **层级输出**：主图只保证"常绿林/落叶林"（证据强），针/阔作为**附加类型层**或专题产品，并标注置信/证据等级。
2. **合并口径**：把 ENF/EBF 在证据不足区域合并为"常绿林"，DNF/DBF 合并为"落叶林"，按生态区决定是否展开。
3. **混交表达**：输出混交度/优势型概率，而不是硬分纯林型（尤其码 8 针阔混交在新池缺失）。
4. **生态规则后处理**：用生态可能性约束（如高海拔/坡向/气候带）降低明显不可能的组合，但**不能把真实生态对立当成错误强行抹平**。

采用上述任一项时，必须写明"哪些区域/年份可展开到针阔、哪些只能到常绿/落叶"，不得整体宣称四类均已可分。
