## §0 摘要（五条）

1. **属性已添加，且不需要新建类别**：GLC_FCS10 的官方码表本身就编码了常绿/落叶——`51/52` 常绿阔叶、`61/62` 落叶阔叶、`71/72` 常绿针叶、`81/82` 落叶针叶（奇=郁闭、偶=稀疏）。因此"添加属性"是**从既有 `fcs10_raw` 派生**，而非重新分类。分布：**常绿 52,801 / 落叶 56,459 / 混交 1,393**。
2. **新增字段 7 个**（原有列全部保留）：`habit_fcs10`（常绿/落叶）、`canopy_fcs10`（郁闭/稀疏）、`leaf_fcs10`（针/阔）、`habit_pheno`（S2 物候侧建议值）、`habit_grade`（一致性等级）、`habit_pheno_src`（证据来源）、以及物候原始量 `v2019/v2023/amp2019/amp2023/djf2019/djf2023`。
3. **与独立 S2 物候的一致率 0.6204**（n=100,757 可评估）。交叉表显示方向不对称：**落叶→常绿 10,406 点 vs 常绿→落叶 5,005 点**，即物候比 FCS10 更倾向判"常绿"。
4. **冲突高度结构化，不是随机噪声**：按码拆开后 `51` 一致率 **0.918**、`71` **0.877**（两类"常绿"都很可靠）；而 `61` 只有 **0.443**、`81` **0.266**。其中 `81` 落叶针叶里被判"常绿"的 5,894 点，**84% 在西南/青藏、海拔中位 2,598 m**（判落叶的那批海拔中位仅 1,004 m、集中在东北）。
5. **结论：FCS10 的常绿/落叶轴在"常绿"方向可信，在"落叶"方向（尤其山地针叶）系统性漏标。** 建议按此不确定度分级使用，而不是二选一。A/B/C 三方案见 §5，**本轮不做最终裁决**（预注册纪律）。

## §2 实现与判据（预注册，写死）

### 2.1 派生规则 R0（基础属性）

`habit_fcs10` 直接由 `fcs10_raw` 映射：`{51,52,71,72}→evergreen`、`{61,62,81,82}→deciduous`、`{91,92}→mixed`。
`canopy_fcs10`：奇数→closed、偶数→open。
`leaf_fcs10`：`{51,52,61,62}→broad`、`{71,72,81,82}→needle`。

### 2.2 一致性等级 R1（`habit_grade`）

| 等级 | 定义 | n |
|---|---|---:|
| `E2E` | FCS10 与 S2 结论**一致** | **62,507** |
| `E2C` | FCS10 与 S2 结论**冲突** | **38,250** |
| `E2U` | 无物候证据（S2 两年未同时判出且无年振幅） | **8,503** |
| `E2M` | 混交林（91/92），不判常绿/落叶 | **1,393** |

S2 侧证据来源分两级（`habit_pheno_src`）：
- `s2_two_year`（52,395 点）：2019 与 2023 **两年都判出且自一致** → 最强证据；
- `s2_amp_thr350`（48,552 点）：两年未同时判出，但 `amp2023` 有值 → 用**年振幅阈值 350** 判定。

**阈值 350 的来历**（阈值扫描，`amp2023` vs FCS10）：

| 阈值 | 与 FCS10 一致率 |
|---:|---:|
| 250 | 0.8361 |
| 300 | 0.8508 |
| **350** | **0.8567** ← 峰值 |
| 400 | 0.8541 |
| 450 | 0.8436 |

`amp2023` 单变量对"常绿"的 AUC = **0.9553**（`amp2019` 是 0.9997，但那是因为 `v2019` 本来就由它截断而来，**循环**，故不作为独立证据）。

### 2.3 一个必须说明的实现缺陷（已修）

首版把 `habit_pheno` 先写成字符串 `'unknown'` 再参与比较，导致 `E2P` 档全部误标为 `E2C`（一致率被压到 0.4518）。修正为**逐元素布尔比较** `(amp2023 < 350) & (habit_fcs10 == 'evergreen')` 后，一致率回到 **0.6204**。留此记录以防后续复现时误读。

## §3 结果

### 3.1 属性分布（全国 110,653 点）

| 属性 | 类别 | 点数 | 占比 |
|---|---|---:|---:|
| `habit_fcs10` | 常绿 evergreen | **52,801** | 47.7% |
| | 落叶 deciduous | **56,459** | 51.0% |
| | 混交 mixed | 1,393 | 1.3% |
| `canopy_fcs10` | 郁闭 closed | **105,892** | 95.7% |
| | 稀疏 open | **3,368** | 3.0% |
| | 混交 | 1,393 | 1.3% |

**郁闭/稀疏极度不平衡（95.7 : 3.0）**——这印证了 doc77 §6 的结论：稀疏林在 FCS10 中本就稀少，且"郁闭/稀疏"轴对针阔判别 **AUC=0.500（完全无效）**。因此 `canopy_fcs10` 只能作描述性属性，不可作分类依据。

### 3.2 与 S2 物候的一致性

|---|---:|---:|
| **全体纯林** | 100,757 | **0.6204** |

**读法（重要）**：

### 3.4 冲突的地理结构（决定性证据）

| 亚组 | n | 主要省份 | 海拔中位 |

## §4 交付物与字段说明

`labels/needle_broad_national_v2_habit.parquet`（110,653 行 × 37 列：v2 原 25 列 + 新增 12 列）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `habit_fcs10` | str | **`evergreen` / `deciduous` / `mixed`** —— 主属性，来自 FCS10 官方图例 |
| `canopy_fcs10` | str | `closed` / `open` / `mixed` —— 郁闭度轴，**不可用于分类**（AUC=0.500） |
| `leaf_fcs10` | str | `needle` / `broad` / `mixed` —— 校验列，与既有 `leaf` 应完全一致 |
| `habit_pheno` | str | S2 物候侧建议值（`evergreen`/`deciduous`/`unknown`），**仅供参考** |
| `habit_pheno_src` | str | `s2_two_year`（强）/ `s2_amp_thr350`（弱）/ `unknown` |
| `habit_grade` | str | **`E2E` 一致 / `E2C` 冲突 / `E2U` 无证据 / `E2M` 混交** |
| `v2019` `v2023` | str | S2 两年离散结论（`E`/`D`/空） |
| `amp2019` `amp2023` | float | NDVI 年振幅（×10000） |
| `djf2019` `djf2023` | float | 冬季（12–2 月）NDVI |

**使用建议（按可信度）**：
- **可直接用**：`habit_grade == 'E2E'`（62,507 点，双源一致）；
- **需谨慎**：`E2C`（38,250 点），其中 `51`/`71` 码的 E2C 应倾向信 FCS10，`81` 码在西南/青藏应倾向信物候；
- **不可用**：`E2U`（8,503 点）与 `E2M`（1,393 点）。

## §9 C 方案规则草案（已用实测校准，仍待批准）

若用户选 C（分级融合），建议采用下列规则。**每条阈值都有一个实测支撑列**，不是拍脑袋：

| # | 条件 | 判定 | 实测支撑 |
|---:|---|---|---|
| 1 | `habit_grade == 'E2E'` | 直接采用 FCS10 | 62,507 点双源一致 |
| 2 | `fcs10_raw ∈ {51, 71}` 且 E2C | **信 FCS10**（常绿） | 51 一致率 0.917、71 为 0.877；常绿码本身可信 |
| 3 | `fcs10_raw == 81` 且 `djf2023 < 450` | **信物候**（落叶） | 81 码内 73.1% 满足；其中物候判落叶 **92.9%** |
| 4 | `fcs10_raw == 61` 且 E2C | **信 FCS10**（落叶） | 61 码物候判常绿仅 15.2%，属个别混交 |
| 5 | 南方湿润区（重/浙/粤/琼/鄂/桂）E2C | `djf2023 < 450` 信物候，否则信 FCS10 | 该带 djf 中位 720（与其他省 710 持平），918 点 `djf` 中位 405 是真落叶 |
| 6 | 其余 E2C | 保持 FCS10，标 `habit_conflict=1` | 保守 |
| 7 | `E2U` / `E2M` | `habit = habit_fcs10`，标 `habit_confidence=low` | 无证据时不引入假设 |

**两条阈值对比（在 100,757 可评估点上复现物候结论的能力）**：
`amp2023 < 350` 复现率 **0.9815**；`djf2023 > 450` 复现率 **0.9425**。两者高度一致（因为它们本就同源），故规则 3/5 用 `djf` 只是便于解释，**不构成独立证据**。
