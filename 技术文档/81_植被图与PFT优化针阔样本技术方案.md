# 81. 用植被图与森林 PFT 数据集优化针阔样本：技术方案

> 2026-10-24。用户提供两份独立外部数据集（`数据/外部数据/`），要求优化针叶/阔叶样本的**数量、质量、分布**。
> 本方案先写死判据（预注册），再执行。结果写入文档 82。

## §1 两份数据的性质与定位（先定性，再谈怎么用）

### 1.1 《2020 年中国 100 万植被图》（矢量，68,756 个图斑）

| 项 | 内容 |
|---|---|
| 来源 | 侯学煜、张新时等三代、200 余位科学家，**30 余年地面实地调查**汇总 |
| 精度 | 11 个植被类型组、55 个植被型、**960 个群系/亚群系**、2,000+ 群落优势种 |
| 关键字段 | **`生活型`**（直接给"常绿针叶/落叶阔叶"等）、`植被型`、`植被亚型`、**`植被类型`**（到群系甚至优势种） |
| CRS | `GCS_Assumed_Geographic_1`（Clarke 1866 / NAD27 假定地理）——**需核对是否与 WGS84 一致** |
| 可直接用的类 | 纯针叶 **12,824** 单元（常绿针叶 12,253 + 落叶针叶 571）、纯阔叶 **19,185** 单元（落叶阔叶 10,132 + 常绿阔叶 9,053） |

**这是本项目至今最强的独立标签源**：它不是遥感反演产品，而是**地面调查 + 专家综合**，与 FCS10（遥感）、CGLS（遥感）、Aprobit（模型）**在方法论上完全独立**。

**针叶内部构成（决定性）**：

| 植被类型 | 图斑数 |
|---|---:|
| **马尾松林** | **4,897** |
| 杉木林 | 1,481 |
| 油松林 | 733 |
| 云南松林 | 651 |
| 黑松林 | 415 |
| 川西云杉林 | 340 |
| 华山松林 | 259 |
| 侧柏林 | 253 |
| 雪岭云杉林 | 245 |

→ **马尾松 + 杉木 = 6,378 个图斑，占纯针叶的 49.7%，全在南方**。这正好击中 doc77 §13 与 doc80 §3 的死结：南方真针叶到底有多少。植被图说：**南方有大量马尾松林/杉木林**。

### 1.2 China Forest Dataset v1.0（1 km 栅格，1980–2023）

| 产品 | 年份 | 内容 |
|---|---|---|
| `1_Forest_Cover_Annual` | 1980–**2023** | 森林/非森林二值 |
| `2_PFT_Annual` | 1981–**2013** | **8 类 PFT 二值**：ENF_boreal / ENF_temperate / DNF / EBF_temperate / EBF_tropical / DBF_boreal / DBF_temperate / DBF_tropical |
| `3_Forest_Change_Gain` | 1980–2023 | 增益起始年 + 持续年数 |
| `4_Forest_Change_Loss` | 1980–2023 | 损失起始年 + 持续年数 |
| `5/6_PFT_Change_Gain/Loss` | 1981–2013 | 8 类 PFT 的增减事件 |

**关键限制（必须承认）**：**PFT 只到 2013 年**，而我们的目标是 2017–2024。因此：
- **PFT 不能作为 2017–2024 的当期标签**；
- 但可作为 **① 长期稳定性证据**（1981–2013 一直是针叶的像元，2017 年多半还是针叶）、**② 变化事件过滤**（2014 年后有 forest gain 的像元，2013 年 PFT 不可信）。

**8 类 PFT → 我们的 2 类映射**：

| PFT | 映射 |
|---|---|
| ENF_boreal, ENF_temperate | **needle** |
| DNF | **needle** |
| EBF_temperate, EBF_tropical | **broad** |
| DBF_boreal, DBF_temperate, DBF_tropical | **broad** |

## §2 核心设计：两源如何分工

两份数据的**时间分辨率与空间分辨率不同**，所以不能同等对待：

| 数据 | 时间 | 空间 | 角色 |
|---|---|---|---|
| **植被图 2020** | **2020（贴近我们的 2017–2024）** | 矢量（图斑边界，1:100 万） | **主标签源**（做"候选区"和"标签"） |
| **PFT 1981–2013** | 历史（距今 ≥11 年） | 1 km | **稳定性证据层**（做"过滤"和"加权"） |

### 2.1 四级漏斗（与 doc79 同构，但换成植被图主导）

```
L0  植被图纯针叶 / 纯阔叶图斑          （12,824 / 19,185 个图斑）
     ↓ 矢量栅格化到 10 m（或点级 point-in-polygon）
L1  图斑内部腐蚀（去掉边界带）          ← 对应 doc79 的"连续区核心"
     ↓
L2  PFT 长期稳定性过滤（1981–2013）     ← 新增，PFT 唯一真正不可替代的作用
     ↓
L3  2014 年后变化事件过滤（forest gain/loss）
     ↓
L4  我方 AEF 森林掩膜（p_forest ≥ 0.5）
     ↓
L5  撒 10 m 点（每 100 m 格 ≤1 点 + 0.01° 去聚团）
```

### 2.2 逐级判据（预注册，跑完不改）

| 编号 | 判据 | 门槛 | 理由 |
|---|---|---|---|
| **V1** | 植被图 CRS 与 WGS84 的偏移 | **< 500 m**（中位） | 若超 500 m 则该图不能用，须先做地理配准 |
| **V2** | 与 FCS10 的针阔一致率 | **≥ 0.80** | 比 CGLS 的 0.75 门更严——植被图是地面调查，理应更准 |
| **V3** | 与 PFT(2013) 的针阔一致率 | **≥ 0.70** | 两者独立，一致即双源确认 |
| **V4** | 影像核查（S2 真彩色 + 物候）确认率 | **≥ 0.85** | 高于 CGLS 的 0.80——植被图声称高质量，须配高门槛 |
| **V5** | **南方针叶新增量**（粤/闽/桂/浙/湘/赣） | **≥ 3,000 点** | 直接解 doc77 §13 / doc80 §3 的死结 |
| **V6** | 与 v2 的空间重叠（0.01° 格） | **≤ 5%** | 要扩出新信息 |
| **V7** | 新增覆盖瓦片 | **≥ +15 瓦** | 低于 doc79 的 +20（因 v2 已 248 瓦，边际递减） |
| **V8** | 卫生 | 0 重复 / 0 NaN / 0 越界 | 同 v2 |
| **V9** | **不覆盖 v2 主样本** | 强制 | 新样本另建文件，标 `src=vegmap2020` / `src=pft2013` |

### 2.3 与 doc79（CGLS）的关键差异

doc79 失败的原因是**CGLS 与 FCS10 同属遥感产品，且南方针叶互斥（一致率 1.51%）**。本轮不同：
- 植被图是**地面调查**，不是遥感反演 → 与 FCS10 的误差机制不同源；
- 植被图**有群系级信息**（马尾松林 vs 杉木林），可以直接验证"南方那些 FCS10 判为常绿阔叶的点是否真是马尾松林"。

**如果 V2 仍 <0.80 且南方针叶仍互斥，那说明 FCS10 与植被图两方有一方系统性错误，本轮就要给出"是哪一方"的判据**（见 §4）。

## §4 若是两源冲突：裁决设计（提前写死）

若 V2 <0.80，必须回答"谁错了"。预注册裁决规则：

| 情形 | 判据 | 处置 |
|---|---|---|
| 植被图与 PFT 一致（V3≥0.70）但与 FCS10 不一致 | 两独立源 vs 一源 | **信植被图+PFT**，FCS10 在该子集判为"可疑" |
| 植被图与 FCS10 一致但与 PFT 不一致 | — | 信植被图+FCS10（PFT 太老） |
| 三者两两都不一致 | — | **该子集判为"真值不明"，不进训练** |
| 南方针叶专项：植被图说针叶、FCS10 说阔叶 | 用 S2 物候 + 冠层高度（GEDI）仲裁 | 见 Q4 |

## §5 资源预算

| 项 | 预算 |
|---|---|
| 植被图读取 | 68,756 图斑，84 MB shp，内存约 1–2 GB |
| 栅格化 | 全国 10 m 太贵 → **只在 v2 的 248 瓦 + 候选新增瓦上做**，vec→raster 用 `rasterio.features.rasterize`，逐瓦处理 |
| PFT 读取 | 8 类 × 1 km，每文件 4254×3580 uint8 ≈ 15 MB；全部读入 <200 MB |
| GEE（影像核查） | 若 V2/V3 过门才做；预估 < 80 EECU·h |
| 时间 | Q1 20 min、Q3 15 min、Q2 40 min、Q4 60 min、Q5 20 min |
| 本机限制 | **CPU ≤10 核、内存 ≤30 GB**；单进程串行；启动前扫 `Get-Process python` 去重 |

## §6 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| **植被图 CRS 是假定地理系（Clarke1866/NAD27）** | 若与 WGS84 有系统偏移，点位全错 | **V1 门必须先过**；用已知地标（城市/湖岸）交叉核对 |
| 植被图是 1:100 万，图斑边界粗略（最小图斑可能几十 km²） | 边界处混类 | L1 腐蚀；点只取图斑内部 |
| 植被图年代是"2020 年前后调查汇总"，不是单年 | 与我们 2017–2024 有偏移 | 用 PFT 1981–2013 + 变化事件交叉；不做逐年声明 |
| PFT 只到 2013 | 无法做当期标签 | **只作稳定性证据**，不作标签 |
| 植被图对人工林（杉木/马尾松）的分类口径与遥感不同 | 可能把"疏林/幼林"算作森林 | V4 影像核查，剔除不符合乔木林的 |
| 南方针叶仍不足 | V5 不过 | 如实报告，不改判据 |

## §8 一句话交接

**植被图（地面调查，含马尾松林 4,897 图斑）是比 CGLS 更可信的独立标签源，PFT(1981–2013) 只能作长期稳定性证据**；方案为"植被图图斑→内部腐蚀→PFT 稳定性→变化事件→AEF 森林掩膜→10 m 撒点"五级漏斗，判据 V1–V9 已预注册（其中 V1 的 CRS 偏移门与 V5 的南方针叶 3,000 点是本轮成败关键）。
