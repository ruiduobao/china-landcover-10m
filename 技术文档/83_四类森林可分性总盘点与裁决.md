# 83. 四类森林（常绿针叶/落叶针叶/常绿阔叶/落叶阔叶）可分性总盘点与裁决

> 2026-10-25。用户指令：区分常绿针叶林、落叶针叶林、常绿阔叶林、落叶阔叶林，"肯定有方法的"。
> 本文做两件事：① 引入 **OlmoEarth v1.3 嵌入**（在线、免账号，全新独立第五源）做实测探针；② 把项目已有全部证据汇总，给出**严格裁决**（哪些能分、哪些不能、为什么）。
> 产物：`F:/lc_work/nb_national_2026/opt/`。**母库、生产池、生产配置、交付件全程未改动。**

## §0 摘要（六条，先说结论）

1. **四类硬分类同图出图：不可行。** 剔除地理混杂后（coregion 子集）四分类 macro-F1 **0.7058**，未达 0.75 门；更致命的是**跨标签源迁移检验**证明不可交付。
2. **但"常绿/落叶"这一维是可靠的真信号**：常绿林 vs 落叶林 coregion **0.8500**（扣掉位置+地形基线后 Δ **+0.136**），doc54 独立人工判读 **0.990**、doc75 空间缓冲后 **0.945** —— 三个来源一致。**这一类可以全国出图，含 2017–2024 逐年。**
3. **"针叶/阔叶"这一维的分数看似不低，但迁移检验判死**：核心证据是用 **12,348 个两源 1 km 内配对点**做跨源迁移 —— 同源训练测试 F1 0.72–0.74，**跨源迁移只有 0.64**，而**两源标签本身一致率就是 0.6356**。即：AEF64 学到的主要是"复现某一套产品的口径"，产品间不一致的部分它学不到。
4. **OlmoEarth 帮不了最想解决的难题**：**落叶松 vs 常绿针叶（ENF vs DNF）在共区域样本上 F1 0.750，低于纯经纬度基线的 0.782**。表观 AUC 0.963 是地理假象——ENF 纬度中位 30.4° vs DNF 48.2°，两类最近距离中位 **356 km**，116 个 DNF 点里只有 11 个在 100 km 内有 ENF。
5. **OlmoEarth 的唯一实质增益在"针/阔"轴**（F1 +0.109、AUC +0.116，200 km 分块检验仍成立），但 **AEF64 在同一批点上达到同等水平（0.730 vs 0.732）**，两者拼接无增益 → **没有理由为生产引入 OlmoEarth**。
6. **本轮发现并修正了一个影响 doc78 核心结论的实现 bug**（详见 §6）：`habit_grade` 的布尔掩码错误使 22,839 个本应一致的点被记为冲突，**一致率 0.6204 → 0.8470**，原"FCS10 落叶方向系统性漏标"表述需下调为"中等可信"。

## §1 OlmoEarth v1.3：接入与实测性能

### 1.1 数据规格（已实测）

| 项 | 值 |
|---|---|
| 位置 | `s3://olmoearth/olmoearth-v1-3-embeddings/embeddings.zarr`，endpoint `https://data.source.coop` |
| 认证 | **完全免账号**（`skip_signature=True`），国内直连无需代理 |
| 组织 | **60 个 UTM 分区**（`utm01`…`utm60`），每组含 `embeddings`/`time`/`x`/`y` |
| 维度 | `(9, 128, H, W)`，**int8**；`time` = **2017–2025 共 9 年** |
| 分辨率 | 10 m，`geoemb:gsd=10.0` |
| 模型 | `allenai/OlmoEarth-v1_3-Base`，源数据 **Sentinel-1 + Sentinel-2 + Landsat** |
| 量化 | `signed_power`：`(abs(q)/127.5)**2.0 * sign(q)`，nodata = −128 |

### 1.2 读取性能（实测，关键工程约束）

| 指标 | 值 |
|---|---|
| chunk | `(1, 64, 256, 256)` |
| **shard** | **`(1, 128, 2048, 2048)` = 20.48 km × 20.48 km** |
| 单 chunk 64 波段 | 5.2 s |
| 单 chunk 128 波段 | **3.26 s 均值**（稳态；中位 3.09、p90 4.20、max 9.37） |
| 大窗读取 | **会超时**（一次读超一个 shard 即 `Body TimedOut`） |
| 传输粒度 | **chunk 级，非 shard 级**：读 1×1×128 仍拉整 256×256×64 chunk（≈4 MB） |

> **工程结论**：OlmoEarth 适合**稀疏点取样**（每点约 3.3 s），不适合密集瓦片式读取。700 点约需 39 分钟；本项目若做全国 10 万点 × 9 年，理论上可行（≈115 MB）但**耗时按点数线性增长**，须分批。

### 2.3 任务 D 的真相：0.963 AUC 是地理假象

- ENF 纬度中位 **30.4°** vs DNF **48.2°**
- 两类**最近距离中位 356 km**；116 个 DNF 点里**只有 11 个**在 100 km 内有 ENF

> **结论：OlmoEarth 无法区分落叶松与常绿针叶。** 这是继 doc82（冬季 VH 崩塌、落叶松物候混淆）之后**第二个独立来源**确认该结论。

### 3.2 三个子问题

**(a) 常绿/落叶是真信号 —— 是，但在两个组内强度不同**

| 组内二分类 | 全量 | **coregion** | coregion Δ(AEF64 vs 位置+地形) |

**(b) 针/阔不可交付 —— 迁移检验判死**

用 **12,348 个两源（FCS10 × 30m植被）1 km 内配对点**：

| 检验 | F1 |
|---|---:|
| 同源训练→测试（FCS10） | 0.7362 |
| 同源训练→测试（veg30） | 0.7197 |
| **跨源迁移 FCS10→veg30** | **0.6426** |
| **跨源迁移 veg30→FCS10** | **0.6387** |
| **两源标签一致率** | **0.6356** |

> **迁移 F1 ≈ 标签一致率** → AEF64 的针/阔判别力主要是"复现某一套产品的口径"，产品间不一致处它学不到。这与 doc75"净叶型信号 0.011"同向，但给出的是**可迁移性上界**。

| 混淆方向 | n | 占错误 | 集中区 | 海拔中位 |

| **D_B → D_N** | 2,421 | 13.0% | 黑龙江/内蒙古/吉林 | 924 m |
| **D_N → D_B** | 2,268 | 12.2% | 内蒙古/黑龙江/河北 | 924 m |

**关键证据**：把 D_N（落叶针叶）按 S2 物候拆开：

| 子集 | n | 海拔中位 | P(预测为 E_N) |

## §6 顺带修正：doc78 的 `habit_grade` bug（已修）

**本节独立于四类问题，但必须报告** —— 它影响 doc78 的核心数字。

### 6.1 bug 机制

`s4_leaf_habit.py` 原式：
```python
v2.loc[need, 'habit_grade'] = np.where((ph_e & f_e)[need], 'E2E', 'E2C')
```
- `ph_e`/`f_e` 是全表布尔数组，`[need]` 先取子集使长度 ≠ `need`；
- **更关键**：`ph_e & f_e` 只在**"两者都判常绿"**时为 True → **落叶方向的"一致"永远拿不到 E2E**。

**修正**：改为双向判等 `(ph_e == f_e)[need]`。

### 6.2 修正前后对照

| 项 | 原报（错） | **修正后** |
|---|---:|---:|
| 总体一致率 | 0.6204 | **0.8470** |
| E2E（一致） | 62,507 | **85,346** |
| E2C（冲突） | 38,250 | **15,411** |
| code 51 常绿阔叶 | 0.9175 | 0.9175（不变） |
| **code 61 落叶阔叶** | 0.4428 | **0.8477** |
| **code 62 落叶阔叶稀疏** | 0.3989 | **0.9928** |
| code 71 常绿针叶 | 0.8771 | 0.8771（不变） |
| **code 81 落叶针叶** | 0.2662 | **0.7113** |
| **code 82 落叶针叶稀疏** | 0.2813 | **0.9273** |

### 6.3 结论调整与影响范围

- ✅ **仍成立**：常绿码 51/71 可信（0.88–0.92）；**81 码内"物候判常绿"那批海拔中位 2,598 m vs 判落叶 1,004 m**（该结论直接用 `habit_pheno` 统计，不经 `habit_grade`，已独立复算）；南方反向带 918 点 `djf` 中位 405。
- ⚠ **需下调**：原"FCS10 落叶方向**系统性漏标/崩塌**"表述**过强** —— 真实一致率 **0.71–0.85**，属"**中等可信**"。
- **影响范围**：`habit_grade` 列**未进入任何训练/生产流程**（全仓库仅 doc78 与该脚本引用），**不影响已交付成品**。修正后的 `needle_broad_national_v2_habit.parquet` 与 `habit_stats.json` 已重写，doc78 已加更正块。
