## §1 为什么这样改提示词（与你原话的差异）

| 你的原话 | 问题 | 优化后 |
|---|---|---|
| "六类样本全部做完制成全国分类" | 样本和分类是两件事，混在一起容易两头都不彻底 | 拆成 A1（样本量）+ A2/A3（样本精度）+ 分类留给下一步，本轮**只保证样本够用** |
| "想尽办法来做，直到做完" | 没有判定"做完"的标准，容易无限迭代或提前收工 | 给了 A1–A7 七条**可逐条报数**的判据 |
| "总体一致率达到 0.85 以上"（上一轮） | 上轮实测证明六类精确上限≈0.699，0.85 不可达 | 改为**分轴 ≥0.90 + 六类精确 ≥0.70**，并说明 0.699 的来历 |
| "看看如何用来提升" | 没说要提升到什么程度、怎么证明 | S1 要求"用于两件具体事 + 口径校验"，S4 要求"用 vs 不用的对照" |
| "记得备份和文档记录" | 没说备份什么、文档写什么 | S6 明确交付目录内容 + VERSION/索引/handoff 三处同步 |
| "这次不管做的怎么样，我都要进行下一步分类了" | 会诱导 AI 在没达标时草草收尾 | 改为"逐条报数 + 写明缺口性质"，**允许未达标但要透明**，这样你下一步分类时知道哪些类不能用 |
| **（本轮新增）** "不能超过 30G 内存和 15 个 cpu 核心" | 只说了上限，没说怎么保证、怎么监控、谁来负责 | 写成 **X1–X6 六条**：含"所有进程之和"而非单进程、启动前去重、单进程设计目标 ≤8GB 留余量给子 agent、分段跑留 checkpoint |
| **（本轮新增）** "尽量多的子 agent" | 没约束会打满机器 | 定**三阶段 8 个子 agent**，明确"并行上限 3"，并要求每个子 agent 的 prompt 写上自己的核数/内存预算 |

### 1.1 四条最关键的改动

1. **把"精度目标"从单一口径拆成分轴 + 六类精确两级**，并给出 0.699 这个实测上限。否则 AI 会为了凑 0.85 而换统计口径（只报分轴、或只报块CV不报按省留出），看起来达标实则不可比。
2. **要求"新数据必须做用 vs 不用的对照"**。本轮新增了两个数据源（ESA CCI、MCD12Q1），如果没有对照数字，就无法判断增益来自新数据还是来自重采样/换口径。
3. **要求区分"数据缺口"与"抽样不足"**。上一轮青藏/西南的 42 类为 0 点是池子里本来就没有，这不是失败；但如果不写明，你下一步分类时会以为那边有样本。
4. **资源上限写成"所有进程之和"并配启动前去重**。历史上出过两个各占 17.4 GB 的同名进程把机器搞重启，只写"≤30G"不足以防止。

## §2 GEE 数据集调研结果（用 gee-dataset-intelligence 查证）

### 2.1 新增：ESA CCI PFT 300 m（本地，非 GEE）

| 项 | 值 |
|---|---|
| 路径 | `E:/landcover100_com_DB/others/1992年-2020年植被类型数据/` |
| 文件 | `ESACCI-LC-L4-PFT-Map-300m-P1Y-{1992..2020}-v2.0.8.hdf` × **29** |
| 格式 | **HDF5 / netCDF-4，`rasterio` 打不开，必须用 h5py** |
| 尺寸 | 全球 `(1, 64800, 129600)`，**int8**，300 m（0.002777…°），EPSG:4326 |
| 关键波段 | **`TREES-NE`(常绿针叶→41) / `TREES-ND`(落叶针叶→42) / `TREES-BE`(常绿阔叶→43) / `TREES-BD`(落叶阔叶→44)** |
| 值语义 | **分数覆盖（连续百分比）**，不是硬分类——**这正是混交类需要的"针阔各占多少"** |
| 许可 | **CC BY 4.0**（可商用） |
| 引用 | Harper et al., doi:10.5285/26a0f46c95ee4c29b5c650b129aab788 |

**它补上的两个缺口**：
1. FCS10 的 91/92 只标"混交"不给比例（上轮实测 **72–74% 的混交点窗口内只有一种针叶码**，规则并未做真正的常绿×落叶比较）；
2. 既有 China Forest PFT **只到 2013**，ESA CCI 到 **2020**，可做 2014–2020 年代桥接。

**限制**：300 m 不能直接采 10 m 点（须先核心区筛选）；全球文件 1.7 GB/年须按经纬度窗口切片；**无 2021–2024**。

### 2.2 新增：MODIS MCD12Q1 `LC_Type5`（GEE）

| 项 | 值 |
|---|---|
| 资产 | `MODIS/061/MCD12Q1` |
| 分辨率 | **500 m** |
| 时间 | **2001–2024 逐年**（`time.end = 2024-01-01`） |
| 关键波段 | **`LC_Type5` = PFT 分类（8 类）**：常绿针叶 / 常绿阔叶 / 落叶针叶 / 落叶阔叶 / 灌丛 / 草地 / 农田 / 城市 |

**限制**：500 m 粗，只能作"区域一致性约束"和时相延展，不能直接当 10 m 标签。

## §3 六类定义与判据（本轮）
