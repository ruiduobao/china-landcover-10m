## §5 S1 口径校验（前置门，不过即停）

### 5.1 ESA CCI PFT 校验

**做法**：从 `forest6_v1.parquet` 抽 ≥300 个**已知纯林点**（41/42/43/44 各 ≥75，已在 FCS10 与 30m 双源一致），按 2020 年取 `TREES-NE/ND/BE/BD`。

**判据（写死）**：

| 组 | 期望 | 通过条件 |
|---|---|---|
| 41 常绿针叶 | `NE+ND` 高、`BE+BD` 低 | `median(NE+ND) − median(BE+BD) ≥ +20` |
| 42 落叶针叶 | 同上 | 同上 |
| 43 常绿阔叶 | `BE+BD` 高、`NE+ND` 低 | `median(BE+BD) − median(NE+ND) ≥ +20` |
| 44 落叶阔叶 | 同上 | 同上 |
| **四类总体** | 二分类可分 | `AUC(针叶 vs 阔叶) ≥ 0.85` |

**不过则停**，报告实测值，改用 MCD12Q1 单独做 45/46。

### 5.2 MCD12Q1 `LC_Type5` 校验

**做法**：同一批 ≥300 点取 `LC_Type5`（2001–2024 逐年，取 2020 与 2023 两年）。

**判据**：
- 编码映射：1=ENF→41、2=EBF→43、3=DNF→42、4=DBF→44、5=Mixed→45/46、其余→非森林
- **一致率**（2020 年）vs FCS10 四类：**≥0.60**（500 m vs 10 m，门低于 ESA CCI）
- 若 2023 年一致率与 2020 年相差 ≤0.05，说明可作 2021–2024 延展

## §6 S2 45/46 判据（写死）

```
对每个候选点，取 ESA CCI 2020 年的四个分数（0–100 或 0–1，按实际标度换算）：
  nf = TREES-NE + TREES-ND      # 针叶总
  bf = TREES-BE + TREES-BD      # 阔叶总
  frac_needle = nf / (nf + bf)
  ever_share  = TREES-NE / nf   # 针叶内常绿占比

混交候选 = nf ≥ 20 且 bf ≥ 20 且 0.20 ≤ frac_needle ≤ 0.80
45 常绿针阔混 = 混交候选 且 ever_share > 0.60
46 落叶针阔混 = 混交候选 且 ever_share < 0.40
uncertain     = ever_share ∈ [0.40, 0.60]
```

**时相稳定性（双年）**：要求 **2017 与 2020 两年都判为同一类**（45 或 46），任一年不确定则标 `pheno_stable=0`，降为 B 档。

**2021–2024 延展（不做逐年独立标签）**：用 `MCD12Q1 LC_Type5` 判定"该点在该年是否仍属同类"，只作**门控（usable_y）**，不修改主标签。

## §7 S3 扩样与质量分档

### 7.1 候选池（五路合并，去重按坐标）

1. 本地林地资产合并池（`forest6_v1.parquet` 472,307 点）
2. 全国 FCS10 森林像元扫描（沿用 F6 的 5×5 窗口规则，仅作辅助证据）
3. **ESA CCI 高置信混交区**（S2 规则，全国 300 m 栅格扫描）
4. **MCD12Q1 `LC_Type5 == 5`（Mixed）** 区域
5. **GEDI 有观测点**（`rh98` 有效）

### 7.2 纯度分档（写死）

| 档 | 条件（混交类） | 条件（纯林类） |
|---|---|---|
| **A** | `pheno_stable=1`（2017/2020 双年一致）且 `0.25 ≤ frac_needle ≤ 0.75` 且 500 m 尺度同质 | FCS10 与 30m 双源一致 + tier ∈ {gold, silver} + 无混交窗口争议 |
| **B** | `pheno_stable=1` 但 `frac_needle` 在 0.20–0.25 或 0.75–0.80 | 单源或 tier 较低 |
| **C** | `pheno_stable=0` 或 500 m 尺度仍为纯林 | 有争议 |

**训练与验收只用 A 档**；B/C 保留但标 `quality_tier`。

### 7.3 撒点规则（防聚团）

- 每 100 m × 100 m 格 ≤1 点
- 0.01°（≈1.1 km）内同类 ≤1 点
- 每瓦每类 ≤300 点
- 与既有 472,307 点 0.005° 内重合则跳过
- 排除境外（DataV 省界，逐个 feature 处理，不 unary_union）
- 每类全国上限：41/43/44 **25,000**、42 **20,000**、45/46 **20,000**
