## §3 P1：ESA CCI 全国扫描（核心新数据）

### 3.1 数据结构的关键发现

| 项 | 实测 |
|---|---|
| 波段 | `TREES-NE/ND/BE/BD` 等 14 个，shape `(1, 64800, 129600)`，**int8，0–100（百分比覆盖）** |
| **每一像元 14 波段之和** | **恰为 100**（100% 的像元） |
| **`NE>0 且 ND>0` 的像元** | **0 个**（中国窗口 2.94 亿像元）；全球采样 520 万亦为 0 |
| lat 方向 | **降序**（90 → −90），索引须 `floor((90−y)/dlat)` |
| 两年变化 | 2017→2020 原始波段仅在 **0.06–0.49%** 的像元变化 |

**结论：ESA CCI PFT 不是"分数覆盖可共存"，而是"每个像元一个主导 PFT"。** `ever_share` 只能取 0 或 1。

### 3.2 扫描结果

## §5 R3/R4：新数据增益与被推翻的规则

### 5.1 R3 增益对照 —— **没有真实增益**

| 指标 | 上轮 doc85 core | 本轮 | Δ |
|---|---:|---:|---:|
| 45 / 46 点数 | 13,776 / 13,069 | **13,604 / 3,750** | −172 / **−9,319** |
| 45 召回（按省） | 0.4171 | 0.4152 | −0.0019 |
| 46 召回（按省） | 0.4379 | **0.3005** | **−0.1374** |
| 六类 macro-F1（按省） | 0.6706 | **0.6584** | **−0.0122** |
| 六类 OA（按省） | 0.7006 | 0.7202 | +0.0196 |
| 分轴 45vs46 AUC（按省） | 0.9260 | 0.9898 | +0.0638（**假象，见 §4.2**） |

**同一批 70,000 混交候选点上**：
- 旧判据（FCS10 邻域针叶码）**100%** 能出判
- 新判据（ESA CCI）只 **20.8%** 能出判（66% 的点 `nf20=0`）
- 两者都出判时一致率 **58.1%**（flip 45→46 = 1,393、46→45 = 4,703）

**这是两套不同信息，不是同一判据的两种写法。**

### 5.2 R4 被推翻的规则

| 项 | 内容 |
|---|---|
| **原规则** | doc86/87 §S2：用 ESA CCI 的 `nf≥20 且 bf≥20 且 0.20≤frac_needle≤0.80` 定义混交候选 |
| **推翻它的实测** | 14 波段每像元之和恰为 100，`NE>0 且 ND>0` = **0 个** → `nf≥20 且 bf≥20` 是**空集** |
| **改成什么** | 混交候选仍用 FCS10 窗口 + AEF 边界距离；**ESA CCI 只用于判"针叶成分以常绿还是落叶为主导"**（AUC 0.9709） |
| **第二处修正** | doc87 §6 原要求 `stable2yr=1`。实测两年 `r=0.99998`（仅 1 点翻转），该门无区分力 → E2 档不强制要求 |

### 5.3 顺带修正的两处实现 bug

1. **索引 bug**：`np.searchsorted(-lat, -y)` 在点落于像元上半部时返回下一行（480 点只匹配 187）。正确形式 `floor((90−y)/dlat)`，已验证 **480/480 四波段精确一致**。
2. **`usable_y` 曾存原始 LC_Type5 而非布尔门**，已修正。
