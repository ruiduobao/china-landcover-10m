## §3 2017–2024 逐年动态证据与三态裁决规则（阶段 S2 & S3）

设施农业大棚是典型的**高动态人工地物**（2017 年后存在新建大棚，也存在“大棚房整治”拆除复耕）。**绝不能把 2019/2022 静态点原封不动复制到 8 年**，必须走“空间锚点池 + 逐年光谱/概率存续检验”。

### 3.1 GEE 逐年证据抓取（2017–2024 每年一套）

对候选锚点池，按 1°×1° 格分块（每请求 **≤ 2,000 点**，`tileScale=4`，**逐波段 `unmask(-9999)` 后再 `cat`**）抓取 2017–2024 逐年特征：
1. **年匹配 AEF64**：`GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`，`filterDate(Y-01-01, Y+1-01-01).mosaic()`，`scale=10`，输出 `A00`–`A63`（float32）。
2. **Sentinel-2 逐年多窗光学与塑料温室特征**（`COPERNICUS/S2_SR_HARMONIZED`，SCL 剔 3/8/9，云量 < 60，`scale=10`）：
   - `s2_alb_med`：全年可见光平均反射率中位数 `(B2+B3+B4)/3 × 10000`（塑料棚膜典型表现为高反照率、高亮白/浅蓝）；
   - `s2_ndvi_max` / `s2_ndvi_min` / `s2_ndvi_amp`：夏窗（6–9 月，2017/2018 缺测用 4–11 月宽窗兜底）与冬窗（12–3 月）NDVI（`×1000`）及其振幅（大棚膜压制冠层红边反射，夏季 NDVI 显著低于露天茂密农作物，且周年振幅异于大田作物）；
   - `s2_ndbi_med`：`(B11-B8)/(B11+B8) × 1000`；
   - `s2_pgi`（塑料温室指数 / 蓝绿红特征比）：辅助区分塑料棚膜与裸土。
3. **Dynamic World 年度概率中位**（`GOOGLE/DYNAMICWORLD/V1`，`scale=10`）：
   - `dw_water`、`dw_trees`、`dw_Savanna/shrub`、`dw_crops`、`dw_built`、`dw_bare`、`dw_snow`（注：大棚在 DW 中通常表现为 `crops` 与 `built`/`bare` 混合，但绝不是纯水体或高大密林）。
4. **地形特征（静态一次抓取）**：SRTM `dem`、`slope`（大棚原则上位于平坦或缓坡耕地，`slope` 极少 > 25°）。

### 3.2 预注册逐年三态裁决规则（先写死进 `criteria_greenhouse.json` 再跑）

在每一年 $Y \in \{2017..2024\}$，对每个锚点独立判定 `keep`（strong）、`flag`（weak）、`quarantine`（剔除当年）：

- **`quarantine`（当年剔除——出现以下任一硬矛盾即判定该年在 $Y$ 年不是大棚）**：
  1. **水体/湿地淹没**：`dw_water >= 0.45`；
  2. **茂密森林/果园**：`dw_trees >= 0.50` 或（`s2_ndvi_max >= 780` 且 `s2_alb_med < 1100`，说明当年是纯露天浓密植被/大田作物，大棚尚未建成或已拆除复耕）；
  3. **高陡坡误标**：`slope >= 25°`；
  4. **地膜旱地 / 裸地伪影拦截**：单源候选点（非多源交集）在当年呈现典型露天轮作特征（`s2_ndvi_max >= 720` 且 `s2_ndvi_amp >= 500`）或纯暗色裸土（`s2_alb_med < 950` 且 `dw_bare >= 0.60`）；
  5. **彩钢瓦工业厂房拦截**：落在 OSM `industrial/commercial` 面内，或 `dw_built >= 0.80` 且周边 300 m `dw_crops < 0.10`（纯城市/工业园区内部，非农业大棚）。
- **`keep`（`tier='strong'`，高置信保留）**：
  - 未触发 `quarantine`；
  - 且满足：`s2_alb_med >= 1250`（棚膜高反射）且 `s2_ndvi_max < 680`，**或**该点在当年有直接专题阳性证据（如 2019 年 NAGP `P1_consensus`、2020 年 Global-PCG、2022 年 China_GH `==1`）且当年 AEF64 与基准年（2019/2020/2022）AEF64 的余弦相似度 `cos_sim >= 0.92`。
- **`flag`（`tier='weak'`，中间态保留）**：
  - 未触发 `quarantine`，但因当年云雨缺测或光谱处于灰带（如棚膜老化覆尘、季节性揭膜期）未能达到 `keep` 强标准，且 AEF64 跨年余弦相似度 `0.85 <= cos_sim < 0.92`。
  - 若 `cos_sim < 0.85` 且无当年光学阳性证据，说明该年地物发生剧烈变化（未建或已拆），直接归入 `quarantine`！

## §6 子 Agent 编排与硬性验收门（A1–A8）

### 6.1 子 Agent 拆分方案（最多 3 个并发）
- **Subagent-GH1（本地栅格/矢量抽样，CPU ≤ 6 核，RAM ≤ 8 GB）**：扫描 NAGP 27 省掩膜、78 个 KML、China_GH 3 期、Global-PCG、OSM，完成核心区 3×3 纯度过滤、7 省补缺与 200 m 去重，产出锚点表 `gh_anchors.parquet`。
- **Subagent-GH2（GEE 逐年特征与 AEF64 抓取，CPU ≤ 4 核，RAM ≤ 6 GB）**：先串行跑 `s0_sweep.py` 与 `s0b_health.py`，使用健康账号池（每账号 1 并发，每请求 ≤ 2,000 点）抓取 2017–2024 八年 AEF64 与 S2/DW 证据，逐块幂等落盘。
- **Subagent-GH3（三态裁决、可分度测评与交付打包，CPU ≤ 5 核，RAM ≤ 8 GB）**：执行预注册判据，补充 CTAmap 省归属，导出 8 年 `.gpkg`，并调用 `AEF整理与可分离度` 同款 5 折 LDA 脚本计算各大区内“设施农业大棚 vs 草本旱地 / 灌溉耕地 / 不透水面 / 光伏”的可分离度。

### 6.2 硬性验收门（全部 PASS 才准收工）
- **A1 样本量**：2019–2024 每年有效交付点（strong+weak）**≥ 25,000 点/年**，2017–2018 每年 **≥ 18,000 点/年**；其中 `strong` 占比 ≥ 65%。
- **A2 空间覆盖**：覆盖 ≥ 28 个省级行政区；NAGP 原先缺失的广东、新疆、内蒙古、重庆四省区必须有实测正样本落盘（每省 ≥ 200 点）。
- **A3 AEF 完整性**：8 年全部 `.gpkg` 中 `A00`–`A63` 的 NaN 数 = **0**，值域 ⊂ `[-1.0, 1.0]`。
- **A4 坐标与属性卫生**：重复坐标 = 0，`ct_prov` 空值 = 0，CRS 严格为 `EPSG:4326`。
- **A5 独立定标源检验**：在 Global-PCG（潍坊+南通）及 NAGP 官方 `Non-AG` 负样本 KML 上，预注册规则对 `Non-AG` 的拦截率 **≥ 90%**。
- **A6 GEE 双路复取保真**：随机抽 100 点独立最小脚本重取 AEF64 与 S2 证据，`max|Δ| == 0.0`。
- **A7 大区可分离度（核心质量指标）**：在主产大区（山东、江苏、河北、云南、辽宁所在 6°×6° 大区），大棚与区内其余类别的 5 折 LDA 平衡准确率均值 **≥ 0.88**，并如实报告最易混类对（与旱地、不透水面、光伏的两两可分度）。
- **A8 落盘回读校验**：8 个 `.gpkg` 用 `pyogrio` 回读记录数、字段类型与统计表 100% 对齐。
