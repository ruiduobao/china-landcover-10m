## §2 候选池构建与分级抽样规范（阶段 S1）

1. **三源空间交叉与先验分级（STRtree 加速）**：
   - **Tier-A（多源共识核心区）**：`Tang ∩ Maus`、`Tang ∩ OSM`、`Maus ∩ OSM` 的交集多边形（向内负缓冲 `-20 m`）；
   - **Tier-B（Tang 独立精细多边形）**：Tang 单源多边形（筛选面积 `≥ 10,000 m²` = 1 ha，向内负缓冲 `-20 m`）；
   - **Tier-C（OSM 独立采石场 + Maus 大矿区核心）**：OSM 单源多边形（面积 `≥ 10,000 m²`，内缩 `-20 m`）及 Maus 单源多边形（内缩 `-30 m`）。
2. **多边形内部抽样与距离控制**：
   - 小矿斑（1–20 ha）：每斑取 1 个内部极点（`representative_point`）；
   - 中大型露天矿（20–500 ha，如山西平朔、准格尔、白云鄂博、德兴铜矿）：在多边形内缩区按 **≥ 300 m 间距**均匀抽点（单矿最多不超过 15 点，防止全国样本被少数巨型露天煤矿垄断）；
   - 全国球面距离 **≥ 250 m 贪心去重**；
   - 全国候选锚点池规模：**35,000 – 50,000 点**（确保晋、蒙、新、陕、冀、辽、川、云、黔、赣、鲁、皖、粤等采矿与采石大省全覆盖）。

## §3 2017–2024 逐年动态证据与三态裁决规则（阶段 S2 & S3）

露天矿在 2017–2024 年间经历剧烈的**剥离扩张（林草农 → 采坑）**与**矿山生态修复（采坑/排土场 → 复垦草地/林地/光伏）**。静态矿区多边形只能代表“2017–2024 期间曾作为矿业用地的空间走廊（Spatial Corridor）”，**某一点在某一年 $Y$ 是否属于活跃/裸露露天采矿场，必须由当年卫星证据裁决！**

### 3.1 GEE 逐年证据抓取（2017–2024 每年一套）

按 1°×1° 格分块（每请求 **≤ 2,000 点**，逐波段 `unmask(-9999)` 后再 `cat`）抓取：
1. **年匹配 AEF64**：`GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`（`scale=10`），输出 `A00`–`A63`。
2. **Sentinel-2 逐年光学特征**（`COPERNICUS/S2_SR_HARMONIZED`，SCL 剔 3/8/9，云量 < 60，`scale=10`）：
   - `s2_ndvi_max` / `s2_ndvi_med`：夏窗（6–9 月，缺测用 4–11 月宽窗）最大与中位 NDVI `×1000`（活跃采掘面与排土场几乎无植被，`s2_ndvi_med` 极低）；
   - `s2_ndwi_max`：全年最大 NDWI `×1000`（识别矿坑积水或尾矿库水面）；
   - `s2_swir_med` / `s2_vis_med`：短波红外 `B11` 与可见光均值（区分黑色露天煤矿面 `vis_med` 极低 vs 新鲜石灰岩/花岗岩采石场 `vis_med` 与 `swir_med` 极高）。
3. **Dynamic World 年度概率**（`scale=10`）：
   - `dw_bare`、`dw_built`、`dw_trees`、`dw_grass`、`dw_shrub`、`dw_crops`、`dw_water`、`dw_snow`（露天矿在 DW 中典型表现为高 `dw_bare` 或 `dw_built` [选矿厂/台阶被识别为人工表面]）。
4. **地形与局部起伏度（静态一次抓取）**：
   - SRTM / NASADEM `dem`、`slope`、`relief300`（300 m 窗口高程极差）。

### 3.2 预注册逐年三态裁决规则（先写死进 `criteria_mining.json` 再跑）

在每一年 $Y \in \{2017..2024\}$：
- **`quarantine`（当年剔除——满足任一条即判定该年在 $Y$ 年不是裸露采矿场）**：
  1. **尚未开挖或已完成生态复垦变绿**：当年 `s2_ndvi_med >= 260` 或 `s2_ndvi_max >= 380` 或 `dw_trees + dw_crops >= 0.40`（说明当年是森林、农田或已复垦绿地）；
  2. **尾矿库纯水面 / 采煤沉陷积水区**：当年 `dw_water >= 0.40` 或 `s2_ndwi_max >= 150`（纯水像元归水体，不混入露天采矿固体地表）；
  3. **高山永久冰雪误入**：`dw_snow >= 0.40`；
  4. **矿区光伏改造拦截**：落入 `04_光伏\中国子集\SolarPV_China.gpkg` 内（矿山排土场架设光伏后归光伏电站）；
  5. **戈壁/沙漠背景伪矿区拦截（针对西北干旱区 Maus 单源大框）**：在新疆、内蒙西部、青海、甘肃干旱区（`lon < 106°` 且 `lat > 35°`），若仅为 Maus 单源点（未命中 Tang 精细轮廓且未命中 OSM quarry），且 `relief300 < 8 m` 且 `dw_built < 0.05`（平坦均质戈壁滩，无采坑地形起伏与工矿扰动迹象），一律剔除！
- **`keep`（`tier='strong'`，高置信保留）**：
  - 未触发 `quarantine`；
  - 且满足：① 属于 `Tier-A`（多源交集）或 `Tier-B`（Tang 精细轮廓），且当年 `s2_ndvi_med < 200` 且 (`dw_bare + dw_built >= 0.35` 或为低反射率露天煤矿坑 `s2_vis_med < 800`)；**或** ② 属于 `Tier-C`（OSM 采石场），且当年 `s2_ndvi_med < 180` 且 `dw_bare + dw_built >= 0.50`。
- **`flag`（`tier='weak'`，中间态保留）**：
  - 未触发 `quarantine`，落在矿区多边形内，当年 `s2_ndvi_med ∈ [200, 260)`（半裸露边坡或稀疏先锋草本排土场）或 `dw_bare + dw_built ∈ [0.20, 0.35)`。

## §6 子 Agent 编排与硬性验收门（A1–A8）

### 6.1 子 Agent 拆分方案（最多 3 个并发）
- **Subagent-MN1（三源矢量融合、走廊生成与抽样，CPU ≤ 6 核，RAM ≤ 8 GB）**：读取 Tang、Maus、OSM 中国子集，构建 STRtree 完成 Tier-A/B/C 分级、内缩抽点、250 m 去重，并生成 `China_Mining_Corridor_500m_WGS84.gpkg` 与锚点表 `mn_anchors.parquet`。
- **Subagent-MN2（GEE 逐年光学/裸露度证据与 AEF64 抓取，CPU ≤ 4 核，RAM ≤ 6 GB）**：多账号并行抓取 2017–2024 八年 AEF64 与 S2/DW/SRTM 特征。
- **Subagent-MN3（三态裁决、裸地冲突扫描与交付打包，CPU ≤ 5 核，RAM ≤ 8 GB）**：执行逐年三态裁决（体现 2017–2024 新开挖与复垦动态），扫描旧 `裸地`（含南方补样层）冲突点，导出 8 年 `.gpkg` 并测算大区 5 折 LDA 可分度。

### 6.2 硬性验收门（全部 PASS 才准收工）
- **A1 样本量**：2017–2024 每年有效交付点 **≥ 25,000 点/年**；其中 `strong` 占比 ≥ 70%。
- **A2 区域均衡**：覆盖 ≥ 30 个省级行政区；湿润区（华东、华南、西南、华中）采矿/采石场样本占比 **≥ 35%**（绝不能全抽在西北戈壁）。
- **A3 裸露纯度**：交付点中 `s2_ndvi_med < 260` 的比例 = **100%**，`dw_water < 0.40` 的比例 = **100%**（零林草复垦点、零尾矿库纯水点混入）。
- **A4 AEF 完整性与坐标卫生**：8 年 `.gpkg` 中 `A00`–`A63` NaN 数 = **0**，重复坐标 = 0，`ct_prov` 空值 = 0。
- **A5 年际动态合理性**：统计并报告 2017→2024 年间“前期为植被、后期开挖入池”与“前期为矿坑、后期复垦退出”的真实动态点数，验证逐年筛选非静态复制。
- **A6 GEE 双路复取保真**：随机 100 点独立重取 AEF64 与 S2 NDVI，`max|Δ| == 0.0`。
- **A7 大区可分离度（重点汇报）**：分“湿润区大区”与“西北干旱区大区”分别汇报露天采矿 vs 自然裸地 / 不透水面 / 稀疏植被的 5 折 LDA 平衡准确率（量化证明哪些大区可直接靠 AEF 分离，哪些干旱区大区需依赖 `China_Mining_Corridor_500m` 先验走廊）。
- **A8 落盘回读校验**：8 个 `.gpkg` 及走廊文件用 `pyogrio` 回读全部 PASS。
