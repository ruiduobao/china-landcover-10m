## 二、改进实验门的评估与简化（**全部建议非实测**）

主 agent 拟门：单因素维持每瓦 ≤20k 与 RF 容量；3 种子起、临界扩 5；目标类 F1 平均 ≥+0.03；同点组级 OA 平均 Δ ≥−0.01；空间块 bootstrap 95%CI 非劣下界 ≥−0.02 且 ≥2/3 省无 >1pp 退化。

评估与简化建议：

1. **冻结容量（≤20k / 100树·leaf2·nodes5000·seed7）**：与 `技术文档/38` §三 L74 一致（E4 教训"浅容量下加样本更差"），作为单因素对照成立，无异议。
2. **−1pp 容差 < 单种子噪声 ±1.5pp**（`技术文档/34` L74）：必须写死"**同点 + 配对种子**（两臂同种子序列），统计量=逐点差"；否则该门自相矛盾。建议措辞："配对设计下，单种子噪声不进入两臂差值"。
3. **三条非劣条件互相重叠**，建议简化为**两级判据**：
   - 主判据（决定去留）：**同点配对差的空间块 bootstrap 95%CI 下界 ≥ −2pp 且点估计 ≥ −1pp**；
   - 异质性旗标（不判死）：省间**点估计退化 >2pp** 才报警并复核，**不要求每省都过**——避免"全国平均通过"掩盖单省塌陷，也避免 1pp 级抖动把实验卡死。
4. **目标类 F1 ≥+0.03**：可行但需与有效 n/CI 挂钩——"目标类"清单先写死（如川=园地/常绿阔叶、宁=裸地/灌溉耕地、粤=园地/灌丛邻类）；n<30 只报合并级（`AGENTS.md` L122）；建议补充"至少 2/3 目标类的 CI 下界 >0"。
5. **种子策略**：3 种子起步、若点估计落在噪声带内（|Δ|<2pp）**预注册**扩到 5 种子（防止任意停止偏置）。多种子均值差的 SE≈1.5pp/√k（k=3→0.87pp、k=5→0.67pp）——**建议非实测的算术提示**。
6. **小样本参考集不能声称检出 2pp**：设 n 为省域概率样本量，OA≈0.85 时 95% 半宽≈1.96·√(0.85·0.15/n)：n=300→±4.0pp、n=500→±3.1pp、n=1,000→±2.2pp（未计设计效应；分层估计按 Olofsson [2] 层内方差）。**报告须写 MDE（最小可检出效应），只报 CI，不报"检出 2pp"式结论。**
7. **地形 bias**：只以"**对照真值上的错分差 + CI**"为错误依据；**不得把 N/S 坡分布差强制压零**——既有 aspect_check 已显示 ENF 偏阴/DBF 偏阳的真实反向富集（a_crop_dem SUMMARY L7），分布差异也可能是真实生态。建议门："同一真值类在阴阳坡的错分率差 95%CI 不含 0 且方向一致方可判偏置"。

## 三、三省独立参考集建议设计（**建议非实测、不立即布点、两层分离**）

> 前置：M3 材料/标签已有消耗（见 `00_现状清单与证据指引.md` §4.9 三态口径）；新参考集必须**新取样、新封存、一次启用**，且**从训练/调参全面排除**。

**A. 省域概率基础集（用于全省 OA/面积，按地图类分层 + 纳入权重）**

- 设计：在各省域（川/粤/宁）按**成品图类分层**抽点（SRS/系统抽样于层内），每点记录**抽样权重/层面积**，可回算面积与 OA 的 95%CI（方法说明引 Olofsson [2]）；判读只认双人盲判+分歧仲裁。
- 规模建议：**300–500 点/省**（n=300 时 OA≈0.85 的 Wald 半宽≈±4.0pp；n=500≈±3.1pp）——**只能检大偏差**；若目标"检出省级 2pp 差异"须 ≥1,000 点/省且配套设计效应修正，或改为多年合并/多省合并报告。
- 覆盖要求：≥1 km 空间独立（借 M3 布点规则）；沿海省注意包含沿海层；富集点**不得**混入（见 B）。

**B. 定向诊断集（不并入全省 OA，只报分层诊断）**

- 易混类对（灌丛/森林/园地/草地、草地-稀疏-裸、滩地-水）：**100–150 点/省**，按对分列；
- 阴阳坡成对：**50–100 对/省**（同海拔带、同岩性区、坡向对置），成对设计直接差分；
- 接缝条带：沿瓦片接缝取 **3–5 段 × 50 点**（跨缝两侧各半），用紧邻内部对照（doc 38 §B.3 口径）。
- 报法：每对/每段给差值与 CI；**明写"富集诊断，不可外推省域比例"**。

**C. 双人盲判要件（两层公用）**

- 判读前预注册判据与 rubric；双人独立盲判（互不可见）；分歧 1/3 内由第三人仲裁；记录置信度与"不可判读"比例（`技术文档/54` §5 的经验：z18 底图有效细节 1–2 m，单期影像不能判 E/D）；
- 抽样权重/空间独立/层面积表随件归档；一次封存、一次启用、用后即宣布失效。

## 四、必须重复检查的措辞纪律（最终核对清单简版）

1. **UA=precision（多分）、PA=recall（漏分）**——`v31_common.metrics` 曾有标签对调（doc 38 L29 勘误），引用 F1/PA/UA 前对表头；
2. **macro-F1 与缺席类 8**：第二次无 8 类正样本，宏平均**要么对缺席类置评注、要么两轮同口径（第一次也剔除 8）**，禁止一边含 8 一边不含；
3. **non-fcs10 ≠ 独立**（净窗口/分层窗口）；
4. **同点对比 vs 同 n 对比**不同：同点=逐 rid 配对；同 n=重抽样，禁止混写；
5. **单种子点估计 ≠ 抽样置信区间**：前者是噪声带（±1.5pp），后者是设计导致的统计不确定（n/分层决定）；
6. **一致率（intercomparison）≠ 精度**；**AI 预判读 ≠ 人工判读**；**maxΔ=0（回读/抓取）≠ 标签精度**；
7. **改进门全部标"建议非实测"**；"已证伪"引用必须带限定条件（见 `00_现状清单与证据指引.md` §5）。
