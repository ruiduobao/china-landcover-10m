## 0. 结论速览

1. **「裸地集中在东部/东北」不成立**。2023 交付裸地 222,481 点中 **92.5% 在 105°E 以西**，东北窗（119–135°E/42–54°N）仅 1,565 点（0.70%），华东华南窗 **0**；黑吉辽合计 352 点。交付/池/成品三线同向（2017 年子集同样 92.5% 西侧）。**「稀疏植被东部缺样本」成立**（华东华南 0、东北 9），且东北稀疏是**真缺口**（外部门控否决，见 §6）；但华东华南空白与对标产品 FCS10 一致（同区仅 2.5 km²）。
2. 2023 交付 1,809,389 → 池 v2 1,764,020，剔除 45,369 点分解为 id 键 39,166 + 位置键 6,203 + **未解释 0**；其中**乔灌园地 4,238 点为数字 id 与评估清单 row_id 撞号导致的保守误剔**（坐标证据：0 个同桌标、中位相距 1,224 km），方向保守、无泄漏，列 P0 谱系修复项、**不自动回填**。
3. 池 v2 的 `src` 是**类目录名**（23 值，1:1 于类码），**目录重命名 ≠ 更换标签来源**：森林 4/5/6/7 与 1/3/11/12/13/16/17/21/22/23/24 的 v2 点 **100% 是首批池 v1 的位置子集**（森林四类 n_v2 = v1_pos_in_v2 = v1_id_in_v2），即旧教师点的质检子集，旧标签体系（含坡向偏差）结构上未被新 QC 解除；真正的扩展层只有 灌木 9/10、乔灌园地 2、木本/草本沼泽 14/15、红树林 18。v1 的真实来源层（v2_glc_fcs30d2020_7yr_stable 1,438,434、glc_fcs10_2023_shrub 521,400…19 种）与质量层（gold/silver/bronze/external/reject…）**未传入 v2**；v2 内 tier 可经交付 gpkg 回接 89.4%（strong 825,753 / weak 185,534 / 其他层级语义 565,997 / 缺失 186,736）。

## 3. 交付 → 池 v2 → 首批池：谱系与剔除分解

### 3.1 逐类总量与剔除（`pool_v2_vs_delivery_by_class.csv`）

- 交付 1,809,389 → 池 v2 1,764,020：剔 45,369 = **id 键 39,166 + 位置键 6,203 + 未解释 0**。
- 位置键主体是 5 个评估窗 + validation_pool_v2 + 错位清单的交集；id 键主体是各评估窗 row_id 清单。
- **乔灌园地（2）4,240 剔除中 4,238 为 id 键命中但位置不在任何清单**：orchard uid 是数字串（另一 id 空间），与评估 row_id 数值撞号。坐标证据：这些 uid 与草本旱地共享 **121,992 个数字 id**，**0 个同坐标**、中位相距 1,224 km → 撞号而非真重复。**结论：4,238 点属保守误剔（宁缺勿漏方向），无泄漏风险**；修复建议见 §7-P0，**不自动回填**（任何回填都须走新预注册批次）。

**读法（区分三条成因）**：
1. **东北稀疏=上游门误否**：候选 3.5 万，五产品一致投"草地"（WC 88%/CLCD 86%/CN30 74%/TH 69%），agree≥3 只剩 28 → 这是标签体系与产品共识的系统性冲突（沙地/退化草原归草地），**不是采样不均**。修复只能靠"对标产品重采/专家样本"定向补样（§7-P1）。
2. **东北裸地=抽稀主导**：44% 过门后 0.025° 落格每格 1 点（2.7 km 格），33,768→1,878→1,794≈母库 1,798，逐位对齐。
3. **华东华南=真实稀少×门×抽稀三重**：稀疏抽稀前只有 64 个候选（对比东北 35,426），裸地 3,910（对比全国 96.8 万）——基数本身就低，与 FCS10 一致；此后又被门与抽稀清空。
4. 质检删除 vs 池排除：裸地交付=223,516−1,002（质检隔离）−33（混淆对）→222,481；稠密稀疏=53,473−6,296（质检隔离）−3,456（混淆对）→43,721。交付→池 v2 的再剔（13: 743；22: 3,965）全部由评估窗/valid/错位清单造成（§3.1），属纪律性排除。
