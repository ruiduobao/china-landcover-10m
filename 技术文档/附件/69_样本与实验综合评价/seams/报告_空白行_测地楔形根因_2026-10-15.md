# 空白行根因报告 — 每 2° 瓦片南边的「测地矩形楔形」nodata（2023 第二批次 + 第一次批共性）

- 日期：2026-10-15　责任人：栅格空白行/网格接缝工程诊断（子 agent）
- 触发：用户报「第二次分类在 30.00149246° 等纬度带系统性一行空白」
- 结论（一句话）：**不是拼接 bug、不是 AEF 缺测，而是 GEE 侧 box 几何用了测地（大圆）边的矩形**——
  `ee.Geometry.Rectangle(meta['box'])` 的数字坐标输入取服务端默认 `geodesic=True`，clip/export 的

  **透镜区被排除**，于是每个 2° 瓦片南边留下一个关于瓦片中央列对称的三角形 nodata。
  该几何在第一批（五省）同样存在，故 **D:/生产_2023五省 与 第二次交付件都带病**。
- 证据等级：**几何归因 = 强证据（本地可复算，亚像元吻合）**；「AEF 该处有数据」= 中强（521 个带 64 维 AEF 真值的池点落在楔内，非全典型抽样）；「clip 与 export region 谁落地成掩膜」= 未裁决（本地无法二分，需云端抽点，本次未做）。

## 3. 根因链（代码级）

1. `代码/9.第二次分类川粤宁/c3_driver_prod2.py`
   - **L220**：`box = ee.Geometry.Rectangle(meta['box'])`　← 几何来源（数字坐标 → 服务端默认 geodesic=True）
   - **L221-223**：`aef = ee.ImageCollection('GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL').filterDate(...).filterBounds(box).mosaic().select(VC.FEATS)`
   - **L224**：`cls = aef.classify(clf).rename('class').uint8().clip(box)`　← 掩膜在此落地（classify 仅透传 AEF 掩膜）
   - **L228-230**：`ee.batch.Export.image.toAsset(image=cls, ..., scale=10, crs='EPSG:4326', region=meta['box'], ...)`
   - **L211-213**（训练侧）：`boxp = ee.Geometry.Rectangle([box±2])` → `filterBounds(boxp)`（同样测地默认）
2. `ee` 1.7.42（生产版本，本地静态源码）：
   - `ee/geometry.py` `Geometry.Rectangle` → `_parseArgs('Rectangle', 2, ...)`：坐标为数字时**客户端不写 geodesic 键**
     → 交服务端默认；同库文档原文：
     *“geodesic: … The default is the geodesic state of the inputs, or **true if the inputs are numbers**.”*
   - `ee/geometry.py` `Geometry.BBox` 显式 `geodesic=False`（docstring: *“planar WGS84 rectangle”*）→ **现成的修复件**
   - `ee/batch.py` `_canonicalize_region`：`region=[x0,y0,x1,y1]` 先试 `Geometry.LineString` 再 `Polygon`，仍是数字坐标几何 → 同为测地默认
3. 几何后果（本地解析，球面）：同纬两端点 (y0,x0)–(y0,x1) 的大圆在中经线纬度
   `tan(φ_arc(λ)) = tan(y0)·cos(λ−λm)/cos(Δλ/2)`，拱高 `φ_arc(λm) − y0`。
   与实测楔高逐一对照（瓦片级，Jaccard = 预测“region 外”掩膜 ∩ 实测 nodata）：

|---|---|---|---|---|---|---|
| T1206 | 97–99/30–32 | 42 | 0.0037791° | 42.07 | 0.9815 | mean −0.53 px，max 1 px |
| T1205 | 97–99/28–30 | 40 | 0.0036177° | 40.27 | 0.9792 | mean −0.57，max 1 |
| T1304 | 99–101/26–28 | 39 | 0.0034387° | 38.28 | 0.9777 | mean −0.59，max 1 |

   → 楔高与纬度依赖（∝sinφcosφ）**吻合到 0.5 行以内**；残差 2% 与 ~0.5 px 系统差来自“像元中心 vs 面”约定。

## 4. 为什么不是「AEF 缺测」

`data/train2023_v2.parquet`（1,764,020 点，每点带 AEF 64 维 A00–A63）中，落在各瓦楔形区内的点共 **521 个，
全零行 = 0**；楔内 `|V|` 均值 0.0996 vs 楔外 0.0997、幅值域一致（min/max −0.46/0.43 vs −0.57/0.59）。
样例（T1206 楔内）：`lon 98.030677 lat 30.000541 cl=11 草地, A00..A07=[−0.0517,−0.1999,0.1085,…]`。
→ AEF 在该区**有真实嵌入值**，nodata 由导出/clip 几何制造。

**限定**：521 点证明“非全区缺测”，不等于“楔内每个像元都可用”；逐像元可用性需重导后核。

## 8.1 新增检查（已实现：`g1_boundary_continuity.py`，**诊断档**，非生产硬门）

> 定级：以下 T1d/T2d/T3d 只用于**报警与排序**，阈值**未经校准**，通过与否都不构成阻断依据；
> 代码注释与本报告同口径（见 `g1_boundary_continuity.py` 文件头）。主报告**不采用** T3d 的公式。

- **T1d 测地透镜几何检测**：按大圆公式预测“region 外”掩膜 ∩ 瓦片 nodata 计数。
  ⚠️ **不能直接判 0 阻断**：瓦片内该区可能天然无 AEF 数据（海面/真实缺测），否则会误拦。
- **T2d 逐行内部断带**：`L(r)` = 行内最长**内部**零游程，`L(r) − median(L(r±5)) > 16 px` 报警。
  ⚠️ 启发式、未校准；**连续光学缺测/大湖/城市带也会出现真空白** → 必须与对照年或有效输入掩膜复判。
- **T3d 覆盖率粗对照**：只报 `coverage_px_pct` 与 `land_frac` 的关系。
  ⚠️ `land_frac`（省界陆域占比）**不是** AEF 有效覆盖占比，沿海瓦还含被分类海面 →
  99.99 / `100·land_frac−0.05` 只是**提示线**，不得写成硬门（本轮输出字段已改为 `t3d_hint_line` / `t3d_over_hint`，
  `grade=DIAGNOSTIC`、`blocking_gate=NOT_EVALUATED`）。

**建议的正式阻断门（G-SEAM，需跑前预注册）**：在「预期有效输入掩膜 EVM」上要求 `输出 nodata = 0`
（或 ≤ 预注册容差）。**EVM 只有一条金标准路线**，另两条是**降级替代（须独立校准，不能与金标准等价并列）**：

- **EVM 金标准（唯一）**：导出 **原始 AEF 全波段共同有效掩膜**，且
  **①不先做 clip**、**②用已验证的平面 region（geodesic=False）**、**③固定全局 grid（显式 crsTransform）**
  导出——否则若沿用同一套错误测地几何导出 sidecar，只会在同一位置**复制同一缺口（自证）**。
  注意 `aef.select(0).mask()` 只是**近似**（单波段掩膜），必须证明 64 个波段的 mask 一致；
  严谨做法是 `aef.mask().reduce(ee.Reducer.min())`（或对 64 波段 mask 取 `min`）后再判「全波段共同有效」。
- **降级替代（诊断 / 需独立校准，不作硬阻断判定）**：
  (a) 「接缝对照带」：取距南边界 0.02° 参考行的有效像元模式，仅对该模式有效的列要求在边界带有值；
  (b) 预注册容差 `N_tol`：由已知无缺陷的对照带（修后重导 / 另年份同瓦）逐 y0 带标定。
  二者都只覆盖“参考行模式的列子集”或“容差带”，**等级低于金标准**，须在跑前声明并独立校准后方可用于验收。

   或 `ee.Geometry.Rectangle(meta['box'], None, False)`；`region=` 传**同一平面几何对象**而非 4 数列表；
2. 显式 `crsTransform` 对齐全局 10m 方度格（避免网格吸附相位漂移），下载沿用 geefast `--affine` 精确对齐；
3. 重导后可只回填受影响纬度带（`y0 … y0+0.005°` 条带）以省算力，但**交付件必须整幅重生**以保证自洽；
4. 验收：**正式阻断门 G-SEAM（§8.1）全绿**（EVM 上 `输出 nodata = 0` 或预注册容差）+ 与现成果的差异
   **仅限楔带**（楔外逐像元一致）+ `ov_build.py` 概览重建 + PIL 全平面验收（doc 43）；
   T1d/T2d/T3d 只作辅助诊断，不作为验收判据。

**B. 训练侧口径修（单列，需冻结样本 ID 后再判影响）**——`filterBounds(boxp)`（`c3 L211-213` / `p1_pilot L137-139`）
同样是测地矩形。按 §4，**全池**（`train2023_v2`）中有 521 个楔内点；但训练实际取的是池内
`filterBounds(boxp±2°)` + `randomColumn(seed=7)` + `limit(20000)` 的**子集**，且 `boxp` 比瓦片 box 外扩 2°
（几何与瓦片 box 不同）—— 因此**不能直接断定“具体选点会变”**，只能说**可能影响样本**，
必须重跑取样并比对 `selected IDs`（池点 ID 集合、类别构成、OA）后才能出结论；
改平面后属重训动作，须冻结 ID、出独立影响报告，不得与 A 混做。

**C. 明确不做**：不以邻行/邻瓦插值填补楔区（§7 S3 已证拼接无法自愈；且填值会污染类别栅格统计与面积口径）。

## 10. 限制与诚实清单

1. `clip(box)` 与 `Export.region=` 两者都吃测地默认，本地无法二分是谁落地成掩膜；**未做云端验证**（按指示不需要）。修复必须两处同改。
2. 「AEF 有数据」由 521 个楔内池点支持（**点证据**）：足以否定“该区全无 AEF”，**不等于**逐像元证明楔区每个像元都有有效输入 → §6 数字为**候选缺口**（楔∩nodata），非“独立证实的应有值缺口”。
3. §2 预测拱高用球面公式，未含椭球扁率；与实测吻合 0.5 行内，够用但非严格 WGS84 测地。
4. 省内面积为**实测 nodata ∩ 解析楔区 ∩ 省界内**；解析楔区与实测楔带相差 2.4–4.7%（残差仍有值）→ 数字来自实测而非外推。
5. 未扫描全部 8 年 × 313 瓦（本报告仅 2023 年第一/第二批）；其它年份如沿用同一 box 构造，风险同源，建议先跑 T1d/T3d 诊断。
6. 近岸海面 nodata 与楔形是两类不同成因，本报告只对后者定性；`land_frac<1` 瓦的楔区含海面/无 AEF 区，故按省界口径统计，且 T3d 提示线不适用于这类瓦。
7. 未动任何成品/`.ovr`/交付件；所有写入均在 `reports/quality_review_2026-10-15/seams/`。
8. §8 的诊断阈值（16 px、99.99%、`100·land_frac−0.05`）**均未校准**，仅用于本轮报警；正式阻断需按 §8.1 预注册 EVM 与容差。
