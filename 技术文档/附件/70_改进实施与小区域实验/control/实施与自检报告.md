## 2. 关键设计（可审核点）

1. **窗口定义**：`deadline_window_s = eval.end − train.start`（`time.monotonic()`，非墙钟）。
   上限 `limit_s = 1200`；`budget_ok = deadline_window_s ≤ limit_s` 为严格布尔判定。
2. **截止预留**：单阶段超时预算 = `min(阶段timeout_s, 窗口剩余 − trigger_margin)`，
   `trigger_margin = 10s` → 在 1190s 触发终止，为终止＋落盘预留清理；若清理后整体 elapsed 仍
   > 1200，照记 `TIMEOUT`，**不伪称成功**。
3. **prepare 独立计时**：数据准备单独上限 `prep_cap_s` 并上报，不并入窗口；runner **一次只跑 1 个
   实验**，禁止把一次实验拆成多次 invoke 规避 1200s（拆分须按 doc70 §3.2 另立预注册降级实验）。
4. **只杀自身子进程**：Windows `taskkill /F /T /PID <pid>`（精确 PID＋树），POSIX `killpg`；
   **绝不** `taskkill /IM python.exe`、不匹配 `bash.exe`。记录 `killed_pids` 供独立审核。
5. **资源**：`n_jobs=10`、`cpu_cap=15`、`mem_cap_gb=10`；启动重活前 `preflight_memory`；RF 重活
   取 `rf.lock`（带等待，取不到记 `blocked_slot`，**不杀任何进程**）。
6. **单实例锁**：`control/locks/runner.lock`（O_CREAT|O_EXCL＋PID 活性，陈旧锁可回收）。
7. **原子 JSON**：写同目录临时文件后 `os.replace`；结果落 `control/run_results/<exp_id>.json`，
   摘要并入 `registry/experiments.json`。

## 4. 命名空间安全排除：只读自检（真实池，不重建）

证据：`F:/lc_work/improve_2023_pilot_20261015/control/run_results/ns_pool_selfcheck.json`。
只读 `F:/lc_work/prod2nd_2023/data/train2023_v2.parquet`：

| 项 | 实测 |
|---|---|
| 池行数 | 1,764,020 |
| 唯一 `point_id` | 1,642,028 → **裸 id 非全局主键** |
| 跨类 `point_id` 数字碰撞 | **121,992**（＝doc69 §2.3 记录值） |
| 碰撞记录数 | 243,984 |
| 跨类同位重复位置 | 3 处（doc69 记录"3 处跨类冲突位置、6 条记录"） |

结论（证据，非新精度）：裸数字 id 跨命名空间排除会误剔；namespace-safe 方案＝位置键无条件＋
id 键仅同命名空间生效。doc69 记录的 **4,238 个园地 uid 误剔** 用此方案可识别为
`suspect_false_removal`（异命名空间同号且坐标不符）；**不自动回填**冻结池。
helper 可直接对**实际小表回接**：`build_exclusion_index` / `exclude_points` / `NamespaceSafeExcluder.apply`。
**已按要求停止全池进一步统计**。

## 6. 限制与边界

- **不是精度证据**：本报告只证明控制与排除机制可用；分类是否改善由实验组与主文 71 判定。
- 本地 sklearn RF 为筛选器，**不等价** GEE smileRF；本地 RNG 不复现服务端 `randomColumn`。
- 内存守卫依赖 `psutil`（本机已装）；缺失时降级为"不可用"并显式告警，不静默通过。
- 时间证据基于 `time.monotonic()`；跨进程/跨机不做时钟校准。并发代理的短命进程可能自然退出，
  故"未误伤"的**硬判据**为 `killed_pids` 仅含自身子进程，其它 PID 变化仅作参考信息。
- `registry/experiments.json` 现为空（自检条目已清理）；未扩 registry 框架。
- 未启动 GEE 登录/任务；未动母库、生产配置与既有交付。
- 后续独立审计如需澄清 deadline 标志（`trigger_margin_s` / `budget_ok` / `deadline_window_s`），
  以本报告 §2 与 `_selfcheck.json` 为准。
