### 4.2 当时怎么解释的（原文机制排序）

`REPORT:7` 五条机制按可能性排序（正文版见 `技术文档/69:271-280` 四因表 + `:282` 结论）：

1. **M1 训练标签体系既有的类—地形约定（证据 A，最可能）**：v1/v2 池标签自身把 ENF 放在阴坡、DBF 放在阳坡；两版地图与该约定**同向且量级相容**（地图 2.82→3.13 vs 池 3.52→5.28）。"是否为地图分带的成因（标签驱动）需受控实验；**这一条本身也可能是'真生态的正确记录'**"。
2. **M2 真实生态分异（不可排除，与 M1 不可分离）**：横断山/川西"阴坡云冷杉针叶、阳坡栎桦阔叶"是**文献级常识**；宁夏 ENF/DBF 主要靠高程分开。"真实生态与光照伪影**预测同一个图案**，本地无法分开"。
3. **M3 AEF 特征继承成像光照（可叠加，B−/C）**：单窗嵌入"组间<组内"、方位轴偏光照（θ*=125° 而非 180°）、doc54 针/阔 AUC 仅 0.724。
4. **M4 调色板差异（已排除，A）**；显示/渲染叠加**未检验**。
5. **M5 计算/仪器口径错误（已排除，A）**：米制换算已核（不做换算坡向仅偏 3.7°、坡度会失真）。

**结论原文（`69:278`）**："存在系统性风险，且仅靠本轮常绿/落叶筛选不足以解决针阔坡向问题；**错误范围和主导机制仍需独立参考点裁决**。不能在缺少真值时把所有阴坡针叶林改成阔叶林，也不能以'生态上可能'忽略规则化分带。"

**doc73 的后续（2026-10-15，盲判）对本假设的削弱**：50 个阴阳坡配对中，**池标签按"阳坡阔叶+阴坡针叶"分裂的仅 7/50 对**（43/50 两侧同型）；盲判叶型轴 **97/100 无法判定** → "**把标签按'阴阳坡对立'直接解释为错标的证据不足**"（`73:140-145`）。

## §8 考古结论（给主 agent 与子 agent #2–#10）

1. **针/阔的全部实测只有 0.724 一个数，样本 103 点、正类 29 点、标签是噪声 67% 冲突的单期目视判读。** 这个数**不足以支撑任何"针阔可分/不可分"的最终结论**（doc54 §A.5 自己承认）。**任何新特征集的第一件事应是重建一个可判针阔的真值集**（带日期多季影像 / 外部林型产品 / 林业小班），否则新的 AUC 仍是噪声。
2. **常绿/落叶 0.9902 是可靠的**（AEF 单独、物候物理标签、无循环性），且已被 doc65 在 466,135 点上用 MODIS 交叉验证（同向 85.0%）。**这轴可作为分层分类的第一级**。
3. **坡向 OR 3.13（地图）/ 5.28（池）是 A 级事实，但成因未裁决**；已有三个干预（地形分层、strict 视图、隔离矛盾点）**全部 REJECT 且都未能改善条件错误**。**在拿到独立配对真值前，任何"把 OR 压到 1.5"的动作都可能是在抹掉真生态** —— 与 doc74 §1.2 判据 3 一致。
4. **最大的盲区是 (a) SWIR 与 (g) 全年月合成** —— 这两项**一次都没测过**，而它们恰恰是针叶/阔叶冠层差异的经典判别源（针叶冬季保持结构、阔叶落叶；SWIR 对木质素/含水量/冠层结构敏感）。建议列为子 agent #6 特征评测的**最高优先级臂**。
5. **§2.3 的大区级森林两两可分度（107 条）是本次考古新汇总出来的既有资产**，它第一次给出"哪些大区针阔可分度高（浙 0.963 / 粤 0.945）、哪些低（川 B0402 ENF↔DNF 0.521 / 黔 0.850）"的定量分区依据 —— 建议直接交给子 agent #7（分层策略）作为"按生态区决定是否展开针阔"的输入。
6. **xfeat（MOD44B VCF + MOD13Q1 + GEDI rh98）已采好 3 个 parquet 但从未评估**（2026-09-14 落盘，13 个月）。这是"零 GEE 成本即可跑"的现成缺口，建议立即补一个探针。
7. **doc74 §1.3 的年度支撑三个判据（8 年可用 / 继承 ≥70% / 跨年跳变 ≤5%）目前完全没有对应实测**，且 **GEDI 只有 2019–2024**，与"8 年可用"直接冲突 —— 子 agent #3 需注意任何含 GEDI 的特征集都必须有降级替代。
