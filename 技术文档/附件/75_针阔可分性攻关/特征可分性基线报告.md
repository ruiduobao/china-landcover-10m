### 4.3 标签泄漏检验（`modis_resid_check.json`）—— **决定性**

**实测**：在 hiconf 集上，`modis_lc`（IGBP 1/3=针、2/4=阔）与 `leaf_axis` 的**一致率 = 100%**，
`AUC(modis_needle vs label) = 1.0000`。

即 **MODIS IGBP 就是针/阔标签的来源之一**（标签集定义要求"我方 class4 与 MODIS 一致"才入选）。
而 AEF 与 MODIS 土地覆盖高度相关 → **"用 AEF 预测针/阔"本质上是"用 AEF 复现 MODIS LC"**，
这是**标签-特征循环性（circularity）**，不是叶型判别力。

逐步剥离（0.25° 网格中心化 → 再对 modis_lc 做残差化）：

| 标签集 | 任务 | 原始 | 网格内中心化 | 再扣 MODIS |
|---|---|---|---|---|
| hiconf | T1 | 0.9978 | 0.9032 | **0.9260** |
| hiconf | T3 | 0.9988 | 0.9157 | **0.9369** |
| strict | T1 | 0.9652 | 0.8379 | **0.8349** |
| strict | T3 | 0.9799 | 0.8718 | **0.8714** |

**解读**：即便扣掉网格位置与 MODIS 可解释部分，AEF 仍留 0.83–0.94。
这不构成"叶型可分"的证据 —— 因为：
1. **扣不干净**：AEF 是 64 维稠密嵌入，与 MODIS LC 的关系是非线性的，线性残差化只能去掉一部分；
2. **标签本身是 MODIS 派生的**，任何与 MODIS LC 相关的特征都会"预测成功"；
3. **唯一能裁决的是独立人工判读标签**（doc54 的 113 点，AUC 0.724）—— 那才是无循环的口径。

## §8 对下游决策的建议

1. **不要因本轮 0.93–0.99 的高分推翻 doc54 的"针/阔不可分"结论。** 高分已被三重证据归因于
   位置 / 气候 / 标签来源混淆（§4），doc54 的 0.724 是**唯一无循环**（人工判读）的口径。
2. **森林 5→2（常绿林/落叶林）的瘦身建议维持不变。** 常绿/落叶轴在本轮**所有控制下都稳健**
   （T4：随机 0.999 → 空间缓冲 0.945 → 网格去均值 0.92+），是真实物候信号，与 doc54 的 0.990 一致。
3. **若要继续找针/阔信号，必须换标签**：现有任何"池标签 × MODIS 一致"造出的标签集都带循环性。
   可行路径 = 高分辨率冠层结构（LiDAR / 冠层高度产品）或长波段 SAR，配**独立人工判读**标签。
4. **优先补跑 F2（SWIR）与 F3（冬季）** —— 项目内零命中，是唯一可能给出真实增量证据的臂；
   但**必须在独立人工判读标签上评**，否则仍会被循环性污染。

```bash
# 1) 点集（可切换标签源）
python sep_points.py --labels F:/lc_work/nb_sep_2026/labels/forest_4class_hiconf_local_v1_clean.parquet \
                     --out points_hiconf.parquet
# 2) AEF64 基线 + 地理天花板 + 空间缓冲
python sep_local.py --points points_hiconf.parquet --tasks T1,T3,T4 --seeds 7,17 --buffer 0.5
# 3) 空间控制 P1–P5
python sep_eval_spatial.py --points points_hiconf.parquet --tasks T1,T3,T4 --protocols P1,P1b,P2,P3,P4,P5
# 4) 缓冲扫描 + 重要性 + 区域
python sep_sweep.py --points points_hiconf.parquet --tasks T1,T3,T4 --buffers 0,0.1,0.25,0.5,1.0
# 5) 气候匹配
python sep_climatch.py --points points_hiconf.parquet --tasks T1,T3,T4 --methods M1,M2,M3
# 6) 气候 × 空间双重控制
python sep_joint.py --points points_hiconf.parquet --tasks T1,T3 --dists 50,100,200 --grids 0.25,0.5,0.75,1.0
# 7) 汇总
python _consolidate.py
```

产出：`sep_results.json`（每特征集 × 每任务 × 每区域 × 每协议）、
`sep_results_local*.json`、`sep_results_spatial_F0.json`、`sep_results_sweep.json`、
`sep_results_climatch.json`、`sep_results_joint*.json`、`modis_resid_check.json`。
