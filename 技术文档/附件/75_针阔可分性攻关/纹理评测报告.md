## 3. 配对设计（doc61 §五 B2 强制项）——本轮核心产出

### 3.1 为什么必须分档

doc61 要求"同一区域内、高低对比的配对设计"，但实测数据条件不支持严格执行：

- 60 m DEM 只覆盖川域，本点集 **3,508 / 24,329** 点有坡度/坡向；
- 严格执行"Δelev≤200 且 Δslope≤5° 且 坡向相近"后，T1 仅 **724 对**，其中可核地形者 ~10 对；
- 全国 1 km DEM 只能补**高程**，不能补坡度（实测 1 km DEM 派生坡度中位 **0.0–0.04°**，p90 ≤0.8° —— 无物理意义）。

因此按**地形量可得性分三档**，各档独立报数（先写死再跑）：

| 档 | 约束 | 用途 |
|---|---|---|
| **P1 严格** | 双方均有 60 m 地形 且 Δelev≤150 且 Δslope≤5 且 Δasp≤45 | 最可信，但实测 **0–19 对** → 全部标"支持不足" |
| **P2 高程** | 双方均有 dem（60 m 或 1 km 补）且 Δelev≤150 | **主档**，样本足够 |
| **P3 邻域** | 仅同邻域（≤radius），不控地形 | 上界参照（混杂最多，AUC 应最高） |

半径扫描：10 / 25 / 50 km。贪心 1:1 无放回，稀缺优先；P1 先占用候选，再在剩余点里跑 P2/P3。
配对分层 CV：**同一 pair_id 的 A/B 两点强制落在同一折**（防"同邻域一点在训练、配对点在测试"的泄漏）。

### 3.2 配对平衡诊断（T1，P2 档，25 km）

| 量 | 值 |
|---|---|
| 配对数 | **590 对** |
| 配对距离中位 / p90 / max | 18,208 / 24,234 / 24,993 m |
| **Δelev 中位 / p90** | **26 / ~100 m**（n=590 全有高程） |
| **Δelev 标准化差 \|SMD\|** | **0.0004**（极佳平衡） |
| 坡向同档率 | 0.002（低——因坡度/坡向仅川域有，P2 档未约束坡向） |

> P2 档的明确局限：**只控了高程，没控坡度/坡向**（全国无可用坡度源）。因此 P2 不能完全排除"坡向混杂"。已用 P3（完全不控）做对照，两者差即为地形混杂的量级。

### 3.4 配对设计的判读

**关键对照：全量 0.9976 → 配对 P2@25km 0.9745，Δ = −2.31 pp。**

- 区域/高程混杂对 AEF64 高 AUC 的**贡献只有约 2.3 pp**。也就是说，**AEF64 在我们的 hiconf 标签上确实学到了针阔差异，不是"区系捷径"**。
- 半径从 10 → 50 km，AUC 单调回升（0.9733 → 0.9784），符合"半径越大、区域混杂越多"的预期，方向正确。
- 但 P3（完全不控地形）反而**低于** P2（0.9572 vs 0.9745）—— 说明 P3 剩下的多是"地形量缺失而无法进入 P2"的点，不是"更宽松的匹配"，两者不可直接当松紧序列读。

**必须守住的口径**：0.9745 仍是**池标签口径**。doc74 §1.0 的核心疑虑（标签按坡向系统性错标 → AEF 含地形光照 → 学到的是被错标的标签）**未被本轮证伪也未被证实**。配对剥离了区域与高程，但**若 ENF/EBF 的错标本身与坡向耦合，且该耦合在全国一致，配对也剥离不掉**。判伪这条路需要**独立真值**（M3 人工判读 / 外部产品一致集），不是纹理能解决的。

**状态：未实测。** 以下为已冻结的设计（先写死再跑），影像源恢复后直接执行。

### 4.1 尺度与指标（预注册）

| 项 | 设定 |
|---|---|
| 窗口 | **3×3 (30 m)、5×5 (50 m)、9×9 (90 m)、15×15 (150 m)** —— 逐尺度单独报 |
| 源波段 | S2 B8（10 m NIR，生长季 2023-06-01~09-30 中位，SCL 掩膜 + 云量<60）；量化 p2–p98 → 0–255 byte（GLCM 要求整数输入） |
| GLCM 指标 | asm / contrast / corr / var / idm / savg / sent / ent / dvar / dent（4 方向对称归一后取均值，与 GEE `glcmTexture` 同义） |
| 邻域统计量 | 局部 mean / 局部 variance / **lacunarity 代理 = var/mean²** / **阴影比例 = 窗口内低于窗口 p20 的像元占比** |
| 地形校正版 | **未产出** —— 另一 agent 的 C 校正模块未见落盘产物；本轮只设计原始版。恢复后加 `--topo` |

### 4.2 臂与判据

- `Arm0` = AEF64（本轮已实测，即 §2.2/§3.3）
- `ArmT_w{k}` = AEF64 + 窗口 k 纹理（逐尺度分别报 **ΔAUC**）
- `ArmTonly_w{k}` = 仅纹理（诊断纹理的独立判别力）
- 判据（沿用 doc61 §阶段3 与 doc74 §1.1）：**ENF vs EBF 配对条件下 ΔAUC ≥ +0.02 且 paired AUC ≥0.80 → 纹理有独立信息；<+0.01 → 纹理无增量**。

### 4.3 注意：纹理很可能反而更难，不是更容易

给主 agent 的先验提醒：AEF64 在配对条件下已有 0.9745，**天花板效应明显**——纹理要在 0.9745 上做出 ≥+0.02 的增量难度很大。纹理真正可能发挥作用的场合是**真值口径**（doc54 人工判读 0.724），而不是池标签口径。**若影像恢复，建议优先在外部独立真值集上评纹理，而不是只在 hiconf 池标签上评**（否则大概率得到"无增量"的阴性结论，且该结论不能被解释为"纹理无用"）。
