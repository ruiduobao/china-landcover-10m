## 二、复核三条最快路径

1. **核属性口径**：`habit_by_code.csv` → `51` 的 `pheno_E=0.9175`（物候也说是常绿）、`61` 的 `pheno_E=0.1523`（物候基本同意落叶）→ **两轴一致**；而 `81` 的 `pheno_E=0.2887`（物候 29% 说常绿）→ **FCS10 漏标**。
2. **核地理结构**：`habit_by_prov.csv` → 西藏 `fcs10_E=0.515 / pheno_E=0.914`；青海 `0.199 / 0.582`；重庆 `0.838 / 0.604`（反向）。
3. **核海拔机制**：`habit_by_code.csv` → `71`（常绿针叶）海拔中位 **1,038 m** vs `81`（落叶针叶）**1,393 m**；再对正文 §3.4 的 81 码内部分组（常绿组 2,598 m / 落叶组 1,004 m）。

## 三、已知实现缺陷（留痕）

首版脚本把 `habit_pheno` 先赋字符串 `'unknown'`，随后用它与 `habit_fcs10` 的映射结果比较，导致 `s2_amp_thr350` 档 48,552 点**全部误标 E2C**、一致率被压到 0.4518。改为逐元素布尔比较 `(amp2023 < 350) & (habit_fcs10 == 'evergreen')` 后回到 **0.6204**。正文 §2.3 已记录。
